# zi-gate-shooter

竖屏无尽数字门射击游戏的策划项目。工作目录名不代表已确定的产品名。

**当前阶段：Stage-00 / 策划 v0.2，尚未开始开发。** 用户明确说“开始开发”后，才核实依赖并搭建游戏工程。现在没有游戏代码、可运行版本、正式素材、已批准概念图或实测性能。

核心体验：左右移动、自动射击，把装备箱打碎、把数字门奖励打高，再走位领取强化，感受火力形态升级，击杀得分并继续无尽循环。

## 范围与状态

- 已确认：竖屏、底部角色、目标向下推进、击杀得分、射击成长目标后领取、无尽、元素少、视觉精细且刺激。
- 候选方向：手机浏览器、TypeScript + Vite + Phaser、精细科幻机械风。平台、形象、风格、具体数值均未正式确认。
- 本轮只完成文档整理、规则设计、档案建立和开源文档仓库发布。没有部署游戏或安装依赖。
- 不加入登录、支付、广告、后台、多人、基地经营；个人项目独立于公司代码、私有包、配置和运行环境。
- 所有策划数值都是待试玩调整的起始值；纸面推导不等于游戏运行结果。
