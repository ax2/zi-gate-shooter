## 运行与构建

使用Node26环境，依赖已由package-lock.json锁定。

```powershell
npm ci
npm run dev -- --port 5178
npm run build:wechat
npm run build:android
npm test
npm run build
```

浏览器打开 `/canvas.html` 检查与微信相同的Canvas渲染器；根页面为早期Phaser验证入口。微信候选输出在 `build/wechat/`，导入开发者工具时填写自己的小游戏AppID；默认不伪造AppID。AppID可在本地构建配置填写或通过WECHAT_APPID环境变量提供，后续构建保留既有本地值。
