# Mechanical Pulse v1 / 原创配乐候选

2026-10-11，由本项目代码tools/generate-music.mjs编曲/合成，未导入外部旋律、音频样本或商业游戏声音。没有调用音频生成服务/模型，故无模型提示词。程序与生成音频按项目MIT提供。重新运行npm run assets:music得到相同SHA256，不覆盖或改动原7个WAV音效。

120BPM、4/4、8小节、16秒。D minor/B-flat/F/C根音各两小节，八分音符合成器分解和声、短次低音、正弦扫频底鼓与确定性噪声军鼓/帽，短循环延迟。候选机械电子脉冲，避免复杂旋律抢射击节奏；不是按用户正式批准的音乐方向制作。

输出public/assets/audio/mechanical-pulse-v1.wav，22050Hz单声道PCM16，705644字节，PCM数据705600字节。峰值0.619995、RMS0.103252（均为归一化线性样本值，非LUFS）；首尾样本0，5ms边界安全斜坡。导出两次哈希一致：e6ab14b9db45c9738b20365969a61cafbe2225dbda14aae53a4f2963ba840efb。数值只证明文件边界和峰值，不证明人耳无缝/混音/质量。解码后设备可能重采样/升浮点/多声道，不能把705KB当实际内存占用。

两个平台独立一个音乐节点，loop=true、候选音量0.18，与音效设置/池独立。默认音乐继续关闭，保留既有存档偏好；用户可在设置打开。只在战斗播放，暂停/后台/死亡停止；手动继续请求同节点从暂停位置续播，平台实际中断/音频焦点需真机验收。创建/配置/播放/暂停失败隔离与5秒退避，迟到Promise/旧节点错误不会清新请求。
