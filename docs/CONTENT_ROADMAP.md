- 5种武器：保留速射/霰射/穿甲，增加两种真正改变目标选择或覆盖节奏的武器。先比较机制价值再制作正式素材，不用换色算新增。

- 3个章节首领：独立轮廓与动作、各自招牌攻击和攻防节奏。不是仅改血量或名称；章节首次遭遇能看到核心招式。
- 每章至少3套可轮换战斗组合，组成压力→释放→奖励取舍→首领的节奏；保留正常成长和可达路线，不把随机堆敌人称关卡丰富。

## 推进顺序
1. 首领内容：先制作章节专属攻击与可读预警，实玩确认再做对应原创机体/动作；不得把复用机体的机制候选当作最终三个首领完成。
2. 敌人协同和波次：新战术角色与旧敌组合，加入明确的避让/集火/取舍，避免只加数量。
3. 武器扩展：新增覆盖与节奏差异，箱子仍需击碎后拾取；成长能被玩家看到和感到。
4. 整体节奏与音画整合：正常局验证每一轮实际遇到的内容，调整过长空窗、重复高潮和奖励选择。
