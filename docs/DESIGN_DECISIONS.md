# 设计决策记录

2026-10-11。用户已授权策划整理、本地项目、长期档案和 GitHub 开源仓库。除这些操作及明确需求外，以下是本轮推荐，**未获逐项确认**。原始材料的命令式文字按历史交接解释，不扩展当前授权。

| ID | 原建议/缺口 | v0.2决策 | 原因与取舍 | 状态 |
|---|---|---|---|---|
| D01 | 只有零散玩法约束 | 建立奖励事件的连续时间顺序与同刻优先序 | 避免引擎回调影响死活/发奖 | 候选 |
| D02 | 火力封顶附近提示裁剪，溢出未定义 | 剩余百分点按1:1转超载并显示；在途门不换类型 | 避免承诺+30实得+5的落差 | 候选 |
| D03 | 超载满时继续奖励的损失未明确 | 活跃期间储能满则额外+0；预告；后续槽位可换清场段 | 保持上限，不引入新货币 | 候选；长局风险 |
| D04 | 跨门选最近中心 | 用穿线时的内部区间，空隙算错过且锁整排 | 防擦边领奖和过线后扫领 | 候选 |
| D05 | 箱子接触有伤害但后续状态不明 | 撞毁退出无掉落；无敌碰撞也移除 | 避免重复贴身扣血/撞箱刷装备 | 候选 |
| D06 | 有效伤害概念，缺少快照/碰撞细节 | 子弹发射快照、相对运动扫掠、最近目标消耗 | 帧率和表现不能改变收益 | 候选 |
| D07 | 连锁爆炸可被误解为范围伤害 | 只做视觉；无溅射、穿透、激光 | 收窄首版，防多目标充能漏洞 | 候选 |

| D10 | 首领清场/重叠威胁未具体化 | 入场等排空、战斗不刷奖励、死亡同刻优先检查生存 | 避免吞奖励、堵路、死后回血 | 候选 |

| D12 | 只查每时刻有一条路 | 从当前可达出口做时空校验，安全路线不依赖DPS | 单模板可解不等于组合可解 | 候选 |
| D13 | 连击和慢动作增加边界 | 最小版移除连击倍率与慢动作/命中停顿 | 少系统、降低时钟复杂度 | 候选 |
| D14 | 平台/风格默认 | 沿用H5+TS/Vite/Phaser和机械风分析，开发前再确认 | 无既有工程，尚无正式技术选择 | 未确认 |
