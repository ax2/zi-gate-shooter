# Stage-228 试玩

固定入口 http://127.0.0.1:5178/ 。服务停止后双击“启动游戏.cmd”或npm run play，保持服务窗口运行。

首章21秒留意轻机后的两翼炮：门仍需持续射击、穿过才领取，可选择先清一翼再转炮。侧翼章21秒从连续冲锋改为两哨错时锁位接冲锋，抢拆或等待实弹后转移。重装章10秒首波中间炮会在锚炮间横移，可跟枪拆炮或转火开路，之后仍有断供中继取舍。

本轮保留总人数和原奖励排程，新增实际射击和位置变化。武器持续叠加、充能与电容接力仍有效；不显示敌弹未来轨迹。自动策略能过关不等于真人难度验收。候选数值后续试玩调整。
