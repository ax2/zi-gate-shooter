Stage-154高火力组合完成后约60秒才产生第一次跳伤，升级感弱。先允许所有已装武器有效直击释放，原攻击先完成：相同策略跳伤11/12→23/22，但后者首次仍等60秒，说明仅扩触发来源不够。all-weapons-only.json与first-checks保留。再补单体聚能：没有可跳邻敌时，若原目标仍活着，打一份储备激光80%伤害；有邻敌则原两跳80%/64%。最多一束、一次消耗，不多次累积，不改射速/原武器/原激光/敌HP，也不读玩家DPS抬怪血。
