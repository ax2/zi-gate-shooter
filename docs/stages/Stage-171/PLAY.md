# Stage-171 首领混合编队

固定试玩：http://127.0.0.1:5178/ 。停止后在项目目录运行 npm run play；本轮构建已完成。

前三轮保持单首领教学，R4–6仍是原来的屏障、突袭、交叉火力。R7起首领机体与护卫编队错开轮换：R7侧翼突袭、R8狙击交叉、R9护卫屏障；R10–12继续错位，形成三种原机体×三种原编队的九种组合，之后重复。不是新增九种首领模型。

屏障场先拆盾卫，突袭场留意两侧冲锋，交叉场优先压制狙击哨机；原机体招式与半血反击继续存在。没有提前显示未来射击轨迹，所有旧武器叠加保留。

旧版后期首领常在1–2秒被秒杀，第二台护卫尚未入场。本轮R7起增加按轮数固定的首领耐久倍率1+max(0,轮数-6)，不读取玩家DPS。前三轮和R4–6的首领HP保持；普通敌人曲线保持。数值候选，重点试玩是否形成取舍、是否拖沓、奖励是否仍有推动力。

三路线各21分钟自动正常成长已验，后期九种组合实际交战3.68–9.87秒；自动策略不是人类难度结论。完整阶段保存在build/playable/Stage-171，46项构建资源逐项哈希核对；serve.mjs配置5252端口，本轮未启动该冻结服务器。不打ZIP。
