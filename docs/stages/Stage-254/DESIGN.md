# 击破表现设计

仅表示层：沿用1.35秒机身解体、四拍0/.16/.34/.56秒、四爆炸槽、三块机身和原胜利/原2.2秒战利品显示。第4拍替换为专属六帧反应堆贴图，持续0.72秒，400px绘制范围，最后20%淡出；前三拍仍为原通用局部破坏，不额外叠一个无限制大爆炸。

三片从原第三帧破损机体裁出，左右外抛速度85→150px/s、旋转0.35→0.65rad/s，落体含短重力项；中心块下坠并轻偏转。寿命和数量不增加，不改World、奖励、碰撞、输入、首领回血或成长。世界仍完整运行，无慢动作/击中停顿/全屏白闪。

主破裂标准alpha0.9、弱档0.55，两档同节拍、同400px范围、同1.5MiB图集；不是GPU性能承诺。绘制位于既有爆炸层，敌弹/数字/HUD在前；正常首领胜利本就清除敌弹，不伪称演示中的额外层级探针弹是正常遗留。
