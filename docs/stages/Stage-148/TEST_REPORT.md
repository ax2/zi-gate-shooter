# Stage-148 机动哨机（2026-10-15至16，画面待验）

## 内容与修订

每个第二章以后的循环中，一台原有狙击哨机改为relocate行为。优先选择30–44秒的首台，缺少该台时选50–56秒的一台，仍用原时刻、位置、HP、35分与3发纵列齐射。没有额外加敌或按玩家DPS增血。该台转为y360可见投送，保留0.45秒局部保护和原安全入场；首章不变，原箱门/补给数量和时刻不变。第二至四轮投送计数35/26/45→36/27/46，来自一台原有哨机改变投送方式，并非新增一台敌人。

首版仅在齐射后的冷却中换位。三种300秒正常策略均见到3台，却全部在首轮射击前击毁，实际移动0台（normal-before-deploy.json）。因此修订为入场先向内侧移动140，速度200，0.9秒部署窗口；随后每次真实齐射后在冷却前段交替返回原位/内侧位，蓄能阶段不横移，10秒后仍按原规则离场。常规两次齐射和一次部署最多三段横移，不用无敌或HP堆积强迫存活。

换位计数sentryVolleys只由实际齐射推进，独立于EMP取消的连射状态。EMP仍暂停射击/中断蓄能，保留已发敌弹与当前换位索引，不把机体瞬移回原位。实战和安全预测共用advanceBody/sentryDestination，无另一套简化危险模型。

沿用项目既有原创sniper-v1.png的完好/蓄能帧；实际查看过三帧，第三帧为破损图，不把它当移动姿态。代码增加当前移动时的0.07弧度侧倾与局部侧推尾焰，弱特效减少尾焰线条；不重画商业素材、不用全屏闪光或未来轨迹。标签区分换位中/机动蓄能，原伤害/掉落/残骸保留。这是既有机体的行为变体，不宣称全新美术机种。
