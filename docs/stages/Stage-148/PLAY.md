# Stage-148 机动哨机候选

固定入口：http://127.0.0.1:5178/ 。在项目目录双击“启动游戏.cmd”或运行 `npm run play`，保持服务窗口运行；尚未构建时先运行 `npm run build`。旧阶段端口不再作为长期入口。冻结候选仍在build/playable/Stage-148，`node serve.mjs`为5228。

第二章起，每轮一台原有普通哨机改为机动哨机：入场先向内侧侧移140，停稳蓄能；齐射后再换位。观察它当前的机体位置和局部蓄能光，重新对齐目标；没有未来敌弹轨迹线。优先击破也能阻止它开火。原HP/分数/敌人数量/有限驻留保留，旧武器与奖励照常叠加。

本轮已做规则、正常成长和渲染调用验证，但浏览器访问策略及标签连接问题阻止新动作的实际截图。用户确认游戏现已能打开，不等于机动哨机画面验收。本候选的侧推/文字重叠、真人难度与长期乐趣仍需实际复查。
