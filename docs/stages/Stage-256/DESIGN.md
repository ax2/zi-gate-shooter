# Stage256 终线轮换与全歼反馈

目标是让首领前的短战斗有不同站位与击杀顺序，并给主动清场一个真实、可见的收益，不增加新货币或局外数值系统。本轮新增6种编排，加既有3种构成9种；不是9种新敌人。使用现有原创机械机体、炮口动作与真实弹道，没有新素材或预测线。

|章节|战况0|战况1|战况2|
|---|---|---|---|
|走廊|中盾扇炮＋双轻机|侧盾护折返炮＋另一翼纵列轻机|中盾＋离盾横移炮＋侧翼轻机|
|侧翼|锁位哨＋两翼短刺|换位哨＋近翼折返＋远翼短刺|三角哨＋双翼折返|
|重装|既有旋扫炮组＋中盾|侧盾护折返炮＋另一翼旋扫|中盾＋横移炮＋缓行加速火箭|

复用battleIndex(round,battlePlan)，与本章战况一致，不另摇随机数；首次走廊固定原编队。原终线4/3/3人数、68秒门槛、旧目标/掉落全部离场后才原子准入的行为保留，已发弹继续危险。完成快仍提前接首领。

首候选实测部分战斗不到1秒，故第二轮起终线装甲/哨机耐久固定×3，盾卫/冲锋×2，轻机×1；首章×1。沿用round基础曲线，不读玩家DPS，不改全关普通敌人。仍允许高火力在出招前击破，不为展示动作强制锁血或设置最短战时。

只有本次成功准入的全部唯一ID通过真实击杀结算才给40充能。等待/拒绝不建立目标；漏敌、撞毁、离场、无关敌人击杀均不能补齐。每组只发一次，下一轮清本组集合；本局累计全歼数保留，重开自然清零。旧分数、火力与所有武器保留，满100照常永久+10%并触发6秒超载和技能点。

HUD下方紧凑显示击破数/目标数、全破+40；契约仍活动时优先保留原契约区。真实截图发现320高折返炮标题被新HUD上沿遮挡，收紧6px解决，避免改敌人站位导致规则对照失效。全歼用金色3秒回执，延后配件回执排队，只有实际展示时间消耗阅读时长；原危险/拾取避让保持。

所有数值仍待真人试玩。单一450ms观察者无伤不是整体难度证明；更多跨章节变化、长局取舍与视听质量仍是目标，不因本轮九种终线组合而结束。
