# Stage-134 首领战术编队验证（2026-10-15）

## 最终内容
首轮1–3原有敌人/首领规则不加编队；4轮起按章节固定三种首领战术，不读玩家DPS选择。每战总共两单位，不无限补兵，首领原HP曲线不变。
- 护卫屏障：两名供能盾卫同时入场；任一存活且未离场时首领只承受55%伤害（45%减伤，不按两护卫叠加）。供能护卫具有普通同轮盾卫3倍固定耐久，前移至y440后悬停，年龄12秒后继续离场；保留盾卫自身开闭护甲/蓄能/射击。允许直接强攻首领；拆护卫能更早解除屏障并取得奖励。
- 侧翼突袭：0.4秒与2.8秒分别投放左右突进机，使用既有蓄能冲刺，目标车道240/480。
- 狙击交叉：0.2秒与2.6秒交错投放左右狙击哨机，保持原本到位/蓄能/射击/10秒撤离。
以上时刻相对正式首领战，入场阶段不投放，且必须存在存活首领。每个组需在实体上限内，通过带实际boss phase/phaseTime的保守安全路线预测（含450ms反应）后才投放；失败0.5秒后重试，超过计划3秒放弃。护卫成对原子检查，不生成半组再强塞第二名。首领胜利/玩家死亡后取消未完成组。
每个实际击破编队单位额外充能15，沿用100突破/超载；自然离场、同一尸体重复接触、首领死亡清场不发奖励。技巧成就“战术拆解”需两个计划单位均实际投放并击破、该战未受伤且首领胜利；胜利回血不能抹掉受伤记录，同帧玩家死亡优先，不给成就。记录进入既有本地存档，无局外伤害奖励。

## 画面与交互
复用项目原有原创机械机体，为供能状态加入薄层分段防御环、供能护卫标签、蓝色首领生命条及明确45%减伤文字，屏障消失时扩散碎环，恢复橙色HP条。不是指向玩家的未来弹道；只有已发射敌弹和机体自身蓄能保持可见。编队名进入HUD，战术提示在底部；编队击破充能也在底部，期间隐藏旧提示以免叠字，不新弹窗挡住首领与危险。弱档减少防御环光晕。
成就页现8项，压缩行距但保持标题/说明/返回按钮完整。原生菜单、光学分支、武器叠加规则保持；共享CanvasRuntime生产入口使用本阶段内容。

## 过程发现与修订
初始普通盾卫耐久下，正常高火力局屏障仅持续约1.0–1.23秒，护卫来不及行动。改固定3倍耐久后，适中构筑的先拆策略仍只能击破一个，第二个在转火前撤离。加入有界悬停后，两护卫可被主动处理，先拆的收益在对照中成立。初版与悬停前记录分别保留initial-guard-durability.json、priority-before-hover.json；没有修改首领HP去制造收益。
最初规则单测在护卫还低于有效射击上沿，或与首领碰撞盒重叠时注入静止子弹，实际无法按预期击中护卫；改在其进入前景后验证奖励，保留射程/碰撞规则。路线拒绝测试需真实击碎拦路箱后再检查重试，而非假设刚受一次碰撞就清空整排。
完整安全回归发现只凭phase=boss、没有存活首领也会调度编队，补实体检查。旧300固定威胁夹具的5秒预计算路径又被后续新调度打断（seed18/profile9），它本来只定义当前发射器；将该固定夹具明确隔离未来编队，保留原无伤/无击杀/无免疫断言，并新增独立动态入场测试：3章节×左中右起点，每次新单位入场后保留450ms反应、持续20秒，重新规划已观察威胁。之后完整回归通过，不把静态预测当作包含未来调度的承诺。
