## 目标与约束

当前许可原文已打入Android包，但玩家没有入口。本轮在Android/浏览器验证入口的设置增加离线许可查看；保留当前游戏World与暂停状态，原生返回键优先关闭许可；文字可选取/滚动，内容来自跟踪原文且不发网络请求。微信入口不引入DOM或Android库声明。

验证路径：canvas.html及实际Android本地web产物→设置→开源许可→滚动/关闭→返回暂停→手动继续。使用frontend-testing-debugging技能；Browser插件未提供，按宿主要求使用CUA内置浏览器，验证页面身份、实际画面、控制台、移动/桌面和交互证据。用户持续档案规则授权保存阶段报告与截图。渲染和模拟证据不得冒充Android插件或微信真机测试。

## 修改与发现

Android/浏览器Canvas平台新增可选openLicenses回调，设置增加开源许可并扩大面板容纳第五个按钮；微信平台不提供回调，沿用原四按钮且不导入DOM。许可查看用DOM dialog/pre，可选取/滚动，保持可见返回按钮、焦点循环、Esc关闭、安全区样式及深色滚动条。原文直接导入JS，原有随包文件保留，没有网络读取。Android App返回回调优先关闭许可；关闭只回设置，不恢复或新建World。

首次自定义Vite文本加载仅生产构建得到正文，开发页实际显示文件路径；截图/DOM检查发现后改为内置?raw导入，esbuild以text loader处理，移除临时Vite插件，最终配置无多余变化。正文39939字符与跟踪原文逐字符一致。失败帧只见当次工具输出，未伪称本地保存了前后对比图。

最终复查发现旧浏览器缺少反射open属性时，fallback关闭判断不能依赖dialog.open；改为检查open属性是否存在。隔离QA页模拟无showModal/close/open反射接口，真实UI打开、正文一致、关闭和焦点恢复通过。QA页不进入APK；这只是API缺失模拟，不是旧Android真机。夹具首次内联module触发Vite junction HTML proxy错误，改为外部mjs后通过，错误发生于测试夹具而非游戏产物。
