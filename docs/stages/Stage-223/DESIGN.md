# Stage-223 终线攻势

2026-10-17。修正强构筑清完尾波后的空等，并给三类章节增加不同的收尾战。没有把“没有敌人”一律当成空场：原28–34/57–62秒的射门时段完整保留。

## 规则

每章在原全部排程之后，最早68秒检查一组终线敌阵。必须等当前所有敌人、数字门、箱子、拾取物自然离场或结算，才投放；不强删目标，不替玩家领取，不改同排互斥规则。旧敌弹保留并纳入同一可达性判断。安全判断拒绝时整组不消耗排程、不发出投放通知，按原机制稍后重试。

|章节|新组|应对|
|---|---|---|
|突围走廊|前盾1、后扇炮1、侧轻机2|先拆前盾或清侧机，再压后炮|
|侧翼夹击|锁位哨机1、短刺冲锋2|蓄能抢拆或离开入场锁位点，留出横移空间|
|重装封锁|左右扇炮2、中央盾卫1|集中一翼取消部分扇弹，再处理另一炮|

炮/哨固定待机0.1秒后走原完整蓄能，盾卫沿用1.5秒待机，所有成员有原0.45秒投送屏障。使用原敌种、固定轮次耐久、机械模型/蓄能/实弹和击毁效果，不按玩家DPS增血。新增基础击杀分依次130/75/160，无新货币或额外研发赠点。

整组清完后直接衔接原两秒首领警戒，不再无目标等到固定72秒。更强火力可以更早推进，弱构筑仍需面对实际存活敌人与拾取物；不会为抢时间吞掉奖励。第一章68秒以前的教学/成长排程和所有原敌阵保持。

## 实现与边界

closing-assault.ts只描述固定投放内容/标题；director追加排程；World沿用spawn/投送屏障/锁位/安全判断，以整组提交，首领条件仍要求全部排程消费、全部Body离场、最早68秒。没有新增玩家操作或大型系统，敌方未来轨迹不显示。

清空死亡敌人的画面不是立刻清弹；已有弹在终线投放和首领入场期间继续按原规则运动。强构筑可在侧翼哨机发射前抢拆，这是有效成长收益；另一实际输入策略已观察它发射，未强制延寿演出。

所有数值为待试玩候选。只解决收尾衔接的一部分，不将三组新敌阵当作完整耐玩性完成。弱构筑与主动瞄准的首领时长、整体难度/章节变化及真实设备性能仍需继续。
