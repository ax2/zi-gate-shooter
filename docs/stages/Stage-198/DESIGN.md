# Stage-198 轮换重盾阵（候选）

将后续侧翼阵从同期开盾转为先左后右的错峰窗口，玩家可集中一翼等开盾突破，或在中继抵达后转火断供。仍是原来的两前盾、两后哨和一个中路中继，不引入货币、操作键或新系统。

R5初见仍保留旧双盾；R8/11/14等后续侧翼章44.5秒入场。左盾0.1秒开始开盾，右盾2.1秒开始，沿用0.8秒蓄能/0.8秒回收与2.4秒闭合恢复。只有新轮换重盾闭合时减伤80%，开放及EMP时正常受伤，普通盾保持50%。生命、分数、武器数值和奖励数量不变，抗性不随玩家火力调整。保护期0.45秒、原4.5秒驻守与后续推进保持，不能永久挡路。

这套阵的中继由45.7延至47.2秒（R5保持旧时序）：先留出第二开盾窗口，再提供停火开双盾的机会。装备箱48秒等所有成长目标时刻保留。中继只影响实际范围内敌人，既有实弹仍危险；预测与运行共用同一机体行为，入场继续通过原安全检查。

视觉沿用精细原创盾卫贴图的闭合/暴露姿态，新增局部金属锁扣和I/II刻线，靠位移、冷暖状态和真实名牌辨认。名牌“减伤80%/暴露”与实际判定一致；普通盾EMP后也不再错误显示装甲减伤。没有未来射击路径，不增加粒子池；弱档保留核心机械及状态。

取舍：强构筑会在自然开盾后迅速击破，测试中R8右盾开放到击破仅约0.033秒；这符合强火力兑现，但真人能否理解等待窗口尚未证实。初版仅错开时间时第二盾在闭合中死掉；80%重盾配早中继又被EMP抢先开盾，均保留失败证据，未算成自然开盾完成。当前数值及10分钟后的首次出现节奏仍需试玩调整。
