# Stage-187 斜射哨机

固定试玩：http://127.0.0.1:5178/ 。停止后运行npm run play并保持窗口。

第2/5/8...轮侧翼章，原23秒的哨机变为斜射变体。它在可见位置入场，锁定你当时的横向位置；局部蓄能后朝该处发三连弹，再撤离。入场后不再追踪你，已发子弹保持原方向，可以横移避开，或在蓄能时优先击破发射器。中继EMP能中断剩余弹，恢复后重新蓄能且只补未发完的弹；旧弹仍危险。

没有未来射击轨迹线。原详细机体加机械转炮、金属分面/铜肋/膛口和真实开火回弹；只在实际接受发弹后闪光。所有敌方实际子弹的原红白危险标记现在按自身速度朝向绘制，仍位于友方特效与奖励面板之上，不改变碰撞或伤害。

原敌人数、奖励窗口与哨机耐久保留，不按玩家伤害抬HP；机动哨机、滑行军械箱和其他章节保留。该变体三发后撤离，极端停火时也最多驻留10秒。具体蓄能/间隔/速度均为候选，真人难度与长期趣味继续试玩调整。
