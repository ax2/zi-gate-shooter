# Stage326：星域、星路与可控加速

用户要求取代原来的双主题选项：总星图与星域图、可滚动星球与连线、目标星球的多程航路、走廊解锁后续星域，以及特殊奖励。已有固定炮台/带盾工事已实际存在，沿用，不新做同类系统。

## 星图和实际通关

六星域各七个有名称节点，共42星球、53条无向星路。每域为入口港→两条分支→必经要塞→两条分支→星门；星门连接下一星域入口。只有抵达上一星域星门才可前往后续星域，锁区仍可查看地貌和奖励。

点星球后用真实图上的最短路径规划；只在确认后开始第一条相邻星路，不瞬移。每程沿用自动射击、普通敌军/特种事件/旗舰规则，击败实际旗舰才抵达目标星球。途中只能查看，不能跳到新目标；抵达后可继续原目标，也可重新规划。死亡不推进，新出击从最后成功抵达的星球开始。未完成的航段和本局规划不跨刷新恢复。

目标星球决定舰炮/磁雷/棱盾主题、特种攻击与首领类型；防御星和要塞把真实工事首波提前至6秒，其余14秒。富矿和矿场包含高速区段；高额金币路线和较安全的维修路线形成选择。战斗强度仍沿用本次出击的sector递增，不按即时玩家DPS抬血，也不把地图上的每颗星球声称为独立新美术关卡。

总图/局部图可滚轮、空白拖动、↑↓滚动；◎定位，M进入/退出。位置区分停泊与航行，途中显示出发点和图示进程标记。上方战斗HUD也显示当前起终点，暂停和主菜单有星图入口。

## 永久奖励和存档

沿用同一version1永久机库存档，增加可选navigation对象{version:1,at,visited}。旧存档原样读取后由新默认入口初始化曙光港。只接收已知42个ID和从起点可连通且满足星门条件的visited子集；位置必须在该集合内。visited按固定顺序保存，视图用深复制，不接受原型成员或未知ID。

实际抵达将当前位置、首次访问记录和金币在同一个机库对象/同一保存事务中修改，避免分离两个localStorage键造成重复领币。保存失败沿用dirty重试与可见提示，不宣称已经写成功。节点/敌军战利仍须拾取；星球奖励是在实际抵达时直接到账，界面明确标记。

## 引擎与高速段

点引擎/Shift获得4秒真实双倍移动，14秒冷却从释放时计算；触摸和键盘均改变位移，不提供无敌、护甲或额外伤害。暂停、星图、商店、帮助和失焦不推进本局冷却。

高速航段在本程18–21秒、41–44秒各提前3秒预警；21–29秒、44–52秒高速8秒，2.6倍场景推进。低频琥珀边缘/极低透明度屏幕闪烁、一次程序预警音和头部倒计时同时提示，不画敌弹未来轨迹。弱档更低闪烁强度，静音不播音。高速增加背景真实滚距、敌机/工事前进位移和来敌频率，保留对象预算；敌弹速度/寿命、普通枪速、敌人开火计时均不加速。旗舰阶段停止高速。

## 缓降战利

新默认星路中的金币与装备货舱统一40逻辑像素/秒，寿命40秒，离开底部回收；对比历史22像素/秒但18秒就消失，此版能明显缓慢穿过更长屏幕。155像素内的原近身吸附保留，实际接触才入仓。最多12货舱、满池合并原位置，稀有装备频率与价格规则不改。历史无导航模式维持原回归规则。

## 边界

入口显式navigation=true。旧无导航World/历史双选模式保留；完整回归不代替新默认配置验证，需要另跑新配置的正常收益流程及浏览器操作。图谱已提供42节点，不代表42套独立敌军或背景；真人长期趣味、全星图最终平衡、设备FPS与音效主观质量仍需实际测试。
