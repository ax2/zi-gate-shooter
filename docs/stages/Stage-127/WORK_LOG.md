# Stage-127 首领攻防与长局压力（2026-10-15）

目标：让叠加成长后的首领能实际出招，保留普通敌群清场反馈；使用固定轮次曲线，不根据玩家实时伤害调整敌人血量。

## 发现与修改
- 正常T1开局、自动领取装备、真实选择技能/精调的三路十分钟基线：首领存活0.617–2.65秒，所有已击败首领实际发射0枚敌弹；原首次出弹需约4.15秒。故首领招式虽存在，正常成长会跳过。
- 首领基础耐久900→2250；轮次深度d=round-1，倍率1+0.6d+0.09d²。重型普通敌人1+0.4d+0.06d²，冲锋1+0.18d+0.015d²；无人机维持基础耐久作为清场目标。普通敌人第一轮基础血量保持。
- 首领初次等待0.45秒，保留1.35秒机体蓄能，约1.8秒真实出弹；精英初次等待1.2秒，重甲/盾卫1.5秒。后续招式间隔、敌弹速度、伤害、碰撞与路线检查保持现有机制。
- 视觉检查发现drawWorld中的首领文字被后绘HUD充能行覆盖。首领名称、剩余/最大血量及条改在HUD背景后独立绘制；首领战冻结提示移到底部。没有恢复敌人未来轨迹。
- 调整旧动画测试的初次等待值，仍检查0.6秒蓄能、发射位置和动作；修正首领第2招结束的断言只检查周期转换瞬间；狙击测试保留前30秒教学无狙击，承认Stage123后期引入。

## 取舍与遗留
首领更耐打、出招更早，原有火力收益可缩短战斗；没有无敌锁血或强制展示完整招式。低装备玩家的首领战可能偏长，低反应输入、20分钟新版渲染、低端设备与真人难度仍需检查。三路只有同一固定种子和路径驾驶器，非玩家研究。更多组合机体、选择型挑战奖励和契约入口仍未完成；整体目标继续。
