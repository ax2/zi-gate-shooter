# Stage-220 首领协同攻势

用户要求更刺激、更有章节差异。正常运行发现部分成型构筑在1.6–3秒击破首领，第一轮敌弹未到玩家附近即被胜利清场；单加护卫实测改善很小。因此同时调整协同编队和固定耐久，让战术有时间发生。

第一轮仍为原耐久的单独首领。第二轮新增追猎双哨：两哨分批入场，锁定各自入场时玩家位置，蓄能后三连，不追踪后续移动；可先拆一翼或避弹继续压首领。哨机外移110/610，避免被首领机翼遮住。后期原交叉护航也采用此行为，九种机体/护卫组合的轮换保持。

第三轮新增护卫屏障：两名供能盾卫提供首领45%减伤，均击破后解除；可以转火清盾，或用更强火力正面压制。所有供能卫队直接在480前方部署/悬停，使目标完整露在HUD下方，原3倍盾卫耐久、12秒驻留与开火规则保持，常规盾卫不改。实际击杀才有原15充能与正常分数，逃离不算击杀；原首领奖励与回血保持。清掉护卫后前8秒提示改为首领火力窗口，不再提示抢拆已消失目标。

首领耐久在原按轮次固定的曲线上乘以：R1=1、R2=2、R3=3、R4–6=4、R7=3、R8=2、R9=1.4、R10起=1。前期提供攻击窗口，后期回接已有加速曲线，实际HP不倒退。没有读取玩家伤害/构筑，没有削弱旧武器、强制无敌或锁血阶段。第一轮2250、第二轮7605、第三轮17280HP。均为候选参数。

恒定四倍的20分钟候选会让光学单首领拖到90秒，已否决并保存证据。最终三构筑最长单场约10.6/18.5/35.1秒。强火力仍能更快击破，快速抢拆护卫仍合法。无新货币/菜单/资产系统，不画提前敌弹轨迹，复用原精细机械机体与实际蓄能/开火/护盾效果。

仍未完成：真人难度、构筑强弱、长期首领重复与完整音画签收。安全自动操作者可无伤不等于真人容易，固定站中路受到惩罚也不等于整体平衡完成。
