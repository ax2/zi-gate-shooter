# Stage-152 构筑检验候选（2026-10-16）

## 玩法与选择
复用每轮前40秒接取、每轮一次、同时一个、30秒有效战斗时限的契约系统。新增“构筑检验”，只从当前已生效的雷暴霰射、棱镜激光、裂甲爆破、离子风暴中选目标，多组合时可切换。查看/切换不花研发点、不改武器、不接取；接取时固定目标和实际计数基线，不能用旧战绩直接领奖。原三个契约保留。

目标为接取后18次霰射跳电实际伤害、6次棱镜侧束实际伤害、4次裂甲实际引爆、6次离子放电实际伤害之一。普通直击、主束、箱门和仅解锁配方不计；其他敌人的真实有效效果也可计入，不限于标记增援。允许受伤和取得新配件，死亡优先失败。30秒内达标立即暂停选择原有100充能或一件已持有配件升级/T3精校，二选一、仅一次；失败不剥夺原成长。实战工程师成就只按实际检验获胜记录，不因浏览或接取授予，本地存档保留旧成就，不加永久伤害。

不同检验提供最多6组、间隔5秒、每组3个原有敌机：双翼装甲/中部精英、前后纵列、紧凑三机。HP、伤害和原画沿用固定轮次原规则，不读取玩家DPS；投送屏障0.45秒，提前准入成功才出现真实目标/通知，失败延后0.5秒重试，不为安全结果取消已入场敌机。单次占用3个现有敌人名额，总26不增，先预测整组到达期的无击杀路线。标记只在当前敌机附近显示，不显示未来射击路径。

卡片重排为四行，成功回执说明具体组合/真实进度，结算显示构筑认证次数。接取整张卡可触摸；有多个目标时单独的大尺寸切换控件替代小字点击区，在390宽映射后触控高度至少44px。十项成就缩短行距并保留底部说明/返回空间。多组合默认偏好不再有效时，从当前显示目标切到下一个，避免首次点击无变化。
