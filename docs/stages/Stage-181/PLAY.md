# Stage-181 交替炮阵

试玩：http://127.0.0.1:5178/ 。停止后在项目运行npm run play，保持窗口。

从第三轮起，每个重装章44.5秒会出现交替炮阵：两台原装甲改为左右220/500驻炮，第二台延迟1.1秒投送，分别蓄能后扇射。驻守4秒后自行推进，不会永远堵路。第一台先压迫，第二台有更长首次蓄能；留意机体光效和机械支脚，不会显示未来弹道。

两种应对：转向一翼集火，或在第二炮投送时抢中路中继。中继与第二炮同时出现、仍有原0.45秒保护；打碎后在300范围停火1.5秒，能打断蓄能。已发炮弹继续危险，需要继续走位。远链可跨两炮280距离，聚焦则适合先拆一侧后处理孤立目标；是否有效仍取决于当时站位、冷却与保护。

复用原两装甲、一冲锋、一中继，敌人数、基础击杀分数155、装备/数字门/首领时刻保持。两炮为固定原轮次生命×3，R3各489.6/R6各1080；不随玩家伤害变强。自己的武器、升级、冷却与奖励不改。打碎箱子仍需拾取，门穿过结算仍互斥。

原创详细装甲主体保留，新增有限机械支脚、驻守姿态与停火颜色，弱档保留战术信息。完整build/playable/Stage-181含46构建资源+serve.mjs，可node serve.mjs使用5263；本轮仅配置冻结服务，未另启，无ZIP。
