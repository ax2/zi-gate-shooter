# Stage-204 游弋火控

新增交替重装章“游弋火控”：第6/12/18等轮仅后炮横移，越出原320中继范围时失去增幅，前炮驻守。原人数、血量、投送时刻与奖励保持，详细机体增加金属驱动舱与局部喷流，不画未来弹路。正常对局实际横移/活中继断供/单线出招已留证；15条无击杀路线通过。长期构筑分工、难度与真人视觉仍未验收。

现有火控前后炮同x驻守，偏向集中贯穿；本轮让固定交替重装章的后炮从入场起平滑横移，保留旧驻守阵作为其它重装章的对照。不随玩家装备/伤害更改HP或阵型。第6轮前炮/后炮仍2160HP，中继144HP。只增加后炮controlPatrol标记与固定homeX，原三体原子投送和安全准入保持。

半幅112、周期3.2秒，左右镜像；4.5秒驻守结束后停止横移，沿原下行速度离场。运动在供能查询前计算，实际射击、预测均调用advanceBody；中继范围、EMP范围、弹速、蓄能与回收规则沿用。投送保护仍0.45秒，不加无敌、不删除旧弹。后炮越界自然失去增幅，此时中继击破只能EMP覆盖范围内机体，范围外后炮继续原单线射击，是可见局部取舍。

第一候选等投送保护结束才横移，正常局中继0.58秒已被击破，虽然动了112却没有供能转换/真实出招，因此没有按已完成交付。修订为保护期间即启动机动，仍平滑、仍免伤/停射。正常四条新策略记录22帧供能/13帧活中继下断供与一发实弹，旧对应0发；不靠涨HP撑场。

原创既有装甲炮完整保留；机动后炮不用驻地支架，改为小型金属侧驱动舱、铆接边/散热栅和当前运动反向的短青色喷流。弱档简化栅片与喷流；方向按镜像运动符号，不是未来位置/弹路。原接收器随实时连接状态亮灭，文字加“游弋”，中继显示实际增幅台数2→1。

原两种雷暴精研/其它武器、装备、成就和奖励不变。本轮确实改变后炮运动和实弹，但普通/先前炮策略在这组强构筑中结果相近，不能据此宣称流派分工或难度已经足够；这些仍是后续验收项。
