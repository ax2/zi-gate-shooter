# Stage-60 敌弹不被奖励面板遮挡
2026-10-14。发现原绘制顺序为爆炸→敌弹→奖励面板，敌弹虽在爆炸上方仍会被不透明奖励面板覆盖。现改为爆炸→面板/标签→敌弹；HUD和暂停菜单维持原层级，碰撞、伤害、弹体尺寸和数量不变。
42项渲染回归通过（1.78秒），标准/弱档既有重叠测试增加敌弹亮芯晚于门数字绘制断言，避免旧测试只验证晚于爆炸而漏掉面板遮挡。类型检查与网页构建通过（136ms）。
新增开发夹具“敌弹与门重叠”：固定双门及一枚静止敌弹放在门数字上。390×844标准档、1280×720弱档实际截图显示橙色弹体在数字上可辨。初次截图未可靠看到敌弹，重新点击运行后约0.3秒捕获保留最终图；不把过期弹体的画面当验证证据。仅静态重叠测试，不是自然长局。恢复视口与正常入口。
本阶段未重新打包APK（仍Stage-56），未跑全量或真机；整体上架目标仍未完成。
