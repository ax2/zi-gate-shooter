# Stage286：配件改装产生真实形态变化

目标：既有精校仅提高同系系数，同一组件数量不变，花材料难以直观辨认。本轮不加资源或新系统，将六早期副组件的头两次真实精校增加有界的新攻击：蜂巢6→8→10发，磁钉3→5→7路，雷球2→3→5枚，电极2→3→4枚，索敌镜1→2→3路，旋刃3→4→5把。保留原发射位置/角度与原武器，旧20%同系系数继续生效；第三次以后只精校系数，不无限增加对象。

仍按现有4、6、8…同系材料支付、原前驱/分支与死亡规则，不免费升级。不强迫改装才能进化。材料足够时大图保留目标下一步/新能力，并给一张实际可付费的未满形态改装卡，形成当下改装/继续进化的取舍。卡片标本件等级/真实数量前后，Demo、火力参数、旋转实物和实际弹体同源。

风险：实际火力/拦截提升，需要候选数值平衡，不能拿全知无伤作人类难度；新旧无改装必须物理一致，原弹/端点不能因升级消失、预算不可突破。同一束光可有多个实际接触，索敌路数不是测量DPS。重绘/预览不得扣料、加时或注入战斗。沿用已读frontend-testing-debugging，Browser插件未提供，采用CUA Edge Playwright真实按钮/截图。新素材无需生成，重用原有机械模块和原创光刃，不用占位图交付。
