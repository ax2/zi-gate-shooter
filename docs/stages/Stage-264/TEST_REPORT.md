## 规则与关键取舍

前三章、单门、未到100%或无T3的配件保持原规则；打满不直接升级，穿过才领取，同排只选一个，漏门不补，死亡优先。旧武器、精校、技能和已经取得的公共成长均保留。本轮没有改变敌人HP、排程、射击速度或碰撞。
