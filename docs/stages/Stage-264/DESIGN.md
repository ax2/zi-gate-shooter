# Stage264 精校门与即时收获

2026-10-18。候选方案解决无尽后期双门都转为充能、用途趋同的问题。第4轮起、基础门火力已到100%、至少有一件T3配件时，双门左侧可给专属精校，右侧仍给充能；前三章、单门、未成型配件不改。不增加货币、敌人或局外属性，不抬高敌人HP。

|实际射击能量|精校门|充能门|
|---|---|---|
|0—23|充能20|充能20|
|24—不足56|充能30|充能30|
|56—不足96|指定T3精校+1|充能40|
|96—不足144|指定T3精校+1、充能10|充能50|
|144满档|指定T3精校+1、充能20|充能60|

达到56后，门的40点名义奖励换成一次现有武器精校，不扣玩家已经储存的充能。精校沿原有系数每次增加50百分点，例如150%→200%，只强化对应武器，不是全部武器提高50%。普通充能继续每100点给予公共常驻火力+10%与6秒超载。玩家可选强化核心，或加快公共突破/技能里程碑；自动光学路线未必适合拿某件武器的精校，不能把它写成全面增强。

门出现时锁定T3目标：先用已指定且符合T3条件的改装目标，否则沿已有构筑核心偏好选择；T2目标不阻塞其他T3候选。之后改变改装目标只影响未来投送，不能改在途门。仍按实际射击命中积累、穿过时结算，同排只领一扇；打满不直接发奖，漏门不补发，死亡优先。原有所有武器和参数保留。

门框继续用项目原创机械纹理，精校支柱用紫色电荷灯。门上显示模块名、精校/充能真实奖励和当前→下一专属系数；大数超过9999时改为精确的“系数+50百分点”，不把舍入后的同值冒充增长。普通门外观不变。上下文引导优先让位敌人战术，安全时说明取舍。

实际验证发现：完整参数回执因持续敌阵与原回执排队，首次显示可晚于实际穿门55秒。保留原面板的危险避让，新增HUD现有分数标题区域的3.2秒即时收获短签，依据真实装备变化显示“霰射炮精校+1”等；分数数字仍在原处。未领取不提示，不新增盖住战场的面板，不暂停战斗；暂停冻结提示剩余时间，开新局与回主页清空。完整领取时直伤参数仍排队，并可暂停查看当前全部参数。

本轮门槛、奖励成本和提示时长均为候选。正常自动策略的突破、得分、拾取发生差异时如实保留，不能据此声称真人最优路线或长期平衡完成。
