# Stage-146 导电中继

最终候选：http://127.0.0.1:5225/ 。服务停止后，在 `build/playable/Stage-146-final` 运行 `node serve.mjs`。

第二章起，44.5秒战术小节新增一台导电中继。击破后，300范围内可见的普通射击敌机停火1.5秒，并打开盾卫。它不会消除已经飞出的敌弹，也不阻止冲撞、碰撞或首领攻击。中继最多悬停3.5秒，再继续向下移动。

可以提前清掉威胁，也可以等敌机开始蓄能再转火中继；一次打断两台蓄能敌机可获“断电时机”成就。成就保存本机，不提供局外伤害奖励。已有武器、配件与技能分支继续累加。

素材和数值均为候选，真实浏览器只达成单台停火；双台时机成就由正常成长的自动化路线证明可达，尚未真人验收。详见 TEST_REPORT.md。
