# Stage-226 三拍旋扫炮

重装终线的重复固定扇射改为实际旋扫。第3轮第二门炮第一次出现，第6/9/12…轮双炮反向、第二炮延迟0.25秒启动。保留原2炮＋1盾、位置/投送时点/轮次耐久/得分，不随玩家DPS加血，不保护到强制出招。强火力或正确优先级仍可抢拆。

候选：0.6秒可见蓄能（与原炮甲相同），三拍间隔0.25秒，各3发，水平中心分量180→0→-180，右侧相反；单拍±40散角，向下310，原按轮次弹速倍率保留。先跟枪拆一炮，或观察当前实弹换位；不提供未来路径。已发炮弹不因炮台击毁消失，EMP暂停剩余攻击时钟，离开原y600开火区不再补发。

使用同一个advanceBody给实时和无击杀预测，新增的rake数据只记录下一拍和实际接受发射的计数/回弹。48敌弹/全局弹体预算保持，预算拒绝不能伪造回弹。机械炮甲主体保持，增加有钢质转台/铜色刻线/三管套筒的旋转炮架，实际发射才有短喷焰与退筒；弱档只减喷焰，不改变危险。

首个±55/0.9秒候选双炮会封死后续无击杀路线，导致admit反复拒绝而卡第6轮，否决。三种散角/两种错时的独立矩阵明确±40能保留路径，选±40加0.25错时；不放宽反应或投放检查。0.9秒中间候选虽过路线却使首轮新炮在三种常用安全构筑下全0发，继续修为原0.6秒蓄能，并把首轮安排在第二炮位，避免默认优先击杀第一炮掩盖新攻击。真实正常开火证据仍是验收门槛，不能仅因有新模式/单测通过便宣称有体验。

此轮是一个新攻击行为，不是新机体类型；没有新增货币、经营、强制扣血、武器削弱或平台任务。数值仍需真人试玩，整体难度/长局趣味目标未完成。
