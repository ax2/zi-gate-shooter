# Stage297：武器来源明确的实际命中反馈

目标来自“酷炫画面”和用户仍难以分清配件用途：把真实命中的物理打击、磁钉穿孔、电击、激光、等离子爆裂与光刃切割分别表现。增加原创精细碎片/粒子贴图，不能仅靠一层变色光圈，也不把未命中的光束端点画成命中。

使用内置image_gen生成单张六格透明命中图集；原图、完整提示和偏差均保留，不借商业资产。新命中记录独立于物理Effect池，不占实际敌弹/光束预算，不调用游戏RNG/实体序号，不影响伤害/奖励。仅在真实正伤害时记录；同一敌人同种来源短间隔合并，有限寿命与数量，暂停冻结，重开清空。

渲染在原战斗区域内、敌弹之前、HUD之外；弱档减少数量与范围，保留来源特征；不新增伤害数字或预测射线。新命中图仅证明表现，需同输入旧新真实World对照、正常成长、手机/桌面画面检查。浏览器连接/设备FPS/真人爽感尚待验证。
