# Stage-147 升级收益预览（2026-10-15）

## 问题与实现

Stage146战术目标已有实际收益，但当前升级卡主要写节点说明，组合配方另藏在暂停菜单。玩家难以知道当前配件能提升多少、下一步怎样凑出组合。此轮在三张升级卡展示真实参数对照、装新武器/强化已有武器的区别、选择后还缺的组合节点；选后回执重复同一收益。沿用原三路线、六分支、组合和持续精调，没有新增货币、系统或敌人。

把World原有profileFor/supportProfile计算原样抽到core/build-profile.ts，战斗与只读预览共用。预览只复制9节点及精调/分支状态，再运行BuildTree合法选择；不克隆World、不step、不发奖励、不消耗真实技能点、不改变随机状态。未选分支只显示共同范围/直伤/间隔收益，分支页仍保留原有用途与取舍。安装未持有武器显示T1，已有T3绝不预览降至T1。直伤含常驻加成、专属精校和精调，不计超载、命中率及溅射/跳电等派生，不冒充实战DPS。

组合行按选择后的状态计算：例如首次霰射后“雷暴还需：弹道2点＋雷电1点”，光学三点后补弹道可直接提示本次棱镜组合；锁住的雷暴节点说明先选导电线圈。没有替玩家强制推荐路线。三路线用原有金/紫/青色区分，保留卡片点击区域、节点名、完整技能树入口和原生可访问按钮。
