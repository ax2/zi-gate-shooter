# Stage270 装备文字避让与细时间核查

武器箱、普通T2箱和拾取物都保留原先的实际奖励。附近没有敌机时沿用完整报价；原报价会挡住敌体或越过HUD边界时，优先在装备朝外的一侧放142×60侧签，保留身份、升级前后值及打碎/拾取状态。侧签字号20/17/16，侧向中心偏移166并限制在画布内。

侧签避让当前敌体与本地状态文字、其他箱/拾取物、数字门、玩家机体和已经存在的敌弹，不读未来射击轨迹。两侧仍被占用时，只在装备自身显示简短名称；有空间后恢复报价。紧凑数字“伤”仍是原refitLabel的单轮直伤，不是每秒伤害；完整武器参数与常态完整报价保留。首领、活动契约、终线HUD有独立下边界，防止拾取文字被遮掉半行。

呈现只读，不变更命中、伤害、弹速、敌人耐久、箱门时序或奖励。沿用原机体、箱体、拾取信号和弱档表现。

路线核查：dangerTimeline/safeRoute增加显式stepFrames选项，默认6帧=100ms不变，诊断可请求1帧=1/60秒。细路径必须按每帧目标执行，不能重新当100ms路径消费。12px安全余量、实际物理速度上限与实际碰撞保持。测试辅助控制器先用原100ms方法，证明不了才用97点横向/1帧时间的预测；每个新敌体仍延迟450ms后才被控制器认识，既有移动继续，不射击、不免伤。

生产准入继续使用默认100ms保守预测。该选项用于补齐可达性证据，不借此改变默认投放量。所有体验与最终美术仍待真人反馈。
