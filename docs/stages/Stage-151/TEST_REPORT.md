机体线圈6格显示当前实际充电；放电使用破碎环弧、中央短电芯和青白火花，透明留出敌人轮廓，裁剪到240..1024战斗带。复用四个爆炸预算并优先保留组合，粒子160/弱50、连弧12/光束16上限不增；弱档保留主环与中心。独立低频/高频短音复用12声音上限。技能树、升级卡、回执、火力面板和结算统计同步说明；没有新增菜单、货币或装备槽。
