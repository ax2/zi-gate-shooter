# Stage-151 试玩

固定入口：http://127.0.0.1:5178/ ，刷新加载新构建。服务停止时双击“启动游戏.cmd”。

选择雷电路线：导电线圈 → 扩散/蓄爆二选一 → 离子风暴。第三点仍保留80%跳伤，并增加6次有效电击后的140范围120%放电。机体电圈显示6格电量；空场/冷却满充保留，下一次命中有目标时释放，最短间隔0.8秒。普通技能精调继续，原枪和旧能力保留。

可以把连锁扩散用于连通敌群更快积电，也可以用电容蓄爆持续打重装；风暴有局部范围收益。此为候选打法，不代表哪条更优。暂停→当前火力可查状态，结算显示实际风暴次数。

自动双分支300秒与规则通过。生产真实时钟在当前自动化浏览器仍有调度暂停，独立虚拟时钟画面回放不能代替真人难度/实时性能验收。平台后置。
