# Stage259 候选设计：布雷战术回报

沿用现有布雷机、充能、成就追踪，不加新资源。抢拆：真实蓄能期首发前击杀，+20充能。穿雷反击：同一载具实际成功发出两雷、两雷均跨过角色完整碰撞带、全程无伤且未接触雷，且发雷后击杀同机（先避雷或先击杀均可），+40充能。每个实际机体最多结算一次且两者互斥，源死不能取消实际雷，也不算躲过；边界销毁、预算拒发、碰撞消失、碰撞无敌不能伪造避雷成功。原敌数、伤害、耐久、射击与章排程不改；仅奖励可能使后续成长不同。

新战术成就为两个战术选择，沿用永久本机记录与本局计数。HUD替换原布雷标签，底部既有技巧提示按上下文显示；不新叠一层界面、不画预测线。战术回执进入已有避让和排队系统，不能被其带来的升级选择吞掉。参数为候选，需真实正常成长证明两种打法可达，不以注入单测代替玩法成立。

初候选要求先避再杀，三路线刻意侧移依然0次反击：成型派生火力常在最后一雷通过前击毁源机。为避免强迫停火，最终改为发雷后击杀与安全避过双雷顺序不限，待全部真实条件满足才结算。被击毁源机只在其仍有真实弹或仍在场时保留有限关联记录；无弹、离场、已结算、死亡/恢复均退休。无敌碰雷仍失效，所有同帧接触后再判最终奖励。
