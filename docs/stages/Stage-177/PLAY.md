# Stage-177 首箱预定

试玩：[火力突围](http://127.0.0.1:5178/)。服务停止后运行 npm run play，保持服务窗口运行。

主界面点击“首箱预定”，可选择下一局第一箱的T2配件：

- 霰射炮：近距聚弹与扇面覆盖，后续弹道路线可选贯穿、爆破或跳弹。
- 穿甲炮：对准纵列贯穿，后续取得T2爆裂可组成裂甲爆破。
- 爆裂炮：重炮直击与密集爆破，后续雷电二阶可组成磁暴榴弹。
- 电弧炮：前方索敌与邻敌接力，后续光学三阶再精调可组成电光连锁。

选择会被记住，主界面展示对应机械机甲预览。默认预定霰射，直接开始即可；仍从T1速射开场，第一箱计划在8秒投送，必须打碎并拾取后才叠加T2配件。预定不会直接发枪或技能点，箱子破碎也不等于已装备。拾取后原枪继续开火，进入对应技能路线不会把已持有T2配件降为T1。

只改变第一轮8秒首箱，后续军械/掉落/技能路线自由选择。错过首箱没有补发预定件，25秒补救保留原规则；每局结束后可重新预定。运行中不能改本局首箱，返回配置页不会自动开始战斗。

新旧偏好存档使用原版本1格式，缺失/非法预定回退霰射，原最高分、成就、设置与组合目标保留。没有新货币或局外伤害。

四种配置各600秒正常成长、实际爆裂起手与下一局电弧改选、手机/桌面与弱档已验。组合方向不是锁定职业或最短路线承诺，所有数值/均衡仍待试玩。完整build/playable/Stage-177保留46资源与serve.mjs（配置5259，本轮未另启冻结服务器），不打ZIP。完整验证见TEST_REPORT.md。
