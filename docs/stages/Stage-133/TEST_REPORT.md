- 分光镜组：每次主激光额外选择一个偏离主线、横距≤180的战场敌人，追加65%主束伤害的独立分束。分束从镜组发出，以有限线段碰撞命中沿途第一个对象，箱子/数字门/护盾会挡住；不是穿过奖励物的无碰撞自动伤害。门只在真实光束相交时收取这一束的能量（最多1次）；闭盾依原50%减伤。没有目标不发射，不从派生攻击递归，不攻击HUD外/入场首领。保留所有原主束/棱镜侧束。
所有比例/间距为候选数值，后续试玩调整。灼烧是重装单体收益，分光是侧翼覆盖，不能只用总伤害判断全部遭遇。没有增加货币、局外攻击力、登录或经营。
程序化局部曲线热焰、白热描边和火星替代初版薄环/硬三角；主体沿用原创机械机体，弱档减少亮度/火星。已发射敌弹与HUD仍位于特效上层；分光复用已有命中折射光效/音色，服从既有光束与粒子上限。

## 实际发现与修订
最初候选“主束首敌向180范围邻敌折光”在受控双敌场景可用，但300秒正常规则测试触发0次。诊断发现主束有效命中时无邻敌，扩大距离不能补救。保留branches-initial-neighbor-only.json与branches-neighbor-diagnosis.json；最终改成独立侧翼分束，未通过放宽“正常流程必须触发”的断言掩盖问题。
最初伤害隔离测试把宽门放在主束路径中，门正确挡住激光；后移动到旁侧再验证“不接触不受伤”。过场测试恢复后重置的激光先击杀目标，改为恢复时将玩家移到侧方，隔离灼烧时序。分束修订后，旧“主束被挡则任何侧翼也不能受伤”断言已不适用；改测分束自己的有限光路与吸收体，并保留主束阻挡下灼烧不附着的测试。上述为夹具/最终规则调整，未移除阻挡规则。
