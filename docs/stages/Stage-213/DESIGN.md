# Stage-213 双线王牌协同战

## 玩家选择

沿用挑战契约→危险猎手→切换狩猎目标的双线王牌，不新增契约类别或货币。原两台相同扇射精英改为左侧扇炮、右侧针炮。先拆扇炮会留下针炮五连；先拆针炮会留下五线扇射。横向覆盖与纵列连发让转火顺序具有实际差异。允许集火在暴走蓄能中抢拆，不能为演示技能给敌人临时无敌或回血。

## 候选规则

原精英类别、位置220/500、数量2、基础200HP×1.6×原章节曲线（R1为320，R2为467.2）、击杀分数/精英充能、30秒时限、20秒后撤离保持，独立于玩家伤害。未接挑战及分批悬赏不变，普通关卡本轮未加难。

扇炮：蓄能0.8秒，三线vx[-120,0,120]/vy300；针炮：蓄能0.8秒，三发同列vy400、间隔0.16秒（固定步长实际约0.1667秒）；基础休整2.4秒。原章节弹速倍率继续作用，最高1.3。

搭档真实死亡才标记幸存者复仇，逃离不会制造死亡。已经蓄能或连发的原招式先完成；随后0.2秒接完整1秒可见暴走蓄能。扇炮变为五线vx[-140,-70,0,70,140]，针炮变为五连，暴走休整1.5秒。可在蓄能时击毁，EMP仍停火；超时后已部署敌人与旧弹保留，不能因任务失败擦除危险。

仍需击毁同轮两名标记目标；两台同刻死亡不能虚构暴走。成功沿用充能150或强化已有武器、另加研发1点，领取一次才结算。既有王牌猎手/交火零伤仍用原判定与存档ID，成就总数仍20，旧武器持续保留。

## 表现与架构

复用原精细原创精英机体，增加原创局部金属侧散热组件或中央连发炮管、斜切边/铆点/供弹刻线。暴走改为橙红状态与增加供弹刻线，实际接受射击才产生局部回弹和短光；弱档保留硬件及角色信息，少量本地笔画，不增加战斗粒子系统。没有未来弹路。

角色/状态使用外侧窄两行描边文字，避开顶部契约栏及普通哨机标签；真实敌弹继续在奖励面板及标签之上绘制。原顶部及下方名牌候选图保留，证明修改依据。较复杂混合敌阵仍可能局部拥挤，不能宣称全局标签布局完成。

ace-duo.ts的出招由advanceBody调用，实时与安全路径预测共用。额外字段只附于选定双线目标，不改默认排程。死亡处只给同轮活搭档标记pending，出招开始才转暴走；accepted-shot回调记录回弹时刻和真实暴走弹数，容量拒绝不虚发光效。
