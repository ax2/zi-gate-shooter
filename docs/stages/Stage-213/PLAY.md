# Stage-213 试玩

固定入口 http://127.0.0.1:5178/ 。先回主菜单再手动刷新；当前对局未被自动刷新。服务停止时用根启动游戏.cmd或npm run play，不需要换端口。

正常取得火力后，点挑战契约；快捷键让位时可走暂停→当前火力与参数→挑战契约。点切换狩猎目标，选危险猎手：双线王牌，再继续挑战。每轮前40秒可接，每轮一次；建议准备T3，过早接取可能不能在30秒内全破。也可保持原分批悬赏或不接挑战。

左扇炮横向压制，右针炮纵列连发：先拆扇炮，接下来面对针炮五连；先拆针炮，接下来面对五线扇射。幸存者会完整蓄能，可继续抢拆；已发子弹不会随炮机死亡消失，不显示未来弹路。

全破后选充能150或强化已有配件，额外研发1点同时领取；看预览决定扩大构筑还是深挖配件，旧武器保留。原王牌猎手/交火零伤成就仍可达成。数值为候选，本轮没有提高默认关卡整体难度。
