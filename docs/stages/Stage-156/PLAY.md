# Stage-156 双线王牌悬赏

刷新 http://127.0.0.1:5178/ 开始新局。服务停止时双击“启动游戏.cmd”，保持窗口运行。

每轮前40秒，打开挑战契约，选择“切换狩猎目标”。危险猎手现在有两个目标：分批悬赏保留原先两名精英先后入场；双线王牌让两名耐久×1.6的扇射精英同时入场，30秒内全部击破。仍需至少一件T2配件才能接取，王牌建议先有T3或多种火力。接取前查看不花点，接取后本轮目标锁定。

仍允许受伤；死亡、目标逃走或超时会失败，失败不扣已有强化。王牌全破后，原来的充能150/已有配件强化二选一照常，同时额外领1点研发，再选择升级路线。额外点在领取时到账，只能一次。

悬赏战中的升级提示移到底部，成就提示顺延；看机体局部蓄能和实际敌弹走位，不画未来射击路径。原画机体/武器与已有成长保留。

正常自动回放中，T2单武器能完成分批，王牌只击破1台后失败；准备三武器后王牌5.77秒完成，发出9发实际敌弹。真人难度、趣味和长期平衡仍待试玩调整。完整冻结目录build/playable/Stage-156保留45个资源文件及serve.mjs，可在该目录node serve.mjs用5237运行；本轮未启动该端口，日常仍用5178。
