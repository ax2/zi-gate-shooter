## 问题与取舍
旧48秒补给在52.9667秒越过玩家，原50秒压制机首批实弹到玩家高度却是R4/R8的54.65秒、R6的53.57秒。先后生成不等于同时形成奖励压力，旧实测见 baseline-no-kill.json。

第四轮起隔轮将原成对箱放到150/570（原222/498），原50秒普通压制机变为49秒落在中央360、y550的盾卫，驻守5.5秒。若50秒为机动哨机，保留它而替换56秒普通压制机。首三轮保持原安排，无新增敌人数/奖励种类。盾卫沿用闭盾减伤、开盾弱点与真实扇射、0.45秒入场保护及EMP反应，未画未来轨迹。与首领供能护卫不同，不设置escort标记。

这不是完全不改难度：将狙击机替为盾卫时基础HP/分数由44/35变为64/60，再按原章节系数缩放。掉落入场计数增加一次，不等于多一台敌人。R4无击杀dropSpawns为47，旧46；R2/R3仍37/28。原两份装备、同排ID及互斥、击碎后拾取/门穿过结算规则保留。

候选几何：箱参数板宽236，盾卫精细机体宽160，左右各留12逻辑像素。护卫51.3秒发弹，首弹52.45秒到玩家高度，早于补给过线约0.52秒。危险优先提示，战略提示随后，既有武器说明仍可读。所有时刻与数值均需后续试玩调整。
