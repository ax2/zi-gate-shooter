# Stage-237 脉冲火箭炮

目标：给走廊增加需要读节奏的敌弹，保持少量元素。复用普通装甲种类与原创精细机体，加入机械双管火箭巢；不新增敌种/资源/模式，不增加敌人总数，不按玩家伤害追涨HP。

走廊章从原38/39/55秒中选择第一台无特殊pattern的普通装甲，替换为脉冲火箭炮；保留kind/x/at/普通HP/分数。首章38秒仍x190/y500；后续对应普通槽位改可见投送y350，原特殊炮阵/中继/补给不改。侧翼/重装不加入，使章节战术有区别。

预备0.5秒后完整蓄能0.9秒，左右端口各一枚，间隔0.22秒（固定步实际0.2333）。出膛初速vx±50/vy180，0.75秒后原方向速度乘4，未跟踪玩家；轮次原弹速倍率同时作用两段。一次双发后撤离，最迟2.5秒开始向下移动；可抢拆、EMP延迟发射，但已发火箭不因炮机死亡或EMP消失/停住。

物理和安全预测共用推进函数，跨点火步返回两个真实时间子段；相对移动玩家也按对应子段时刻计算连续碰撞，避免整步直线插值制造假命中或漏命中。普通弹不进新分支，折返事件仍只在真正反弹时计数；点火不能冒充bank-bounce。原弹预算/6秒寿命/掉出画面清理保持，获准发射才记数、回弹与喷焰。

炮巢使用钢壳侧向明暗、切角、散热槽、箍带、喷口内外环及螺钉/管线，保留原装甲机体。火箭有金属弹体、尾翼和当前尾焰，点火时尾焰加长；不画未来射击线或未来路径。弱档保留危险轮廓/主要材质，省部分小铆钉并缩短发射口喷焰，实弹危险尾焰保持。没有新增商业素材或依赖。

初稿允许反复双发，在第4章战况1让原24/49点8秒规划失败两条；97点诊断能找到路，不能称连续空间无解。修为一次双发后撤，保留首发两枚与4倍点火，最终原设置90条全过；这是明确的有限压制段，不靠无限驻炮封住后续补给。

取舍：正常首章/第4章能真实看到双发，第7轮以后强构筑可抢拆而0发，不锁血强制表演。光学自动操作者首章无敌比例13.96%→22.36%，其他两条基本不变；奖励和某些打法死亡时刻也改变。不把新机制或自动无伤当整体难度/长期耐玩完成，继续真人检验。音频未新增或试听。
