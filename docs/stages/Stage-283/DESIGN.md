# Stage283：拾取后点图强化与副组件组合进化

用户实测再次反馈“还是没看出来收集了一堆配件有什么用”。仅改善材料回执和未来树不足以解决问题：普通材料必须主动打开科技树才能付费转成武器，主循环缺少可见结果。本轮将材料够用后的图片装配作为主流程，完整树用于路线查看和主动规划。

每次真实收集材料后，若有可支付的科技，自动暂停战斗，显示最多三张大图片卡。卡内展示原攻击资产图标、攻击示意、真实效果及真实材料费用；点一张即支付、追加能力并恢复战斗。可选“暂存材料继续”或进入完整路线。自动选择不赠送材料、不代替玩家随机装配、不丢弃旧武器。首个提示不设冷却，后续装配间隔至少15秒、暂存后20秒，并要求新材料。光甲和维修仍为即时补给，不能伪装成付费选择。

支付后HUD优先显示实际追加/精校回执2.8秒，不能继续显示刚支付前的“材料入仓”。精校显示同系100%→120%等实际变化；新科技依自身真实攻击示意区分。菜单直接说明“拾取材料 · 点图强化”。前期图片会优先提供新能力，追踪目标的下一前驱优先；长期已装能力仍能用实际材料精校。

新选择专项必须直接运行真实FlightRuntime、正常击杀和拾取，不通过旧测试的暂存操作绕过新流程：验证三起手自动出现/冻结/一次支付/重复点击拒绝/旧火力保留，90秒仅点击实际弹出的图片而不访问科技树，验证连续实际强化。旧手动树回归通过真实“暂存材料继续”操作保留原覆盖范围，明确不是生产开关。

目标：把六个早期末端配件变成有未来的构筑分支，补真实强科技，保留所有已装火力。当前六分支是可选叶，已有原科技链不能改成强制必须购买副组件。

新增六个候选进化，每个必须同时拥有本分支配件和另一科技，实际材料支付后安装：蜂巢爆星（蜂巢副炮+爆裂弹仓）、磁钉雷网（磁钉阵列+连锁电桥）、电浆星核（巡航雷球+灼热透镜）、极光护航（护航电极+棱镜折返）、天穹猎镜（追光镜+猎隼线圈）、光刃回响（回旋光刃+反弹弹芯）。同系继承已有副组件二选一，三系进化可以混装，不与旧终极另设互斥。

六种追加攻击分别为双爆弹、三目标雷链、追踪爆裂灼烧球、双极索敌光束、三路蓄能优先光束、三枚真实出返飞刃；旧攻击、计时和基础参数不替换。使用现有原创机械/爆炸资源，弹体与开火有实战识别，不宣称新增六套精细原画。敌弹危险芯最后绘制。参数集中在evolutions.ts，伤害参数和预览同源；同一飞刃对同敌只命中一次，有限转弯/寿命，拦弹不刷收益。

第四页“组件进化”以图示双前驱AND、两种进化结果、缺少前驱/费用/互斥状态展示未来能力；副组件页可直达其进化，点击前驱回到正确页面。只读预览不支付、不推进，必须防止预览偷偷补上已互斥的前驱。火力页显示真实进化参数，保留旧基础图和组合突破。
