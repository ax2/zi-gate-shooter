# Stage274 自由空战与配件组装

## 用户变更与边界

2026-10-22用户要求将数字门模式改为雷电式纵版空战。已确认：主角可在可玩区域二维移动；退出固定数字门/装备投放；击敌后各位置出现增益；随机配件组装、升级既有火力；图示科技树有多前驱及强科技；击杀/分数有额外回报；反弹、雷电、激光和多种敌攻。此前“仅画面底部/数字门主循环”被这条用户要求覆盖。总目标仍是足够内容、画面与体验，平台上架仍后置。

本轮选择独立flight规则和Canvas运行入口，避免对旧World数百处固定playerY做不完整替换。默认index切新版，canvas.html留历史模式；旧存档键不读取也不改写。不是两个模式同时验收，不声称旧成就/契约或Android/微信入口已迁移。Stage273未交付分支保留git stash与本地QA。

## 核心闭环

起始图片三选一（双翼炮/电弧发生器/聚焦激光），基础主炮一直保留。相对拖动、WASD/方向键可二维移动，速度600，命中核心12；手机无需把手指压在飞船上。空间为720×1280，HUD以外x32—688、y196—1198。自动开火，抬高飞船会改变实际枪口和前方覆盖范围，同时承担接近敌人的风险。

击毁敌机按击毁位置掉落弹芯/线圈/透镜；每四击杀至少一次组件掉落，普通随机概率36%，数量上限32。同类过量奖励合并，拾取才入仓，18秒离场；靠近155范围吸附。组件被追踪时，55%概率偏向仍缺的类型，不保证每次同种。分数300首次补给，此后门槛间距逐次增加150；奖励实体为双份组件，每第三次另加维修，不能只击杀便自动升科技。首领留下三系组件和维修，既有已装火力保留。

科技树包含18个功能节点、三系六层、实际前驱连线。节点同时检查全部前驱和全部组件，扣料原子化；无随机升级弹窗。点击图片看效果示意、实际功能、前驱图片、费用；可跳转前驱并追踪零件。已安装节点仍显示原功能，允许精校该系伤害+20%，费用递增。根节点前驱为飞船核心；后续有跨系前驱，所有节点可从核心到达，无环。

终层蜂群武库/超导风暴/日冕阵列是本局三选一，未选择的终层不能安装或追踪，原已装组件不移除。此限制来自首轮实测：全部18节点可同时安装时，约3分钟后三路线趋同；改成单一终极专精以保留最终战术差异。互斥是本轮设计选择，尚需真人反馈；没有声称长期耐玩性已解决。

## 实际技能与战斗

弹道：双翼斜射、边墙反弹和命中跳弹、轨道贯穿、每第四发主炮溅射、六发蜂群、终极追击弹幕。电磁：自动两敌电击、四敌连锁、优先蓄能射手、弹丸第三次命中释电、定时磁暴伤敌清近弹、终极双源无衰减。光学：三敌贯穿、左右分束、三次灼烧、双斜束边墙折返、八敌深穿、终极八束扇形日冕。原攻击都保留，组合不是简单替换旧武器。对敌有效伤害按来源记录，暂停和战绩可看真实贡献。

敌机包括直射机、冲锋机、三发扇炮、十向环射机、锁定激光机和旗舰。警示只在机体局部蓄能，不绘制未来弹路；激光提前0.65秒锁位置，开火后才显示真实有限危险线，可横移避开。敌机可见入场后才倒计时，不能刚进入画面就瞬发。首领三空域分别用环弹+瞄准扇射、左右双炮交叉、慢环弹+高速纵列，半血加速；击破换场景和编队，60秒入场，等待实际击破才进入下一区。

三空域机群分别横排推进、偏侧斜列突袭、双纵队重装封锁。敌生命仅按空域固定增量，不跟随玩家DPS。敌弹、友弹、敌数、掉落、特效均设上限；真实连续线段命中、受击无敌、角色死亡优先、同帧奖励不可复活。树/暂停/失焦冻结物理与输入；弱档只降绘制亮度和粒子，不改变战斗。

## 美术与技术选择

新增原创透明俯视飞船，原图实测1254×1254，运行图512×512；保留原始图、生成说明和可重复导出。外挂使用已有原创机械配件图，技能/掉落图片共享语义。场景、敌机、爆炸沿用项目原创图。爆炸九帧、局部火花、弧线闪烁、分光/折返光束和发动机脉动均实际绘制。敌弹和敌方开火束置于友方特效上层，HUD独立，不以大面积泛光遮危险。素材未获用户最终美术批准。
