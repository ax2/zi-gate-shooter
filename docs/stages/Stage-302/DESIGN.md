# Stage302 设计与关键取舍

## 实际战术

第二段交替磁雷循环用连锁雷库替代普通布雷艇行动。首段三主题的旧行动不变；舰炮双艇与棱盾主题保持，后续按循环交替，不同时挤入更多系统。雷库由1有限盾布雷核心+3真实电容组成，占4个旧敌人槽位；预算不足整组等待，不先出半组。

侧前双电容与后电容留出正面射击通道。电容位置是核心实际位置的连续偏移，敌机任意位置均可接近射击；没有提前画敌弹射线。击破任一电容可沿近距连接触发其他电容过载，实扣核心剩余护盾；直接集火也能耗完有限盾。拆掉电容本身不发整组材料，击破核心才投6线圈，必须飞近拾取。普通击杀和分数奖励继续。

## 候选参数

| 参数 | 候选值 / 作用 |
|---|---|
| 有限护盾 | 600×(1+关卡编号×0.2)，不按玩家DPS同比抬高 |
| 电容数量/HP/半径 | 3 / 44×(1+关卡编号×0.4) / 24 |
| 侧电容偏移 | X±105，Y+75；中电容Y−60，给前向主炮留通道 |
| 链网 / 普通雷爆区 | 同网175，普通雷105；不是全屏无差别爆炸 |
| 过载伤害 / 结构削盾 | 52×(1+关卡编号×0.4)，每个削初盾1/3并按剩余盾封顶 |
| 电容分数 | 每个10；断电清理不伪造击杀/分数 |
| 布雷 | 进入可攻击区域后首轮等待3.4秒，后续沿用1.8秒；普通布雷艇不变 |
| 时间 / 整组奖励 | 26秒 / 实体6线圈 |

所有数值候选，自动驾驶生存不代表真人难度签收。初始三前排方案在实测中挡主炮、迫使近身撞雷，已根据失败证据修订；不放宽核心胜负/未全拆强攻断言。

## 图像和反馈

复用原创布雷舰、金属雷壳、旧爆炸图、线圈图标，无新分发素材和依赖。蓝绿窄环与低透明实际电力连接区分电容与普通危险雷；击破用短电弧和实体爆光，不画预测攻击轨迹。电弧遵循旧Effect两端点契约与原220上限，弱档继续减辉光。危险弹最终绘制顺序不变。

顶部安全区显示3电容图/拆除数、真实有限盾/剩余时限、线圈×6，第三行y70避开材料栏；战场提示让位危险时目标仍可读。选择空域卡按实际encounter身份画单核心+三电容，不能因同为6份奖励就误画成双艇。未增加长说明面板或被动等待前驱锁。

## 边界和计量

结构削盾与武器实际护盾伤害分别记录，不把护盾数值算作武器DPS。递归链爆先标记破坏，死目标不可重复给分。核心击破/超时/死亡/首领入场关闭尚存电容，不给假击杀，不清掉已经射出的敌弹。精确26秒的致死保留普通击杀但不给行动奖励；满掉落池承诺投送，死亡后不得补发；重开清理。

本阶段不增加平台/上架/真机、登录/支付/广告等工作。长期内容和真人可理解性仍待持续验证。
