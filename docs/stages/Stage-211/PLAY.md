# Stage-211 试玩

固定入口 http://127.0.0.1:5178/ 。正在游戏时先返回主菜单，再手动刷新加载新版本。服务中断时运行项目根启动游戏.cmd或npm run play；不要另换端口。

可在成就→战术中追踪“先制拆炮”或“诱射反击”。首轮约51秒出现锁位哨机：蓄能时转火拆掉，或避过三发后击毁同一炮机。追踪不是达成的必要条件；游戏仍自动射击、横向移动。试另一技巧可重新出击，旧成就保存，本局战力重新成长。

本阶段没有增加成就数量或局外增伤，局部金属奖章用于解释已经达成和保存的结果。数值是试玩候选，真人长期体验待验证。详情见DESIGN.md和TEST_REPORT.md。
