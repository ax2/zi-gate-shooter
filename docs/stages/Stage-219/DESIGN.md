# Stage-219 章节追击编队

用户要求整局更多敌人、更刺激及章节差异。沿用单角色、累积火力和现有原创机械机体，增加后续章前半段追击，而非新增菜单系统或依玩家伤害抬血。

| 章节 | 新增追击 | 编排与取舍 |
| --- | --- | --- |
| 走廊（第4轮起） | 每章18轻机 | 0.5/18.5/28.5秒，每段两批三机，0.9秒后另一翼切入；适合群攻清场并转火 |
| 侧翼（第2轮起） | 每章6哨机、2盾卫、10轻机 | 0.5/14/26秒，左右双哨相隔1.2秒；仅开场配前盾与锁位三连，后两波普通哨机配轻机屏障；抢拆或避实弹再换边 |
| 重装（第3轮起） | 每章3盾卫、3装甲、6轻机 | 0.5/14/26秒，每段同翼前盾后扇炮，对翼轻机；优先后炮或用集中火力击穿 |

镜像与左右顺序沿用现有战况轮换；原敌阵、门、箱和奖励时间全部保留，第一章完全保持。普通血量/弹速/开火规则和26敌人/48敌弹预算保持。已有安全入场照常等待，不吞排队对象。仅开场双哨使用已有锁位三连，目标锁定入场位置，不追踪玩家，也不画提前弹路。强构筑可抢拆，旧武器不移除。

首波6.5秒会和10秒原攻势挤压，改为0.5秒；重装与侧翼后两段提至14/26秒，避免堆到原中段特殊阵列。全波前盾和全波三连都未通过保守无开火路线，保留失败结果；最终只开场配盾和三连，后两波使用轻机。没有放宽450ms逐目标观察或增加免伤。

初始候选参数仍待试玩。现有敌人可得正常击杀分，增加真实连杀反馈；无新货币或免费研发。整体长局变化、真人难度、音画爽感仍需继续，新增敌数不等于总目标完成。
