# Stage-225 开场接战 · 设计

针对每章初始巡逻被清掉后6–10秒等待，追加一组章别不同的敌阵。首章6.5/7.4秒两批共4轻机，位于右侧，原左侧8秒预定箱保留通道；后续走廊三批共5轻机＋1扇炮。侧翼新增1锁位哨机、2短刺冲锋、2屏机，短刺目标280/440，迫使先拆炮或避弹换位。重装新增2错时扇炮与2屏机，间隔0.9秒，可先拆一翼留缺口。新敌正常得分，没有额外经验币或新后台系统。

新组6.5–8.55秒排程，沿用原逐敌admit安全检查、0.45秒投送保护与可见蓄能、实际发射；保护中不能提前打掉。首章不投射手，保留操作学习。原全部敌阵/箱门/首领完全保持，按轮次固定耐久和弹速保持，不随DPS抬血，不删除已经发射的弹幕。即便有敌也可以优先接补给；保留射门时段和成长收益。

候选侧翼原先随战况多翻一次边，会改变后续锁位/行进关系，在90条无击杀观察路线中有两条无法找到通路。25/49/97格一致失败，未当作网格误差掩盖。最终侧翼只随种子镜像，所有战况保持一致开场方向，保留同样人数/招式/时间；原失败路线复核通过后重跑完整90条。不是取消攻击或放宽反应约束。

画面沿用已存在的原创机械轻机、锁位转炮和重炮，以及对应实际开火动作/实弹；显示一次开场战术名与行动提示。不绘制未来敌弹轨迹，不用换色冒充新敌种。此轮新增章别战斗组合，不宣称新增机体类型或解决全部无尽重复。候选数值仍需真人试玩。
