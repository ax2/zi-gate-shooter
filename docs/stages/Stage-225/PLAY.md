# Stage-225 试玩

固定入口 http://127.0.0.1:5178/ ，服务停止后用项目“启动游戏.cmd”或npm run play，保持窗口运行。

每章约6.5秒接新的开场敌阵：首章右侧两批4轻机，后续走廊有机群藏炮；侧翼锁位哨机配两翼短刺，选择先拆炮还是避弹后转火；重装双炮错时扇射，可集中一翼开缺口。敌阵名称与打法在底部出现，未提前画射击轨迹。原8秒箱等补给保持，仍需打碎再拾取，门穿过才结算，旧武器持续叠加。

建议观察开场巡逻到下一波的连续性，以及侧翼/重装不同的转火需求。自动对照与90无击杀路线已完成，真人难度尚待试玩。冻结build/playable/Stage-225含完整资源，node build/playable/Stage-225/serve.mjs可启动备用5308（本轮未启动）。
