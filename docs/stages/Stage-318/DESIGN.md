# Stage318 交互与边界

机库所选武器进入独立试射页，上方五级路线，三种靶阵；左当前整机，右试装武器到其现有槽或同类第1槽。显示槽位变化与当前/试装等级，两栏使用固定种子及相同靶机，5秒实际攻击、1秒结果展示循环。未实有前驱不会自动激活组合；未购买条件清楚标示。预览不购买、不入仓、不掉金币/成就。

直接用FlightWorld固定靶场工厂抑制自然生成，三高耐久无射击靶机；相同HP/半径/漂移/时间。来源标记、判定、伤害、挂载动画、真实弹体和特效复用，不复制一套攻击公式。统计是整机命中结果，受距离/排列影响，不能当无限伤害或通用DPS。

页面支持暂停/重播、失焦暂停、Esc返回原机库、声音开关。正式World/随机数/资产冻结，双训练World单独固定步进与循环销毁，不持久化。既有素材复用，不称新增原画。
