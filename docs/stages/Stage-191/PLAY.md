# Stage-191 试玩

固定入口：http://127.0.0.1:5178/ 。刷新进入新局。

按原玩法打碎并拾取装备箱；获得研发点时先选升级路线，回到战斗后留意装备回执。它会显示具体武器、T级/弹数/贯穿/跳电变化，以及领取当时的常态全弹直伤前后。新武器是从0新增，旧枪继续开火；同武器连续升级会合并显示。重复装备只转充能，不冒充新武器。

首领战利品或契约选择已有配件，也会收到实际T级或精校前后的回执。原战场告警、数字门、箱子、敌机与敌弹优先；没有安全位置时回执等候。暂停不吃掉阅读时间，新局不带入旧提示。当前火力页仍显示即时参数，回执的“领取时”值不会把之后的全局增益算回旧装备。

开发验证页tools/visual-fixtures/equipment-receipt.html仅在临时Vite5255使用；正常输入/奖励、隔离内存存档、加速虚拟时钟，无World注入。固定可玩包不含它。数值不是命中率修正后的实测DPS，真实爽感/多局理解/低端设备性能仍未签收。


r2补充：底部武器说明按当前构筑跳数显示。例如T2电弧获得导电线圈后，技能回执与底部均为3跳。最终本地完整目录build/playable/Stage-191-r2，备用serve端口5274（本轮未独立启动）；固定5178已验证。初版Stage-191/mdA仅作为历史候选保留。
