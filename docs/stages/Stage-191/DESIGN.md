# Stage-191 装备成长回执

目的：解决“拿到强化后不知道哪件武器变强了、强多少”的具体反馈缺口。本轮只改表现层，不改变World、效果事件、参数、成长时机、敌人、奖励或存档。原源码20e1ef6作为运行对照，原始交接仍是历史证据而非本轮新授权。

## 实际数据

活跃拾取存在时，在World固定步前捕获所有已持有武器的阶段/精校与当前builtWeapon配置，在步后只比较所有权、阶段或精校是否实际变化。仅全局火力变动、超载开始、重复装备转充能不产生“装备升阶”回执。首领与契约领奖也以领取前/后实际结果捕获；拒绝的领取不入队。技能节点自己安装的武器仍沿用既有技能选择回执，不重复当作拾取播报。

标题显示新增/T1→T2/精校0→1与该武器主要机制变化：弹量、贯穿、范围或跳数。副行显示“领取时常态全弹直伤/秒 A→B”，采用当时永久火力×每轮直伤之和×轮速，排除超载、跳电/贯穿二次目标/溅射/组合与命中率，不叫实测DPS。延期播报仍保留领取瞬间的数值，明确“领取时”，不把后来获得的全局火力归因于旧装备。即时参数仍在当前火力页。

## 展示与调度

仍使用既有两行安全阅读区与遮挡检查，不新增面板、菜单或经济系统。侧边条及标题用武器既有色系区分，保留当前武器的真实挂载/弹道/声音与升级闪光。没有为了展示回执扩大或掩盖危险。

队列最多五个未读武器条目（当前总武器数五），同武器未读变化保留最早before/最新after合并。当前正在读的同武器收到新升级也合并并刷新阅读窗口。新条目3.2秒可见阅读时间；技能/组合提示优先，打断时保留剩余阅读时间而非从头重播；真正的新收益才重置3.2秒。原地无法安全显示时暂停耗时，底部战场告警也优先。队列不授予任何数值或奖励，死亡不画在战斗层，新局清空。

捕获仅在可能实际拾取的帧或明确领奖动作周围，不在每一帧无条件克隆World；数据是小规模配置快照，没有完整World副本/新战斗框架。原效果与声音处理照常进行，只避免旧泛化“升至T2”与新增明细重复播报。重复转充能的提示保持。

## 取舍与后续

保留补播可避免研发/组合覆盖装备所得，但会产生几秒延迟；正常样本的等待峰值需记录并继续用真人反馈压缩，不通过丢消息或盖住敌弹“解决”。初期手机截图显示领取时穿甲直伤50而当前全局火力已+30%，因此补上领取时标签，避免误认当前参数。未把更多提示等同于更爽，真人理解程度与长期干扰感仍须试玩。


## 确认后的强化脉冲

发现原0.45秒薄环按墙钟过期，读技能菜单会消耗其可见时间。改为战斗模拟时间0.45秒，成功确认技能时也触发一次。选项界面/暂停不消耗，恢复后正常展开/淡出；新局清空。保留原半径48→148、细线透明与敌弹优先绘制层，不增加不透明屏幕闪白或新粒子池。实际菜单等待一秒后剩余仍0.45，恢复0.2秒后仍可见，再推进一秒归零，见pulse-menu-resume/pulse-expired及对应实际截图。


r2补充：底部武器引导读取当前builtWeapon的targets/chainHops，消除技能树加跳后低报。无构筑的默认调用不变，实际射击数据不改。菜单升级回执与当前能力说明需一致。
