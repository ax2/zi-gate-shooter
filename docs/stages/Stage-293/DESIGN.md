# Stage293：让零件的两种作用在一个入口里可见

用户要求是实际玩时能知道捡了什么、变强在哪，不是继续叠科技数量。本轮不增加系统、不重做战斗数值。

1. 战斗材料栏变为有边框且有“材料 → 点这里装配”的常驻按钮，直接进入现有大图片强化页，省去找科技树/切页。
2. 图片页上部用三种真实材料图 → 飞船主炮示意，展示实际弹路×单弹伤害、离下一次加弹路还差多少，以及累计拾取带来的齐射增幅。齐射百分比与相同校准系数下的未回收主炮相比，包含弹数变化，只描述主炮一轮标称伤害，不伪装成全武器DPS或实战命中收益。
3. 下面图片对应真实付费追加/改装。费用改为库存/所需。库存不足也能进入看三张可达配方，但不会出现安装按钮或绕过前驱/互斥。已有钱时沿用自动强化的真实候选，不另外创造免费奖励。
4. 自动强化和手动材料入口共用一个画面；自动节奏保持。手动浏览/返回不能重置自动提示的计时器，暂停进入仍返回暂停。装配才扣库存，累计回收和原武器保留。
5. 保留原科技树、路线入口和本局配方。光甲/维修仍即时生效，不计入材料强化。

取舍：先缩短从材料到实战装备的交互链，并把累计作用常驻，不用更多文字教学/奖励币种/免费自动选择来掩盖问题。图示理解度仍以用户试玩为准。
