# Stage-176 双盾哨阵

试玩：[火力突围](http://127.0.0.1:5178/)。服务停止后运行 npm run play，保持服务窗口运行。

从第五轮开始，在侧翼章（R5/8/11……）的44.5秒遇到双盾哨阵：左右前盾驻守、后排哨机蓄能射击，1.2秒后中路投送中继。前盾与后哨使用原精细机械机体，属于编队变化，不算新增敌种。

- 可集中强攻一翼；盾卫照常在蓄能与开火时暴露弱点。
- 也可转火中路中继：实际击破后，300范围内当前有效射手停火1.5秒，盾卫同时失去护盾减伤。已发出的敌弹仍需躲避，停火敌人也仍会碰撞。
- 这一组四台射手固定为本轮原基础生命的4倍，所有玩家相同；旧枪、成长、精校、雷电/激光/磁暴等能力全部保留。不会按玩家DPS即时加血。
- 盾卫驻守4.5秒后继续下移，后哨沿用10秒撤离；本组总数仍5，轻机换盾卫增加总HP与基础分，原补给/门时刻保留。

本轮实测自动正常成长可清掉5台，但确实有敌弹穿过角色区域；持续压一翼的对照多出敌弹且少40分。不能据此认定真人难度或最佳策略。现有配方、检验和跨局成就继续保留；不加新货币、局外增伤或平台接入。

完整可玩目录build/playable/Stage-176保留46构建资源，serve.mjs配置5258（本轮仅配置，未另启冻结服务器）；不打ZIP。详细数据和限制见TEST_REPORT.md。
