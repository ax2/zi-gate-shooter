# Stage267 构筑检验预定

沿用六配方与已有研究契约，不新建币种或认证判据。玩家在配方页主动设目标、预定；预定目标固定、可取消，换目标即取消，每次预定只接取一次。需要再次挑战时可主动重新预定，仍受每章一个契约限制，不自动循环刷奖励。预定只在当前运行中保留；回主页、死亡、重开清除，不写存档。认证仍使用既有持久化certifiedBuilds。

真正的canAcceptContract是准入依据：战斗中、活着、章内含40秒窗口、没有当前契约/待领奖、已具备该检验资格。错窗口等下一章；磁暴还需雷电3与磁暴精研。手动另接契约优先，不覆盖；预定后手动接同一目标视为兑现，不在之后再自动补一次。接取后暂停展示高亮卡片，继续后才推进计时与敌阵。

不在解锁或预定时给认证/充能。契约真实30秒内触发计数，既有最多6组验证敌阵、入场安全与胜败规则保持；成功后主动选100充能或已有配件强化。配方页显示已获得认证，与本局未成形/已触发数据分开。战后页面只读，不能预定。

参数、窗口与奖励沿用原规则，不宣称新美术或新战斗数值平衡完成。未预定和已取消时不自动加敌、不接契约。
