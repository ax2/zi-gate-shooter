# Stage-32 玩法差异候选（2026-10-13）

用户反馈：武器、敌人和关卡单一。目标由细节打磨转为增加真实战术差异，保持单角色、横移自动射击、打箱/打门再兑现奖励。

武器保持T1～T3成长，增加速射/霰射/穿甲三种射击机制。首轮16秒出现成对武器箱，射碎后拾取才换装，同排只领取一种；普通升阶箱延续当前武器。速射精确、霰射覆盖宽但远距分散、穿甲可穿2～3个敌人但对单体节奏较慢。门和装备箱仍吸收弹丸，不能用穿甲绕过奖励取舍。类型与阶数分别显示，所有参数待试玩。

三种波次结构按轮次轮换：突围走廊（交替小队）、侧翼夹击（横移编队与斜冲）、重装封锁（装甲/精英与扇面射击）。沿用原创机体资产与循环场景，通过实际行为、组合、时间和奖励路线体现关卡差异，不把换色算新敌人。新攻击先有实际路径提示；安全路线预测与实时运动使用同一个行为实现。

验收：三种弹道有可复现差异；穿甲不重复命中同敌人；箱碎不直接换装，选择兑现只一次；升阶不丢武器；三轮波次结构不同、正常成长可达、预算有界；实际手机尺寸/桌面画面显示武器和危险路径。既有存档兼容，无登录/经营/抽卡等新系统。

本阶段机制已实现并验证，具体证据见TEST_REPORT.md。正式新武器机体美术、数值平衡、人评、微信工具/双方设备与上架验收仍待完成。
