# Stage-240 强化提示排版

目标是看清真实成长：此前离子精研说明在手机实景伸到604px面板外，碰撞/避让仍只预留面板，文字和规则边界不一致。修复两类共用战斗文案：短时战术通知、真实升级/配方/装备回执。短说明仍单行；长说明保留每个字符/数值，优先在空格/间隔点/中文分隔符之后折为两行，按两行实际宽度挑较平衡的分段，必要时降字号。没有省略号、横向压缩或伪造伤害；标题单独适配。

文字内宽560逻辑像素，对604px面板各留22px。上区仍104高，下区回执仍88高、战术通知仍94高；两行详情在上区61/85、下区52/75处居中绘制，标题在26/23处。短回执保留原字号/位置，长详情优先保留上区23/下区22，实际正常样本不得小于18。每次文案或上/下区切换才重新测宽，缓存仅最后一条，避免逐帧反复测量。实际Canvas字体测宽；没有真实字宽的headless shim使用保守字符上界，只用于规则测试，不能据此签收实际画面。

内容存储、World、触发规则、回执队列/隐藏读时与combatPanelClear边界都保持。新诊断combatCopy只读记录实际绘制行/字号/宽度/位置，不能用于给奖励。极端外部长输入也保留全文缩至两行，其字号不作为游戏内容可读性承诺；正常实际内容通过18字号下限与实际手机/桌面证据单独验证。原技能树完整数值仍是构筑查看入口。

权衡：不新增通知历史页、不拉高面板占用战场。长说明多占一行但保持原面板和现有读时，局内判断仍以敌体/已发实弹优先。整体目标仍包括敌阵/多章节奏、酷炫效果和长期成长，本轮不宣称解决Stage239实得奖励下降、真人难度或低端性能。
