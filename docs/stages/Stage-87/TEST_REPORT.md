# Stage-87 爆裂炮（进行中）

新增第4武器，慢速集中炮弹命中敌人后造成邻近敌人溅射。范围伤害不打门、不打箱、不隔着成长目标引爆；直击与溅射均遵守盾卫减伤。炮弹发射时保存范围，换装不改变在途炮弹。需要独立三阶机体和炮弹/爆炸/声音表现后进入正式武器箱。
