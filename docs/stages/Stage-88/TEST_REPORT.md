# Stage-88 电弧炮（进行中）

第5武器：直击后依距离顺序连锁邻近敌人，每跳衰减，禁止重复命中/链到成长目标/屏外。闭合盾卫截断连锁。制作三阶线圈炮机体、局部电弧和独立声音，箱子仍需打碎再拾取。所有数值及美术是候选。

## 实现
- 第5武器arc：射速2.5，直击16/22/28，追加1/2/3跳，每跳160像素范围、伤害乘0.65。按距离最近优先、同距离按对象ID决定，visited保证不重复；成长目标/屏外敌人不参与。
- 闭合盾卫承受减伤并截断后续连锁，展开时可以继续；无链式事件递归。连锁次数随炮弹保存。
- 第4轮起第一章武器箱电弧/霰射，第6轮起第三章速射/电弧；第二章保持爆裂/穿甲。T3箱仍提供保留当前武器，正常击碎拾取流程保持。
- 原创三阶线圈机体，2172×724透明源图；为抵消原图三格中心轴偏移，导出窗口x偏移58/0/-58，边界检查通过，运行图768×256/220808字节。源图和完整prompt保留，候选未最终签收。
- 局部绿色电弧、白芯与低亮外光，最多12条、0.16秒寿命，暂停冻结/重开清空；弱档省去外光。电弧在危险文字和敌弹之下。独立电击发射/跳电音接入。

## 验证与发现
- 网页类型检查/构建通过（228ms）。专项arc/blast/explosion-render共66项通过（2.60秒），覆盖跳电衰减/屏外及箱门隔离/盾卫截断/12条上限/暂停与重开。
- 五武器正常成长各20分钟规则模拟最终5项通过（17.43秒）。过程中失败如实保留：偏好新武器的操作者先拒绝其他升阶箱，又会在击碎后转向另一箱错过拾取。修改测试操作者接受升阶并优先已有掉落物，没有改生产奖励规则或放宽20秒T2/65秒T3时限。
- 长局原断言还假设每次升级前只打碎一个箱，实际可合法打碎同排两箱。改为验证阶段依次2/3、每次升级前存在对应阶段破箱及严格时间顺序；World中升阶必须对应拾取计数+1的不变量仍保留。
