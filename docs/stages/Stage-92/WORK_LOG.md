# Stage-92 超载持续表现（进行中）
发现：超载具有6秒伤害强化，但持续表现主要依赖HUD，启动环结束后机体不够明显。增加有界局部尾流，弱档保留简化反馈，不修改成长或伤害数值。

## 实现与验证
- 超载期间机体两侧局部金色尾流，末0.6秒淡出；标准档含白芯/流动短纹，弱档两条细线，绘制在机体和危险之前。使用模拟时间，暂停冻结，不新增持久对象。
- 首张390×844截图发现尾流被机体挡住，已移至外缘；保留失败与修订截图。修订手机标准和1280×720桌面弱档均在启动2.4秒后截取，可见持续两侧反馈，未遮住弹道/HUD。
- 夹具预置T3储能70及掉落物，通过生产拾取结算激活超载；并非自然长局。
- 首次测试58通过1失败，原因标准档描边两层，测试误计为两次；修正标准/弱档计数后59项通过。位置调整后再跑59项通过，网页类型检查/构建通过（198ms）。覆盖无超载不画、暂停冻结、结束和重开清除。
- 真人动态观感、长局重复度仍未验收，目标继续。没有平台发布或设备调试。
