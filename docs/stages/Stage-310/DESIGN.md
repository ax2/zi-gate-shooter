# Stage310 设计：密集战利图示与真实数量

LootCallouts仅保存上一帧活跃ID组，完整连接距离入组112/拆分136逻辑像素，避免传递式长链横跨战场。新局清空历史；丢失、过期、已回收物立即退出；分组只改变显示，不写World、RNG、材料、价格、伤害、坐标或拾取半径。独立物沿用完整旧表现。

近邻物用已有原创材料/开放机械舱/光甲图示缩绘，隐藏重复名称；紧凑汇总按五类真实amount求和，数量表示物资份数，光甲仍刷新6秒。物体与单条中性细引线关联原位物体，不是未来攻击预告。面板58高、每内容48宽加16边距，优先近处，普通最多8/弱档4，尝试上下左右及对角；x12–708/y206–1195。避开实际物体、其他提示、当前机体及真实挂载包围框、敌机、实弹和有效激光，危险最后绘制。无清晰位置则不显示面板，保留紧凑实物和各自份数。提示无点击区，不抢移动/拾取输入。

修复维修amount>1始终只回1的数量兑现漏洞：hp=min(maxHp,hp+amount)，特效与回执写实际回复；满血仍消耗实体并显示满，不额外送材料。普通和分数来源、满池合并、过期/死亡都分别验证。此项有意改变多个维修份数的回复，不能将全部战斗逻辑说成未变。

候选阈值待真人试玩；Native离屏可检查原Runtime像素、世界冻结与真实内容，但不是浏览器事件/控制台、声音、真实设备FPS或趣味签收。
