# 持续叠加成长：本轮修订

用户实玩反馈优先于旧版验收：充能意义不清、看不到持续升级和参数、换装可能变弱、整体单调。数量与自动测试通过不是体验完成。

## 已实现
- 已取得的五类武器独立计时、共同开火；新武器不移除旧武器。机体外观暂仍显示最近领取的武器。重复箱提供充能，不生成重复武器实例。
- 基础火力门累积至+100%后奖励转充能。每100充能增加本局永久火力10个百分点，触发/刷新6秒伤害×1.35超载，余数保留；超载中继续充能也不吞奖励。永久仅指本局，重开清空。
- 第3次突破追加激光：每3秒一道，基础伤害30，继承永久/超载加成，最多贯穿4敌；箱、门与闭盾挡住射线。
- 第5次突破追加折射：速射弹命中后向180范围内最近邻敌追加60%伤害，不递归、不充能箱门；闭盾原目标截断。电弧武器继续独立开火，与上述能力共存。
- HUD说明充能用途、武器叠加数。暂停菜单的当前参数由生产配置与实际成长读取，显示射速、弹数、伤害、穿透/跳电/爆炸范围和附加能力。
- 保留击碎后拾取、穿门才结算、同排只领一种奖励、成长不带入下一局。

## 候选数值与证据
所有数值仍待试玩调整。种子1337规则操作者首个突破93.967秒，激光144.283秒，折射193.633秒；20分钟43次突破，仅取得速射+霰射（操作者固定偏好）。这不代表真人获得频率或自然局必然收齐五种。

## 未完成的后续重点
1. 奖励节奏：首领/精英明确奖励、阶段能力进化选择、重复奖励的价值呈现。
2. 组合辨识度：组合机体、辅助发射点、独立激光/折射声音与升级演出，不能只堆白光。
3. 叠加后敌群清理更快，需要战斗组合与节奏调整，不能即时等比例抬血抵消升级。
4. 更深能力进化、长局目标与奖励大节点。目前只是成长重构第一版，不宣称已解决全部单调问题。
