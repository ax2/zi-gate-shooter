# Stage289：拾取立即强化主炮

问题证据：材料只加库存，Runtime下一次选卡前没有任何火力变化；bank又延后20秒。用户“收集一堆配件没用”的反馈未解决，不能只靠新首领/更多文字说明。

本轮规则：所有真实拾取的弹芯/线圈/透镜，每份永久增强本局基础主炮（初始/造物/库存注入不算）。累计3份主炮1→2路，9份2→3路，之后维持三路并按1+0.05*log2(1+份数)提高每发伤害；炮口有限，后期重点仍是多前驱组件/组合进化。材料同时保留在库存用于图示选择；装配材料被消费不会降低拾取成长，其他武器不移除。光甲/维修不算零件成长。奖励落地未拾取、过期、死亡、暂停/预览不得成长。参数候选，必须后续真人试玩。

交互：主炮真实机械枪管/对应真实弹路从一到三路，每份拾取显示主炮伤害变化，跨节点显著回执/沿用upgrade声音与局部装配火花，主炮UI常驻当前路数和下一节点进度；图示选择前明确显示已生效的主炮变化，避免误以为暂存取消强化。用既有原创模块和主角素材，无新素材依赖/抽卡/额外货币。
