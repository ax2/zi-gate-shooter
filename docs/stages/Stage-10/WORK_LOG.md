# Stage-10 / 爆炸动画候选

2026-10-11，起点5255e4c。当前爆炸只有props单帧缩放淡出；本阶段制作一张原创候选爆炸图集，检查真实画面中火球/碎片/烟尘层次，同时保证数字、危险与HUD处于上层。不新增玩法系统，不改变判定/奖励/模拟时间。

先使用内置imagegen生成3×3九帧透明图集候选，检查分帧/透明/材质后才决定接入。候选不是正式美术批准，原素材保留。既有爆炸上限4、弱档降强度保留；纹理解码预算按RGBA计算，不拿PNG大小当显存。实际移动画面与动态帧序另验，不以生成图代替游戏验收。

## 发现与修改

生成原图1280×1280真实透明，九格显著alpha没有触及3px边界。保留源图，以sharp技术裁格到256×256、合并768×768运行页，149698字节，解码2.25MiB。内置imagegen提示词全文与来源单独登记，不声称用户批准。运行时按已有事件寿命顺序播放九帧并淡出，标准0.9/弱0.5最大透明度，同屏最多4个；新增只读blasts计数便于捕捉短暂效果。旧props仍保留，其余规则/碰撞/音频不变。

新增三项渲染回归。第一轮测试夹具错误调用不存在的resume、误写初始门+5%，3项失败；检查真实API与配置后改用继续按钮触摸，按实际奖励文本查找，3项通过。该失败属于测试构造错误，未记为产品缺陷。完整12文件67项通过97.86秒，网页构建/类型检查通过。

## 画面与验证

浏览器实际APK网页产物普通开局第一只敌人死在屏幕顶端外，1.2秒截图不可证明爆炸观感。随后正常走位，在28.633秒拍到可见箱碎火球、T2掉落和双门数字；20分、3HP、T1+30%，未注入世界状态。手机尺寸另开普通局4.033秒、10分、3HP，暂停成功，无console warn/error。手机网页不是原生机验收。

显式重叠夹具使用同一CanvasRuntime与真实纹理，布置四爆炸、门、敌弹与冲锋预警；桌面1280×720、手机390×844请求（PNG390×843）拍标准/弱档。门深色面板遮住局部烟火，数字仍可辨；第三处火球中心的敌弹箭头与左侧危险通道仍可见。夹具冻结在第8步，不证明普通局路线可达/动态爽感/设备性能。QA页关闭、临时视口复原。
