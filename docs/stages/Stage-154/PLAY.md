# Stage-154 电光连锁试玩

固定入口 http://127.0.0.1:5178/ ，刷新后开始新局。服务停止时双击“启动游戏.cmd”，保持窗口运行。

光学路线三节点后，第一次光学精调成为“连锁蓝图”；搭配已拥有的T2及以上电弧炮，自动组合电光连锁。可以先取导电线圈，再走光学，并利用首领奖励升级电弧；也可以走纯光学，主动收集电弧箱的掉落。打碎不等于取得，旧武器和光束全部保留。

激光最多储备一束光链，下一次有效主束或电弧命中时向附近其他敌人追加最多两跳，范围220，伤害为储备激光的80%和64%。没有邻敌就保留；不需额外按键。角色上方小菱形/暂停“当前火力”显示待发状态，“组合配方”显示缺少条件。

第二轮后可在挑战契约里选择已成型的电光连锁检验：30秒内实际跳伤4次，完成后选已有配件升级或充能。原成就“实战工程师”适用于它，不另加刷量成就。

正常360秒两种策略已解锁并产生实际跳伤；高火力下触发仍偏疏，属于群敌组合技，不能当单体首领增伤承诺。真人乐趣、听感和实时长局性能未验收。冻结目录 build/playable/Stage-154 保留完整文件，可用 node serve.mjs 在5235运行；日常仍使用5178，本轮未启动5235。
