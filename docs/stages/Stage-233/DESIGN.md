# Stage-233 开场追兵接战

来源：正常20分钟审计发现，强化后的后续章节仍在开头沿用单敌稀疏巡逻，部分1～2.35秒没有任何目标。无敌但有门箱的时段不能直接算无聊空场，本轮按两种指标分开处理。

第二章起在2.6、4.8秒追加两批，共6个目标；每个目标再错开0.28秒或0.35+0.28秒进入，避免整批尚未出现就被同一发爆炸抹掉。沿既有战况翻边，保留首章全部内容和后续所有旧目标/补给时点。

- 走廊：两组左右交替轻机，后组中间加入折返冲锋，清一翼后有追击威胁。
- 侧翼：两次外侧短刺＋固定航道轻机；冲锋只切到280/440。轻机不摆动，给现有猎袭汇合后留较宽外侧退路。
- 重装：锚炮＋后继横移炮，轻机在另一侧错时到来。锚炮沿原0.1秒开火准备；横移炮等待1秒再进入原0.6秒蓄能，防止延迟入场后与旧6.5秒炮组同步封路。

全部沿普通敌人HP、得分与行为，不随玩家伤害追涨耐久；原护盖0.45秒、共享预测/真实碰撞和接纳预算保持。复用现有机械机体/实际炮口蓄能、冲锋姿态与弹丸，不画未来射击线，不增加屏幕光墙或新经济系统。箱破再拾取、门穿过结算、互斥选择、武器叠加均保留。

取舍：本轮补接战连续性，保留玩家提前拆炮的收益；不锁血强制演招。并未观察到第二章起无避险策略更早死亡，不能用额外6人或自动无伤认定整体难度已足够。真人长期趣味和更大章节差异继续。
