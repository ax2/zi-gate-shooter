# Stage257 超载协议

第12次公共充能进化后，数值之外再增加第16次突破的本局协议二选一。不另加货币，不取代武器，不减已有能力，不消耗技能点；可在升级选择或暂停→当前火力→技能树中打开，允许延期，选定本局锁定。重开清空。

|协议|真实行为|取舍|
|---|---|---|
|轨道雷枪|超载期间每1.5秒追加直线90基础伤害，最多贯穿3敌，宽度半径12|需横移对齐；箱门、闭盾、入场保护截断；可以伤害箱/充能门，但仍须拾取/穿过结算|
|环流电链|超载期间每1.5秒从近敌起跳，首击640范围/60基础伤害，后续260范围，最多3敌，后跳每次×80%|覆盖分散敌人；不打箱门，闭盾会截链；首击较雷枪弱，不能反复跳同敌|

两者伤害乘本局常驻火力和原超载1.35，不再乘一次临时射速（协议固定1.5秒），超载原所有武器射速1.25与伤害1.35保持。无敌人/首领耐久调整，不生成敌方预告线、不回收敌弹。每次协议触发只作一组有限攻击，不递归触发光链/离子等派生；实际扣血单独入超载协议贡献，过杀/箱门/保护期不计伤害贡献。

选择后若正在超载，下一正常战斗步立即追加一发；之后相邻触发间隔1.5秒。充能刷新超载不把协议时钟重置，避免连续充能刷首发。超载结束时清准备计时，下一次超载可立即发首发。首领入场/恢复不射击、清准备计时；暂停、选择和失焦沿既有时间暂停处理；死亡与首领已击破不追加。

视觉：雷枪用独立金色双导轨、细白芯/蓝色电离层、沿已经发出的线段移动的感应卡箍与炮口弧圈，弱档减少光晕和卡箍；电链复用已有精细折线电弧，与雷枪直线可辨。沿用既有16条束/12条电弧的上限，不增加纹理资源；金属机甲和敌机仍用项目原创资产，不能把本轮过程图当新美术批准。

升级页与技能树各增加一个明确的协议按钮，选择页按真实常驻加成显示首击伤害、触发条件、免费/本局锁定以及各自限制。装载回执使用原可排队的组合反馈，不把选择页阅读时间算作战斗。当前火力下方入口标为技能/协议，战斗HUD显示正在超载的协议名；贡献页单列真实协议扣血。

所有数值是候选。协议是额外长期节点，未宣称解决整体难度和耐玩性，也未把单一自动策略结果当路线强度排名。
