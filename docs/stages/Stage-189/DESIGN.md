# Stage-189 火控中继编队

现有事实：原重装55.5秒两装甲+轻机，在三种构筑各600秒的R3/R6样本均0发弹；变成纯耐久数字也不会产生明确目标优先级。本轮给这三单位加入可断供的攻击协同，保留七类非首领家族和所有已获得武器。

## 正常入口与规则
R3/6/9...55.5秒，替换原两装甲与一轻机：同侧纵列440/550与440/350、中继210/450，章节镜像时整体镜像。三机整体检查敌人预算和无击杀可达预测，通过才接纳，不出半队再突然增幅。没有槽位或不能证明安全时整组重试；不删除已有危险来制造路线。

驻守4.5秒后正常推进，装甲y>=600停止发射，中继也会离场，不无限拖住首领。原0.45秒投送保护保留。装甲固定原轮次HP×6，中继固定144HP；均与玩家DPS、武器和选择无关。0.15秒启动、完整1秒局部蓄能，供能源仍有效/同组且320范围内时三向扇射（原100/280速度及轮次倍率），恢复1.1秒；断供则单线、恢复3.2秒。沿用300半径/1.5秒真实EMP，中断当前蓄能，旧弹继续危险；恢复时只剩单线。

先断供减少实弹，穿甲纵列可直接清炮，外侧也能绕行；不削已有弹道/派生效果来强制等敌人表演。原击破总基础分110→135，额外25来自轻机改为中继；敌数仍3、箱门时刻/领取规则不变。为避免详细机体叠图，仅紧随56秒盾卫横向移到620（镜像100）；其排程时刻/耐久/奖励及其他排程字段保持。未增加额外货币、成就或局外战力。

## 表现与可读性
沿用项目已有原创装甲和中继详细贴图。装甲增加接收线圈、金属天线与有限驻炮脚；中继增加两片机械折叠发射盘。状态端口由实际连结数量控制，停火转青色，断供熄灭；不以发光方块替代主资产，不增加远程连接线或未来敌弹轨迹。源标签显示实际增幅台数；纵列拉开200间距，名牌居于各自血条上方；蓄能/停火/单线状态不盖住另一机体，后盾横向间隔180。只画本地蓄能和已发出的红白危险弹，保留原危险最上层。

## 取舍与证据边界
最初3倍装甲/48HP源仍常在0.6–0.9秒清掉；一条旧补给箱并存路线无反应余量。保留失败后修为6倍/144HP源/1秒蓄能，18个无击杀延迟反应镜像窗口HP3。现代精研正常策略显示光学/雷电的源先与枪先有真实发弹差异，弹道仍能快速清双炮。测试操作者有预测能力，真人压力/趣味/低端性能未验收。

最终布局还修正“只居中摆炮”带来的取舍消失：中继与炮列保持230横距，普通220跳链不能顺带跨越，近邻中继仍能EMP覆盖双炮；不削连锁和已有伤害。最终240相关/13炮阵行为复验与正常策略/18路径数据见TEST_REPORT。
