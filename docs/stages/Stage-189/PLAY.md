# Stage-189 火控中继编队

固定试玩：http://127.0.0.1:5178/ 。停止后运行“启动游戏.cmd”或npm run play，保持服务窗口。

第三轮起，每个重装章55.5秒会出现火控中继编队：一台带折叠发射盘的中继、两台装有接收器的纵列装甲。中继标签显示实际增幅台数；供能装甲会扇射并更快复射。只显示局部蓄能和已经发出的敌弹，没有未来射击轨迹。

可以选择：
- 先转火中继，触发1.5秒停火/打断蓄能；装甲恢复后改为单线。已发子弹仍需躲避。
- 用穿甲与已有组合打穿纵列，发挥直接清炮的构筑优势。
- 保持外侧通路绕行，等驻炮结束再争取后续箱门。

中继原金属主体加两片机械发射盘，装甲有接收线圈与驻守支脚；供能、蓄能、停火、断供单线在名牌显示。纵列名牌放在外侧，避免压住后机。两机4.5秒后推进离场，不拖无限循环。现有武器不削弱、不删除，箱门/奖励时刻与领取规则保留。

本段击杀基础分原110→135（轻机改为中继），没有额外货币或局外数值。固定耐久/时间为候选，需真人试玩调优；有界自动测试与脚本操作不等于难度/长期趣味验收。
