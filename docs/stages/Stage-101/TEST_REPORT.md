# Stage-101 武器覆盖对照

2026-10-14；基于0dd12ed后的生产代码，未修改游戏规则、资源或Stage-100试玩包。

## 方法与复现
运行 `npx esbuild tools/weapon-study.ts --bundle --platform=node --format=esm --outfile=build/qa/Stage-101/weapon-study.mjs`，然后 `node build/qa/Stage-101/weapon-study.mjs`。
共105组：5武器×3阶×7布局，每组600个固定步长（10秒），固定种子1337、玩家x360、零加成/无超载。调用真实World射击、子弹移动和连续碰撞；仅夹具清空关卡生成，重甲靶HP改为100000、速度0、攻击计时1000。含首次开火与飞行时间，不能直接当稳态DPS。无击杀收益/转火/敌弹/走位/盾卫/首领，不能推导正常关卡胜率。

## 判断与后续优先级
- 已验证机制定位：穿甲纵列最强；电弧能跨错位目标接力；爆裂能覆盖紧密横排。紧密横排电弧仅命中2靶：先连一侧后，另一侧超过160距离，这是最近邻单链规则的实际结果，不是全范围群伤。
- 平衡风险：爆裂在所有单体距离和紧密横排领先；霰射即使贴近靶也仅略超速射。不能据此宣称五武器已完成平衡。
- 下一轮先对照正常HP小怪的首杀延迟、过量伤害、移动中覆盖及真实武器箱选择，再确定爆裂直伤/溅射分配与霰射近距收益候选。不要只凭此高生命靶数据全面调伤害，也不要为证明某武器强而设计只利于它的关卡。
- 本阶段没有新增渲染截图、真人试玩、手机性能或上架测试。没有生产代码变更，因此不重复整套构建/20分钟渲染；此前Stage-100的249项共享回归与Stage-99静态20分钟证据仍对应当前生产运行时。
