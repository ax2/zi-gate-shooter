# Stage-188 斜射双路线技巧目标

固定试玩：http://127.0.0.1:5178/ 。停止后运行项目“启动游戏.cmd”或npm run play。

主界面→成就→战术→下一页，选择“先制拆炮”或“诱射反击”，再返回出击。第2/5/8...轮侧翼章会出现斜射哨机。原武器持续叠加，目标只是改变这次操作顺序：

- 先制拆炮：等护盖打开，在蓄能且第一发还没发出时击毁。只在待机/EMP中击破不算。
- 诱射反击：先移开原锁位、暂时错开炮机，三颗实际子弹全部安全通过后，再追上并击毁同一台。目标名牌显示避弹0/3至3/3可反击；入场至击毁期间受伤、提前击毁或未追上都不算，但下台仍可重试，不惩罚整局。

底部若有奖励或既有成就，目标名牌仍显示关键步骤。名牌没有未来弹路。成功后保存本机成就奖章、显示达成横幅；原击杀奖励保留，不额外增加局外伤害。

战术八项分为两页，打开时定位追踪/本局新成就；原成长/构筑页面与旧记录保留。平台工作后置，真人平衡与长期耐玩仍需试玩。
