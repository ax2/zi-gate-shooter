# Stage-188 设计

先制拆炮：斜射哨机保护结束、实际处于蓄能且尚未接纳任何发弹时击毁。停火/仅入场/普通哨机不算。

诱射反击：同一斜射哨机实际接纳三发子弹，各自在仍有效且源机存活时穿过角色下方安全界面（playerY+40，碰撞半高31外）；之后在该机离场前击毁，入场至击毁期间未失血。发射数量、弹体消失、无敌吞弹、击毁后旧弹通过、预算拒绝均不能替代安全避弹。

两者共享原敌人而不增加实体；同一目标不可兼得。永久奖章不加局外战力；追踪可跨局保存，战斗提示按真实阶段更新，并服从已有危险/回执/奖励的避让。八项战术成就分两页，每页四项，保持字级而不压缩成八行。打开页定位当前追踪或本局新成就；只能操作当前可见按钮。

暂无真人试玩与低端性能结论，正常策略仅证明实际可完成，不代表长期趣味已验收。
