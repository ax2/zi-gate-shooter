# Stage-208 通用弹芯构筑

问题：原弹道二阶仅影响霰射，其他弹道枪投入同路线收益少、预览只看霰射。将已有三选一共享四种弹道武器，不增加货币、武器或树节点。电弧保持原电学机制。

- 共同伤害系数130%；霰射原一阶110%作为升级前基准，其余原生伤害、射速、弹数、组合保留。
- 贯穿至少2敌，取原生更高上限，原三目标穿甲仍保留；箱门、闭盾和首领入场保护仍截断。
- 爆破范围至少140，50%邻伤。原榴弹只扩大已有一次爆炸，不叠加第二次；原生爆炸既有闭盾行为保持，新微爆不能通过闭盾触发。
- 跳弹有效直击后280范围侧击一次，横距至少80、55%伤害，不递归、不充箱门。伤害归实际原武器，不伪算霰射。
- 子弹出生时记弹芯，选择前已飞行弹不会补新能力；统计来自真实碰撞，并汇入战绩与已有跳弹检验。

预览列出实际受益配件和合计理论直伤/秒，不含临时超载、不等同实战输出；未选分支不偷设贯穿。参数页显示当前真实目标数/范围/侧击及原组合。

微爆采用青铜断弧和金属飞屑，source-over，0.18秒，弱档3片/标准6片；72距离内合并并复用原全局4爆炸显示上限，显示合并不改伤害。不画敌人未来轨迹。

首章24.5秒原三轻机检验改三台固定80HP原装甲：x300/y500、x300/y330、x420/y500。纵距170大于原榴弹130范围、侧距120支持爆破/跳弹。同数量但类型/血量/分值改变，原30总分变150，无额外充能、装备或研发赠送。其他排程另有严格对照。

贯穿依赖纵列，爆破适合邻敌，跳弹覆盖侧翼；当前和未来拾取四类弹道枪共享，旧火力叠加。候选数值和长期强弱要后续试玩调整。
