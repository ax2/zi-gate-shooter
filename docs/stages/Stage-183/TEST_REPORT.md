正常装备策略能使电弧精校9，但旧表现停在T3。新增1/3/6三档刻纹/金属导轨/弹体套环，五武器按已有颜色与机械轮廓分别表现。原详细机械图与弹体保留，不新增素材。挂载最多+15%、回弹+36%、主导轨尺寸+21%，原主机体/发射点/碰撞/参数/奖励不改。画面封顶不限制后续精校。

出生时给友弹写只读calibrationBand，缺失或未精校保持原样；不改变damage/速度/弹数/生命周期。旧弹不被后续改装追改，机体刻纹则读各自当前精校，动态光由实际fire的WeaponMotion脉冲驱动，不设假充能计时器。弱档减少路径，原友弹80/敌弹48/光束与粒子预算保留。附加弹体路径局部横距<=18、后向<=60逻辑像素，不添加全屏光晕或假命中。它们是已发友弹上的细节，未画敌人未来弹路。

组件检查发现最初金属线偏细，改为有厚度的深钢/高光；实战大光束盖住新尾迹，调整为友方光束上、详细弹体下，敌弹仍最后绘制。手机刻纹偏细，补有限挂载加固与实际回弹。没有为了显眼无限放大光效。
