# Stage-175 磁暴实战认证

固定试玩：[打开火力突围](http://127.0.0.1:5178/)。服务停止后运行 npm run play，保持服务窗口运行。

1. 雷电三阶并持有T2爆裂炮后，下一次雷电升级选广域磁场或分流电桥，照常消耗1技能点，旧火力保留。
2. 下一轮前40秒，在“挑战契约”接取“磁暴精研”。选定精研后默认展示该目标，也可以切换其他检验。每轮仍只选一个契约。
3. 30秒内对验证精英产生6次有效精研命中，并命中至少2批验证敌人。广域只计算原150半径外的扩圈命中；分流只计算场外电桥。普通场伤、旧计数、普通敌人和直接击杀均不能替代。需要调整站位和射击目标，给电场留下覆盖机会。
4. 成功后任选充能+100或强化已有配件；满阶武器可精校，旧能力不移除。失败没有奖励、没有认证，重新开局也不会补发。
5. 成就→构筑中的“磁暴双修”记录广域与分流各自认证，分两局完成即可达成，可设为追踪目标。两分支在“构筑全才”中合计为一个磁暴检验类型，不重复计数。

验证精英使用原fan实弹与机械造型，固定2倍耐久，最多6批/5秒间隔，投送保护0.45秒并保留安全路线准入，不按玩家DPS抬血。不显示未来射击路径，没有新局外经济或增伤奖励。

候选平衡仍需试玩；自动正常成长样本可以较快通过，不代表挑战性和长期耐玩已完成。46个构建资源保留于build/playable/Stage-175，serve.mjs配置5257（仅配置，本阶段未另开冻结服务）；不打ZIP。完整证据见TEST_REPORT.md。
