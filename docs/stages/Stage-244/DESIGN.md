# Stage-244 近距回收

2026-10-18，候选参数，整体目标继续。

面对更密的敌阵，玩家可能已经打碎装备箱、也向掉落物靠近，却因躲弹偏开几十像素而错失强化。本轮在原装备物理拾取上加入近距横向辅助，不扩张原52px碰撞圆，不直接发奖励、不增加新经济或技能槽。

|规则|候选值与行为|
|---|---|
|对象|仅active的pickup，箱子必须先打碎|
|窗口|y784至1076，即角色前240px至原圆形可拾取下界|
|距离/速度|横距112以内，最多210px/s横移，原纵向速度保持|
|结算|沿原相对连续圆碰撞接触才拾取，移动本身不给装备或研发|
|互斥|同排拾取圆或未碎箱碰撞边缘之间额外留12px，不能把选择吸到一起；接触一件仍取消同排其他备选|
|危险|没有无敌、停弹、危险清场或敌人减数；同刻致死仍优先，不能死后领装备|

同排两个拾取物的中心最小保留116px；另一件是未碎96px箱时保留132px（拾取半径52＋箱半宽48＋玩家半径20＋间隙12）。已经很近的原布局不会被强行推回，只阻止继续向另一选项靠近，向外移动不受阻。不同排仍可各凭实际接触领取。

使用现有机械模块原画和小框，只在实际横移帧显示青色边角、3粒3px短尾和“回收中”原位标签；弱档保留识别，未横移仍沿用原“拾取/快拾取”，过期不留假信号，不画指向敌人未来路线的大光线。没有添加新的全屏面板。

首箱真实偏右90px对照，新旧同前态下旧版错过，新版13.2833秒接触后叠加霰射T2并取得原研发，选择原导电线圈后3种火力开火。军械箱真实二选一中仅得穿甲T2，保留旧速射/霰射/电弧，未领爆裂；没有把该实际叠加案例写成改装案例，已有配件refit另作碰撞检查。

辅助只处理最后一小段接近，远处装备仍需选择和走位。长流程取得更多装备但弹道样本少穿1门，部分战况空场退步保留；不能因此认定所有奖励与刺激程度都已完成，真人平衡仍需试玩。
