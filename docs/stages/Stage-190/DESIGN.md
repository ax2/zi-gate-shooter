# Stage-190 离子精研

目标：把雷电第三节点后的成长从纯百分比推进为一次有明确用途的二选一，保留既有能力和普通精调。前置为雷电3、雷电精调2、实际持有T3电弧、尚未选过离子精研；若磁暴精研同时已满足，先展示磁暴，之后离子不会丢失。每项仍花费一个真实技能点，本局不可换，后续可正常精调。返回选择不扣点；预览不改World。

两路线共有：原6次有效电击、140范围120%放电、0.8秒冷却不变；普通电弧精调系数每次+10个百分点仍生效。实际雷电命中填充原充能，派生雷核/雷矛不再次触发电容、离子、光链、磁暴或裂甲，不充箱门，不改变箱碎后拾取/门穿越/同排互斥。单位死亡仍走原奖励一次结算。

- 巡航雷核：原放电后，从命中机体下方（半高+32，最多80，且不越过玩家前24）推出金属核，上行260/秒，持续1秒，0.1/0.45/0.8秒三拍；100半径每拍最多2敌，每敌35%触发该次放电的电击伤害。最近距离/ID稳定排序。原目标仍在范围内可受击。最多2核；实体飞行碰到箱门/闭盾消失；原放电机体不吸收自身推出的核。下移出生点兼顾初始金属结构可见性与沿敌列推进；不是额外扩大脉冲半径。
- 分岔雷矛：原放电后两支，从命中点左右±12/上12向各自侧翼400内最近有效敌人的当前坐标定向；不追踪未来位置。无该侧目标时默认45度。只有左矛在无左侧目标且原敌仍存活时，从原机体左外侧16/下16回击原敌一次；右矛仍向外，不给双倍单体补击。每矛75%，最多2敌/0.65秒，速度约1414；最多4矛。重复命中排除，闭盾按旧规则半伤并吸收，投送保护/箱门吸收且不造成奖励充能。

两者独立有界池，不抢原80友弹预算。加入同一连续碰撞队列：按接触时刻排序，阻挡在同刻脉冲前，实际死亡/首领获胜后不再追加伤害；新生成投射物下一模拟步开始运动。上方HUD作战边界裁切；恢复/死亡时清空。暂停不推进World，新局不保留进化。

视觉：原创机械六角外壳与分段线圈、透明断续电场、雷矛尖芯/有限历史拖尾。弱档减少线圈细节但保留核/矛形状。派生层在机体标签与敌弹之前，绝不画敌弹未来轨迹。保留已有精细机甲/场景资产与正常命中音效；本轮无新外来图片或依赖。菜单、参数、配方和战报显示所选名称与实际追加命中数。技能树提示前置，不另开经济系统。

取舍：最初原点出生的小核与风暴重合，修为更大金属结构及机体下方出生；固定45度双矛两次/十分钟、仅侧翼寻敌三次/十分钟，修为单矛回击单体以保证后期升级可感。数值均为候选，正常操作者收益不等于真人平衡。两路线不追加新成就，只沿用已有组合/成就系统。
