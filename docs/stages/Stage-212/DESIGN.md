# Stage-212 边缘肩架

目标是解决真实截图中靠边丢失外挂炮身与弹匣的问题，保持升级后的完整机体轮廓。不是新武器、技能或奖励系统。

外挂炮保留原尺寸和T级/精校扩展，以实际绘制半宽加8游戏像素限制中心横坐标。连接臂跟随相同中心，炮身/精校外壳不再分离。中心区域保持原位置；不缩小整体画面，也不改变角色可达横移68–652、碰撞、出弹点、伤害、敌人、箱门结算或成长。

仅横收候选通过范围检查，但实际手机图中外侧霰射被主武器挡住。因此侧下槽位（原y>-60）随横收距离以3.5倍向上抬肩，连接臂增加一个折点；上方炮位保持高度。此倍率为候选视觉参数，最大T3/精校3档仍有界；只从当前角色位置推导，不另加动画时钟，暂停不会漂移，离边连续复原。原开火回弹仍使用模拟时钟。

双弹芯弹匣以64像素含笔画包围宽度同样保留8像素内边距。原机体和模块是已有原创材质，新增仅肩架布局，不声称新增获批资产。没有未来敌方弹路，弹丸出界仍按原规则。主机体、所有爆炸和光效整体范围不属于此次越界归零结论。
