# Stage-162 构筑目标验证（2026-10-16）

## 目标与交互
上轮正常构筑检验揭示最近补给策略可能反复选改装、迟迟凑不齐配件。本轮增加一项可主动选择的构筑目标，不增加战斗系统/资源/战力。主界面新增入口，暂停的原配方入口保留；五个已有构筑统一展示，补齐离子风暴。选择/取消只写v1存档的可选recipeGoal，未知值/旧存档回落null，不改旧分数/成就/设置，不默认强设路线。

只读recipe-goal模块分别表达技能节点、光学精调和真实武器阶数；光学三节点不能冒充一次精调，激光充能解锁也不冒充棱镜节点。箱体/掉落只有实际帮助缺少的配件时才标记：未持有配件可安装、已有T1可升阶，普通同阶重复/无关配件/未持有武器的改装不误标。目标满足后不继续推销已经达标的配件。

配方页有当前状态和设为目标/取消；需要的箱子增加金色边框/目标字样，原角色、用途、数值仍显示；真实掉落显示目标·拾取。底部原帮助区域提示所需补给，已掉落和未碎箱分开描述，同排只领一件。技能卡保留原参数比较，另显示哪些节点推进目标与0/3→1/3等进度；不自动选分支或装备。危险提示优先，真实敌弹进入帮助区域时省略可选帮助，区域清空再恢复。原移动/武器/首领帮助保留。

配方从未满足变满足时排入目标成形回执，等playing恢复后显示，避免连续分配多个点时被后续升级回执覆盖。选一个已成形目标不伪造再次获得；重新开局保留偏好但按新World重新算缺件。战绩的下局目标也会反映该构筑状态。不增加额外奖励、粒子池、声音、贴图或自动获取能力。
