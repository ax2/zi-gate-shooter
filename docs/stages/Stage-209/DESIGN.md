# Stage-209 复合弹芯

基线5046d30。三条正常600秒策略审计：弹道/雷电/光学优先分别31/31/30次升级，300秒后17/17/16次。弹道最后一次原机制分支后多为数值精调；这不是所有流派穷尽审计，也不等于真人难度。

追加后期复合选择：弹道3、弹道精调至少10、任一已拥有T3弹道武器、已有原弹芯且未复合，并先处理当前可选原裂甲/雷暴精研。花1已赚技能点，在其余两种弹芯选一；本次照常增加原精调10个百分点，原130%基础不再次乘130%，不移除旧枪/原机制。允许仅做常规精调、未来再复合；返回不花点。不能重复原弹芯、更换副芯或追加第三芯；本局结束/重新开始清除，不存成局外战力。

- 贯穿＋爆破：至少2直接目标，各直接接触保留原范围爆破；原生较高穿透/爆炸取大，不复制原榴弹爆炸。
- 贯穿＋跳弹：每次有效直接接触可追加一次侧跳；侧跳不成为新的直接弹丸，不递归贯穿/跳弹/爆破。
- 爆破＋跳弹：直接接触分别触发已有邻伤和一次侧击，侧击本身不爆破；同一个邻敌可能合法同时承受两种派生伤害，这是组合收益，不是重复直击。

既有闭盾/投送保护/首领入场/箱门截断与伤害来源沿用；箱碎仍需拾取，门仍穿过才领取。出生弹保存主副弹芯，选前已飞弹不补新副芯，只有新出生弹获得新能力。后来拾取的弹道枪也共享。跳弹检验资格与参数显示使用实际两芯，不只检查原主芯。

选择页明确原芯与两种追加、常规系数变化、1点代价和延期；本局参数/技能树/战绩显示复合结果。五武器参数改三行：名称、实际能力、频率/弹数/单发伤害，避免精校和多能力横向重叠；战绩用短双芯行，完整裂甲/雷暴记录仍存在。机体右下增加有边框、铆钉、分槽和刻印的双芯金属弹匣，利用原开火闪光，不新建粒子、实体或全屏亮层。

精调10与一次复合均为候选取舍：延后到约5分钟产生一次新机械决定；没有新增树/货币/武器，但也只延长一个关键节点，不解决此后全部重复。三组合强弱、长期压力与真人选择需继续检验。
