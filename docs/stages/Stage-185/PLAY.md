# Stage-185 击破穿震

固定试玩：http://127.0.0.1:5178/ 。停止后运行npm run play并保持窗口。

持有T2穿甲+T2爆裂，弹道3后下一个弹道点选择「贯通冲击」。保留原三击裂甲爆破；现在穿甲弹直接击破敌人时，也向前释放一道穿震。适合借前排击破继续打后排，与更快同目标破核的双击路线形成不同用途。两路线仍花1点、常规精调照常增伤，旧火力/组合/成长不移除。

候选参数仍为向上320、宽240、最多2敌各75%来源伤害；箱门/入场保护阻断，后排闭盾减伤后阻断。派生伤害不会继续触发击破穿震；首领胜利立即停止，不刷奖励。同排机体前缘与发射原点交叠也能被实际波宽命中，完全在后方者不受影响。

金属双轨/锻尖和原点破口只在真实发波后显示；遇阻就截断，零长度接触只绘局部破口，不假装继续向前传播。弱档减少细节，原效果池上限不增加，不画敌人未来弹路。配方显示实际爆破/穿震次数，击破穿震已触发时不会误报未触发。

这次是已有路线的用途与反馈修订，没有新增敌人、武器或资源系统。三组正常策略的额外命中有增加，但真人选择价值、长期趣味和低端性能尚未验收。

最终完整可运行目录build/playable/Stage-185-final：46资源+serve.mjs（node serve.mjs使用5267，只配置未另启），不生成ZIP；原Stage-185为中间冻结保留。战绩也显示真实穿震次数。
