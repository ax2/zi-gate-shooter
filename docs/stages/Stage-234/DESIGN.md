# Stage-234 分叉电弧放电

目标：提高已有电流的层次和可辨认程度，配合前轮敌阵变化。不新增目标、伤害、粒子实体、素材或依赖；敌人/成长本轮不变。

已结算连接由纯函数生成主丝：最多14段，弱档最多7段；两端收束到原命中点。绿电幅度上限10逻辑像素，金索敌4，光链6；分叉最多2条、末端偏移26，短链接不分叉。绿两短枝、金一短枝、蓝紫反相双丝。确定性变化随原life推进，不调用Math.random，不消耗战斗随机流。

Canvas先深色衬线，再有限宽度加色光晕、彩色主流、白芯、短枝/双丝及目标冠光，保留索敌角标和光链源棱镜。限制在玩家射击区域，restore恢复绘图状态；危险和数字仍由现有后层绘制。弱档移除外晕、短枝和第二股光丝，保留单流和真实端点。不开全屏闪光/模糊滤镜，避免堆光遮挡。

取舍：短枝不寻敌、不形成伤害范围，只表现原连接的放电；明确限制幅度。初稿手机实景分叉太细且三色共形，修为三种形态，保留初稿证据。该方案未证明低端性能或真人爽感，也不替代难度与内容开发。
