# Stage299：长局主炮突破与真实回收反馈

当前不足来自用户的持续升级/奖励需求，以及298截图中的同值前后箭头：主炮9份后永久三路，仅有越来越小的对数增伤，容易看不到收集价值。本轮保留原3/9份的前段成长，在累计24/60份分别增加四/五条真实弹路；五路后每60份再提升一次主炮基础伤害系数，阶级继续而弹体数量有上限。

候选阈值0/3/9/24/60，之后120/180/240……。旧连续微增保留，周期提升为基础主炮伤害系数加0.12（不是当前伤害乘1.12，不冒充全武器DPS）。新炮口真实发弹，外观收窄排布、后坐保留，开火音接入当前炮口阶段；不改变敌人HP/攻击以抵消玩家成长，既有物理预算不加大。

累计成长与可花库存继续分开。弹芯/线圈/透镜拾取才计入，掉地/过期/光甲/维修/精校付款不能凭空积累；旧武器/路线目标保留，不免费解锁科技。HUD/装配页展示下次突破进度，微增显示正的真实每发差值；阶级突破给清楚回执，不能四舍五入成同值箭头或夸大为实战DPS。

新增后段成长会改变战斗和掉落节奏，24份前应与298原规则一致；之后按真实旧新流程分别记录，不能要求全局相等或将更快通关等同于平衡更好。真实浏览器听感、真人爽感/难度和设备FPS仍需后续验证。
