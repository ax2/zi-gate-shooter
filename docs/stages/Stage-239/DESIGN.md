# Stage-239 先遣与追兵

用户目标仍是敌人更多、战斗刺激、章节区别与长期体验。已有开头并非空白：旧首个敌人1秒出现，后续章0.5167秒追兵可见。旧统计最长5.43秒空场实际在首章56.58–62.02秒，早期解释错误已在工作日志更正。不能以平均或最长值编造时点。

本轮把原初始3个巡逻槽位替换为5人先遣队，仍保留原3人的时点/横位，按章展开：走廊中轻机后两翼交错轻机；侧翼新增右翼短刺与左翼轻机，后接原左翼切入；重装中炮保留普通扇弹，新增两翼前屏，原后续中列轻机继续。替换发生在旧排程变换之后，避免使后续“首个冲锋”选择误变，也使新落点不被旧统一投送高度覆盖。原6.5秒及以后所有非新增项目逐对象与旧版相同。

仅首章在57.5/59.5秒各追加3架轻机，左右交替、逐机错0.12秒入场，填实测清场尾空段；原58秒门和62秒收尾不删、不提前领奖。故首章总增加8敌，后续每章增加2敌。没有根据玩家火力/血量生成敌人，不改固定HP曲线、发射规则或奖励数值，既有投送屏障0.45秒仍可见。没有未来轨迹线、新货币、经营或新敌种，用现有精细机体/投送环/真实枪口/命中爆炸表达。

重装新中炮opening0.35秒，再完整0.6秒蓄能，实际首发约章内1.95秒；允许被已有强火力抢拆，不锁血演招。屏幕外沿保留空路。侧翼与重装原早期追击队保留，章首不是只剩5人。初稿路线一条粗网格规划失败，最终仍有；97点同状态能找到且实际450ms延迟无射击全章HP3，因此保留原失败而不削掉整队凑原网格通过。生产admit/路径算法未改变，测试工具新增可选细化，默认原样。

数值都是候选。首章敌群更密，但长局状态依赖走位和成长，部分后续章空场增加、装备/门实得下降，不能称整体难度、真人刺激度或长期耐玩通过。下一步仍需收敛奖励接近路线与多章压力；平台后置。
