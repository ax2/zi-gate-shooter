# Stage-216 破阵重炮

2026-10-17，基线2032c20。用户持续目标为内容、画面、体验，平台发布后置；本轮针对成型火力清掉普通炮甲后没有新决策的问题。

重装章（R3/6/9…）21秒原九人增援中的两门普通炮甲改为同时入场的供能重炮，一名轻机改为侧方中继。该段仍3炮甲、5轻机、1中继，共9对象；整章新增27对象总数保持。两门炮分别550/350纵列，侧方中继450。方向随原战况/镜像变化，炮列基准420、中继180，再由既有x映射处理。第三攻势从53.5提前47秒，留出55.5原重炮段的释放窗口；走廊和侧翼仍53.5秒，108排程检查其他对象/奖励逐项保持。

复用原火控与原创闸甲：活中继范围320内闭甲减伤80%，炮击后开甲0.9秒。拆中继沿用EMP、停火、开甲，旧实弹仍保留；也可等开甲集中打炮。新组电路ID取负轮次，原55.5秒电路仍正轮次，不能被另一组中继隔空供能。共享advanceBody用于实战和预测，不画未来敌弹线。

中段固定耐久倍率3，为原晚段6的一半；R3每炮489.6HP，中继144HP。数值与玩家伤害无关。初版沿用6倍时三条正面策略都难以击毁；修订后三路线拆中继均能消灭双炮，成熟弹道构筑可不拆中继直接击毁双炮，电磁/光学正面击破仍较慢。不是要求所有构筑都用相同打法。

不新增武器或货币；原普通击杀分与中继断供反馈沿用。因一名轻机改中继，名义击杀分10→35，原门/箱/研发数量不增。箱碎后拾取、穿门结算、同排互斥、火力叠加保持。金属闭甲、机械滑轨、开甲受击、火控供能和EMP均用既有原创精细资产，不用色块替代。

取舍：普通机群提供快速击杀反馈，破阵组提供一个约数秒的主动处理窗口。仅改重装章中段和重装第三攻势节奏，不宣称整个游戏的长期内容已足够。
