# 火力突围 · Stage-100 独立网页试玩

安装了Node.js的电脑，在本目录执行 `node serve.mjs`，浏览器打开 http://127.0.0.1:5190/ 。不要直接双击index.html；资源需通过本地HTTP加载。服务仅监听本机，Ctrl+C停止。不需要npm install或开发服务器。

左右拖动或A/D、方向键移动，自动开火。射击箱子后拾取强化；射击数字门增加奖励，穿过才结算，同排只选一个。暂停后可查看冻结战场，再明确继续。设置中可调音效、音乐、震动及特效档。

内容：五武器×三阶，六类普通/精英敌人，三章专属首领，九套轮换战斗组合。独立的爆裂范围伤害、电弧衰减连锁、盾卫减伤截断和狙击蓄能等机制。没有登录、付费、广告或后台。

这是当前可玩版本，不是商店或微信发布包。静态自动操作者20分钟已完成；真人平衡、主观爽感与低端设备性能没有最终验收。开发环境曾出现前台长回调间隔，根因未完全确认；安全暂停仍保留，需明确点击继续。

源代码与许可证见 https://github.com/ax2/zi-gate-shooter 。本目录保留MIT LICENSE和资源/依赖说明文件，构建文件清单见manifest.json。
