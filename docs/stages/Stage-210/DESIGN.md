# Stage-210 联动闸甲

起点：5d15f4f。两条正常20分钟复合构筑均R15/HP3/实际受伤0，R9火控组可在无发射时被清掉。自动操作者知道危险与最佳路径，不代表真人难度；这轮让已有后期战术发生，而非提升玩家面板后再同比抬血。

第9/12/15等重装章，原55.5秒火控组的两台装甲加联动闸甲；原敌人种类/人数/坐标/排程/血量/奖励不改。只在运行时给原装甲附加模块，不新建角色/货币/配方。第3/6轮与其他章保持原规则。

同组存活中继在原320圈内供能时，闭甲减伤80%，截断贯穿与受盾阻断的派生；原榴弹在闭盾直接命中仍保留已有爆炸行为，邻伤继续按各目标真实减伤结算。不是无敌，闭甲仍可被强火力击破。每次发射动作后0.9秒开甲，直接输出恢复；只模拟发射或未被弹预算接受的调用，仍遵循原发射状态时钟，不为渲染改伤害。

先打双炮：要面对第一次实弹并利用开甲窗口；先打中继：立即断供开甲，圈内原EMP仍暂停1.5秒，旧弹保留。横移后炮出320供能圈也开甲，回圈可重新闭甲，不回血。中继死亡会立刻重算关联，避免同帧下一次命中仍错误挡住；其他中继组不被误关。所有伤害来源按实际扣血计贡献，武器/复合能力没有被移除。

闭甲/开甲共用原精细装甲机体，增加窄钢叶、薄导轨、铆钉、通风槽和划痕；发射后0.1秒向侧面展开。首版钢叶遮盖过多原机体，已按实景缩窄，initial证据留存。不增加全屏光层、粒子/实体预算或提前轨迹；本地名牌分别说明80%减伤/暴露，EMP优先显示停火。

实效：规则两策略对照中R9先打双炮，旧版0发、新版6增幅弹；先拆中继旧/新版均0发。源血144、两炮各3859.2完全相同，新版先拆约0.57秒停火、两炮约1.38/1.55秒击破；先打双炮约1.42/1.92秒击破并留下旧弹。只是一处可观察的目标取舍，不证明整局难度已达标。

数值80%/0.9秒和第9轮起均为候选。出现较晚，不能替代前段难度与整局奖励体验；真人长期兴趣、更广构筑/种子、低端性能仍开放，平台继续后置。
