# Stage-201 密集命中光效层次

同枪同点命中复用已存在的材质与火星；通用飞屑每4颗保留1颗炽亮，其余使用有色细线和钢灰边，降低密集白团。武器伤害、组合、奖励和真实爆炸不变。24项专项/回归与构建通过，旧新各600秒完整World/mode哈希一致；手机同状态三点留证。临界近白像素589→213仅为静态指标，多重爆炸中心过亮、真人观感和长期体验仍开放。

原impact池已合并同枪同点，却仍为每次事件创建4颗旧式宽晕白头火星。现在拒绝重复呈现事件时立即返回，不影响后续独立kill爆炸。不同枪保持独立。呈现相位0..3在开局/回主页复位，不改变World随机数或粒子运动/生命周期/池上限。冷却飞屑用source-over而非叠加，热点保留原材质；弱档同样保留颜色与细线。

第一候选仅合并火星，临界仍581近白像素，未达到目的；因此增加混合层次。最终137颗粒子与第一候选数量相同，热点36颗。所有效果为候选，不代表用户已批准视觉质量。
