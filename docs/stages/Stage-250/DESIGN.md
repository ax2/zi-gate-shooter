# Stage-250 独立正常成长验证页

2026-10-18，进行中，不是新的游戏内容发布。先核对已有护炮与领奖画面，再决定是否修改，避免盲目增加未验收视觉。

验证流程：正常菜单开局→接取无伤契约→按实际可见选项领奖→正常成长进入第三章→护炮初现→真实敌弹接近→第二组→第三首领战利品。使用实际CanvasRuntime、控制按钮、触控与正常赚取的装备/技能/分数。虚拟时钟与全知操作员加速推进，独立内存存档，不修改用户localStorage，不注入World，不代表真人或设备性能。

页面保留推进下一阶段、推进0.1秒和切换特效档位。只在已达到的节点停留；没有观察到护炮实弹时，明确记录未观察到，不能伪造发射。品质与尺寸切换不得改变战斗状态。对照模式使用本轮纯HEAD基线，供后续真实渲染修订核对。

check-escort-deck是执行同一脚本的合成DOM/Canvas单元工具，并非另一个真实浏览器驱动，不提供像素、控制台或实际交互签收。它发现首次领奖只能选择已有速射炮，不能硬选尚未取得的霰射；验证改为选择实际可见的已有武器，保留原游戏规则。

浏览器当前问题：定向连接能识别IAB，但其webview未附着，新建页崩溃；Edge由用户确认可显示验证页，自动连接Edge仍超时。没有改系统、关闭用户标签或用其他控制技术绕过接口。
