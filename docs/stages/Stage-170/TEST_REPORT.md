## 可选择的战斗目标
新增“跳弹侧击”到原构筑检验，仍是原四类契约之一，没有独立货币/经营系统。取得跳弹弹芯且持有霰射才可选择，每轮前40秒主动接取、每轮仍限一次。目标：接取后30秒内12次有效跳弹，且派生伤害实际命中至少2批当轮验证精英；达标立即进入原奖励选择，充能100或指定已有配件升级，T3仍可专属精校。原五种检验保持，新目标不是第六套组合配方。

验证敌阵最多6批、间隔5秒，每批两台原精英x230/490、y380、既有fan扇射与原HP/章节倍率。0.45秒可见投送保护与原可达性准入保留，不依玩家DPS即时改血，不造新无敌期或清空已发弹。260横距超过140爆破半径且在280跳弹范围内，瞄准一侧能借弹打另一侧；不处理扇射会受到真实威胁。通过后剩余精英/飞行弹继续存在，领奖暂停后恢复战斗，不用删除威胁伪造通过。

Body只为该检验记录proofRound/proofGroup；Contract以Set记录实际被跳弹扣血的验证批次，只认当前回合、已准入的1–6批且契约active，重复/未来/过期批次不计。全局scatterRicochets减接取时快照，只计接取后真实有效跳弹；原始直击、无关击杀、闭盾/投送屏障和装饰光迹不算额外触发。普通敌跳弹可贡献次数，批次数必须来自该轮验证精英。死亡/超时不发奖，不会因之前累计次数追认。

首度成功记录“折弹高手”（主动检验完成，非积累刷数）与ricochet认证；沿用本地Achievements解析/保存，旧ID/最高分与认证保留。成就总数15、认证目标6；“构筑全才”仍需任意3种不同认证。六行战术页缩为108步长/98卡高，原五行页不改，页脚/返回和所有成就仍可读。结算页补实际跳弹次数，修复仅跳弹有效时误报“尚未触发派生能力”。

- 新成就让原战术组六行压住页脚，原测试抓到。修正布局，保留所有成就/页脚原断言；新UI测试误从暂停页调用不存在的契约按钮，改走实际HUD contracts-live动作，未给产品增加旁路。before-achievement-layout-fix.txt保留。
