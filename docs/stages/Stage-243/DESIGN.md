# Stage-243 四拍斜切

2026-10-18，候选参数。持续完善内容、画面、体验；不启动平台发布。

## 体验问题与选择
上一轮增加火箭炮仍在强构筑下被抢拆。本轮不继续只加单位或按玩家DPS抬HP，转而改第二种首领的一项真实招式。旧双翼attack2在场地x200/520同时放两列竖弹（每列4），主炮给中区留出大空隙；护卫依然能打中中路，不能把它说成整场战斗安全。

## 新招式
双翼首领attack2：保留原1.35秒蓄能，四拍、每拍真实双翼炮口各1弹，共8颗。拍间0.15秒；炮口随首领机体为x±120、y+90，避免空中整列凭空生成。固定纵速度300，随原章内弹速倍率同比乘横纵，伤害/数量/首领耐久/护卫/奖励保持。

四拍左翼在玩家高度的固定落点300/340/380/420，右翼取720减该坐标；隔次原attack2反向顺序。方向在出膛时定死，不读取玩家位置、不追尾。由原竖列改为中区交剪，玩家应在蓄能后向外换位，再回中集火。该宽度是候选，12条满血和30条半血/转段完整实战路线验证可避，非真人难度结论。

第一拍到下次蓄能的原周期2.8秒（长战3.5秒）保持，第四拍恢复扣回已过0.45秒；35秒边界按第一拍选档。半血转换保留已经蓄能的四拍，结束才接原过热反击。第1、第3种首领与普通关卡排程不改。

## 画面与声音
沿原精细双翼首领原画叠窄钢质炮筒、散热槽、口环、与当前弹向一致的局部转角；仅实际接纳发射后0.12秒显示后坐/短枪焰。常档枪焰最长28逻辑像素、弱档19，蓄能只在炮口，不画未来射线或覆盖危险的大面板。现有敌弹外观与血条保持。

每拍真实接纳后发一个wing-fire事件，复用现有boss-volley声，gain0.45；满敌弹池拒绝发射不闪不响。检查事件与消费者，不冒称音频已试听。
