# Stage303 设计：回切弹幕与主动击落

## 可见的实际差异

棱盾后两种机动轮换保留两架环绕哨机、六发一轮和原来HP/得分/物理掉落；其中两发由侧炮向外发射，撞左右墙一次后回切。第一种棱盾轮换保持原六发扩散球，让初次遭遇仍是既有入门强度。第二种折镜哨阵较平缓，第三种双环折镜用较陡角度，改变回切位置；不增加敌人数或扩展预算。

镜弹与原可击落球同属可射落实弹：主炮/实体副武器能截断它，光甲挡弹，原反相护场可以把它转成友弹。激光和电弧仍按既有规则攻击敌人，不能把光束演示当作免费拦截。击落不计敌机得分或伤害，避免刷分。杀死发射者阻止后续发射，已经射出的弹不消失。

## 候选参数和公平性

| 参数 | 当前候选 |
|---|---|
| 每轮数量 | 六发中替换两发，另四发保留原扩散球 |
| 墙面 | X16 / X704，一次折返，保留当步剩余位移 |
| 速度 | 原关卡速度×1.15，初始方向朝外/向下 |
| 入射角 | 水平侧向分量±1，向下分量0.45 / 0.8后归一 |
| 半径 / 寿命 | 12 / 3.6秒，撞墙不续命 |
| 连续发射间隔 | 原环绕哨机2.25秒，入场暖机不缩短 |
| 对象预算 | 敌26/敌弹200/友弹280/掉落32/Effect220，均不增加 |

护甲和身体命中、友弹拦截在反弹当步用同步折线路径检查：记录真实撞墙点和帧内时间，按双方实际运动分段求接触，不能拿起点/终点直线切角。非镜弹、未撞墙帧继续旧碰撞路径；镜弹转为友弹后清掉敌方折返状态并恢复旧能力规则。

所有数值候选。自动驾驶知道完整局面，不能证明真人安全路线、难度适中或长期耐玩。首轮长局仍全部存活，不据此把难度或趣味定为达标。

## 画面和信息

新增的是既有原创精细敌机上的机械侧炮，炮座和实际出弹共享mirrorMount；复用原创金属雷壳缩成镜弹实体，暖金菱形边/青色未折返刻线/短后向尾迹，撞墙用局部火花。没有用大光块代替机体，没有未来弹路线。镜弹与其他实际危险一样在友方爆光后绘制，弱档减细线/尾迹。

空域卡显示折镜哨阵/双环折镜，并明确“镜弹折返 · 可开火击落”；这两种主题确实改变攻击，而不只改名称。普通材料/掉落/科技树/主炮累计成长不改。本轮不声称解决全部配件理解度或长期重复问题。
