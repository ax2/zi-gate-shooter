# Stage314 三棱巡航堡垒设计

第2、4等三空域循环的棱盾行动替换旧拆盾，首循环保留；仍18秒窗口准入，需4个空敌槽，26秒限时。移动核心有限HP260与盾540、三炮镜各50HP，按既有sector系数缩放，不按玩家伤害抬高。环绕半径115×72、旋速0.62rad/s，核心入场140px/s、18秒后撤离。每镜每2.4秒两发绿镜弹，一次折墙/3.6秒寿命，炮镜可打掉则不再发射。击破一镜移除最初盾的1/3（不会反复减）、40分/真实击杀；不触发镜间连爆，区别于磁雷雷库。直接击穿有限盾/核心也获胜；未击破炮镜断电而非伪造击杀。

核心胜利新机库模式实地投金币60，不消耗或扰动稀有武器投送计数；旧材料夹具仍6透镜。12物满池只合入不带其他行动tag的货舱，否则保留待投，既有物原位不瞬移；实际拾取才入永久金币。失败/时限/首领/死亡不能领胜利奖，已射弹不瞬间清空而按原寿命退出。

复用原创堡垒/追光镜与金属炮口图，形成实体核心/三卫星轮廓，连接仅表示当前供能，非未来射线。实弹亮芯最后画，弱档减少光效。新经济HUD按首领→行动→磁轨优先，任务条避当前危险；选择页正确显示金币货舱/新堡垒60币，不再展示永远0的旧材料库存。数值候选，真人趣味/听感/设备FPS待验。

实际堡垒货舱拾取后，在既有有限encounterHistory上记录claimedAt；3.5秒回收回执优先于随后2币，按World时钟冻结/到时退出，沿用当前危险避让。只是反馈，不额外给金币，不增加长期状态或存档版本。单纯拆完镜但未杀核心不获悬赏，已有镜击杀分保留；穿甲火力集火可能附带拆镜，正常强攻不承诺“所有镜保持存活”，纯0镜强攻由隔离规则验证。
