# Stage282：弹幕疏解、光甲与拾取含义

用户反馈：敌弹积满屏、掉落作用不明显。本轮只改自由空战，不改旧数字门或平台接入。

## 候选规则

- 旧敌弹最长9秒；改为普通实弹5.5秒、慢速能量弹4.5秒，离开实际战场边缘32px即回收，寿命结束前0.5秒收缩外壳，危险芯一直可见。过期弹在碰撞前失效。保留敌阵/射法，不靠降低敌人HP处理积弹。
- 慢速能量弹采用可破碎六角壳，友方实体子弹命中可击碎；普通红色实弹及激光不可击落。每次拦截消耗一发普通友弹/一次穿透，无击杀、分数、材料、连锁触发，保留电极和反相护场对硬弹的价值。使用相对运动线段检测，先拦截后判玩家中弹。
- 首次普通击破掉落和其后每第六次普通掉落替换为光甲，首领、悬赏、战术目标、分数奖励及副舱承诺材料不替换。拾取立刻保护6秒，重复拾取刷新至6秒、不累计；仅抵御实体敌弹，激光和机体碰撞仍须躲避。光甲不恢复HP，暂停冻结，结束失效，护罩撞弹反馈有界。
- 零件拾取仍真实入仓，不能假装立即增伤。回执区固定在HUD内，以原实物图+名称+数量显示，强调“材料入仓”，动态给出同系可装配科技或所需下一份材料。回执可点开对应科技真实预览，支付才安装；立即生效的光甲/维修另用即时图示。HUD材料计数补名称，掉落短标签也对应名称。

数值全部待真人试玩；自动驾驶和虚拟60Hz不能证明真人难度或性能。新物理与渲染需分别验证，实际截图保留原件。
