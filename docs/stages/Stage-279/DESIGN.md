# Stage279 空域机动编队

基线Stage278/2f2e8cb。继续用户的雷电式自由空战和长期内容目标，不开展平台发布工作。

现状：三空域已有不同实物奖励目标，但普通波次大多纵向下移。此轮每四波替换一波为章节机动编队，沿用现有机械敌机、生命/得分、实地随机零件和既有首领，不新建货币/经营/抽卡。

- 炮列扫域：重炮横移，三发扇面方向逐次偏转，纵向换位或抢拆炮艇；普通僚机提供抢分目标。
- 交叉截击：两架截击机从上方进入后横穿空域，交叉过程中射双发近射，最后向下脱离；可绕侧追击。
- 旋阵封锁：两台哨机环绕中央空域，六向抛射逐次旋转，另有延迟进入的激光哨机；实际弹隙和抢拆顺序不同。

每三个空域为一轮，之后改变阵位、旋转方向与进入顺序，三个循环后轮换。候选参数集中在airspace.ts；运动连续、从可见边界入场、发射有本地短蓄能，不画未来弹路。对象预算满时原子推迟该波，不生成残缺编队；不能因此拖住首领。旧武器与成长不移除，不根据玩家DPS同比抬高敌人HP。

渲染复用已有原创精细机械机体，依据实际横移倾侧，附短机尾喷焰和真实炮口开火，不把几何占位当最终素材。标准/弱档/暂停应不改变物理结果。

验证：规则隔离用例检查原子准入、连续路径、边界、真实发射、脱离和首领；正常赚取流程与Stage278对照，测首60秒奖励、首次终极/突破时间、伤害与预算，不能以全知控制器生存代表真人难度。至少三类编队实际截图、移动尺寸/桌面/弱档和固定入口验证后再推广。

参数修订：机动核心编队3架，但完整波次按原阶段规模及后半段补普通僚机，避免后期稀疏；它替换既有波次槽，不额外叠一整波。初版稀疏数据保留供对照。
