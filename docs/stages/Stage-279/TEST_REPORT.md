## 已实现与范围

每四波候选槽改为章节编队：横移炮列三发偏转扇面、横穿截击双发近射、环绕哨机六向旋转抛射。后续循环改变方向/阵位，九个名称是三类编队的轮换，不是九张新地图或九类新敌人。普通机械机体、3场景、武器技能和既有三类首领沿用；机体按真实位移倾侧，短尾焰与真实炮口闪光，不画未来攻击轨迹。

保留原阶段常规波次人数与后半段僚机规模，满额整波延后0.35秒，不生成残缺编队，不阻止60秒首领。每20波与旧双精英槽重合时亦替换为本编队，因此并非每个槽的人数/生命总量都与旧版相等。没有新货币或编队赠料，沿用实际击破得分、每4击破保底随机实物、分数补给与飞近拾取。敌人HP仍由原机体/空域决定，不读取玩家DPS。
