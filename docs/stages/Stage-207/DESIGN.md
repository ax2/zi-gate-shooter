# Stage-207 折返炮阵

第4/7/10等走廊章35秒的原双装甲位改为折返炮阵，复用原创详细机械机体，加钢质环形发射器。固定镜像x210/510、y380，驻停3.2秒后继续下移；固定血量倍率4，不随玩家装备或DPS抬血。原两台数量、时刻、击杀分值和其它奖励排程保持。

开场0.1秒后局部蓄能0.65秒，向外射出一枚环形实弹，基础速度横220/纵260，沿用既有固定轮次弹速倍率。弹在x36或684处反弹一次，随后继续直行，寿命仍6秒。冷却1.4秒再蓄能，源炮离开射击带即停射；EMP仍能停火，拆炮不会删除已发实弹。先拆一边可减少回切压力，原有充能/技能/装备火力均保留。

炮台名牌从入场起显示“反弹一次”，蓄能时显示“蓄能”；不等升级回执让出位置才讲规则。只有局部机体蓄能和实际运动，不画未来射击轨迹。环形钢边、红橙危险边、热芯区分普通三角敌弹，仍最后绘制。弱档减金属细节，敌弹危险标记保留。

真实弹与保守安全预测共用advanceProjectile。反弹帧保留碰墙前后两段以及各自在原步长中的时间区间，对玩家运动也按对应时间区间插值，保持原碰撞排序；不能用起点到终点的弦线替代。普通弹保持原积分顺序与原始玩家端点。投送准入预测包含驻停和离场，仍受旧对象预算约束。

取舍：原双装甲在正常强构筑中来不及发射，固定耐久和更短首轮蓄能为真实出招留窗口，而不是增加新敌人堆满屏幕。此为后期走廊的一个新攻击问题，不能据此宣称无尽内容或真人难度完成；R13以后的超长局、更多构筑和人类反应仍待验证。
