# Stage277 空域战术事件

本阶段回应关卡重复、敌方攻击单一和奖励缺少目标感。默认玩法保持雷电式自由空战，不恢复固定数字门或固定装备排。事件与普通机群同时存在，玩家直接用走位和射击选择目标，没有接受任务或失败处罚弹窗。

## 三类空域的实际区别

| 空域 | 新目标 | 玩家选择与后果 |
|---|---|---|
| 冷却港湾 | 武装军火艇 | 横摆下移、三实体炮口瞄准扇射；追击并击破投4弹芯，飞离则失去本次额外奖励 |
| 侧翼突袭 | 布雷艇 | 三雷扇形布署，0.9秒武装，近距离或4.5秒引爆为8发实弹；先击破艇停止后续布雷，或射雷引发友方连爆清路、反伤敌舰 |
| 重装封锁 | 护盾中枢与双护航机 | 前方护航机有有限护盾，可直接磨穿；优先击破中枢立即解除剩余护盾。正常赚取对照中优先级实际改变完成速度和解除量 |

每空域18秒后尝试一次，38秒后不再新开；预算不足时延后，三实体护盾编队原子准入。普通波次和60秒旗舰规则继续运行。目标飞离或内部26秒上限结束即撤离，界面显示实际剩余耐久，不用与自然飞离不符的倒计时。后续空域循环换事件，事件记录最多保留12条，总次数单独累计。

固定候选耐久：军火艇180、布雷艇360、中枢420；沿用敌机空域倍率1+0.4×空域序号。护盾每机720×(1+0.2×空域序号)。不读取玩家DPS调节耐久。布雷艇/中枢先进入纵深275再悬停，护航机保持在中枢前方100与左右145，解除护盾后恢复自身移动。

## 奖励与命中

击破事件目标投放4同系实物零件，正常空池时在击破位置出现，拾取后才入仓。金框/战利数量与30秒窗口区别于普通18秒掉落；满池同类合并、否则等待空位，不暗送库存。死亡、撤离、重复伤害和失效物体都不能重复发奖，过期物即使碰到飞船也不拾取。

护盾先扣吸收量，溢出才扣船体，击破源释放双护航机的剩余护盾；护盾吸收单独记shieldDamage，旧伤害贡献仍记录实际船体/实雷伤害。击破实雷每枚10分、计拆雷，不计敌机击破或成就；连爆对115范围其他敌人造成35×(1+0.2×空域序号)伤害，真实击破敌舰才正常计敌数。矿雷自己引爆不赠分。所有武器与旧配件能力保留。

复用项目已有原创军火机三帧图、布雷艇/实雷六格图、中枢和电爆六格图，资产字节与基线一致。军火艇三弹实际从三个炮口出生，炮口闪光读取该敌人真实新发弹丸，满弹预算未发出则不虚闪。护盾蓝弧、实际能量连接、目标角标、零件图示和耐久条区分目标身份。武装雷芯及敌弹最后绘制，弱档不减危险判定；只降低装饰特效，没有未来敌方弹路。

## 已知边界

成型构筑的正常自动流程会抢拆实雷，不能声称后期雷区总能形成压力；只使用起始组件的实际赚取路线已验证武装雷阵和连爆。事件仍是三类循环，长期技能分支、更多战术变体和真人吸引力仍需继续完善。候选数值和美术未获最终真人签收。
