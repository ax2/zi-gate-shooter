# Stage-224 试玩

固定入口 http://127.0.0.1:5178/ 。服务停止后使用项目启动游戏.cmd或npm run play，保持窗口运行。

正常获得研发点后升级光学模块，再在第二节点选择“折返镜组”：保留主激光，间隔3→2.25秒，追加65%斜束，沿最近场边反射一次，最多命中2名敌人。左右移动能改变覆盖区域。箱、门、闭盾或投送保护会截停；旧武器不移除，破箱后仍要拾取，门穿过才领取。

暂停→当前火力与参数查看累计武器、激光间隔与伤害、折返命中数。让同一束光反射后实际命中两敌，可达成“借壁破阵”；主菜单→成就→战术第3页查看。不是累计打中两次，也不是墙前一敌加墙后一敌。
