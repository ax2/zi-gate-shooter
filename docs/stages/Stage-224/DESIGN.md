# Stage-224 折返镜组

2026-10-17。现有光学第二节点从灼烧/分光二选一扩为三选一，增加真实空间几何，而不是再加一层同类增伤。保留原主激光、-25%间隔、已有武器和未来棱镜/光链。

## 新分支

折返镜组随每次主激光追加一束65%激光伤害的45°斜束，向玩家较近的场边发射，反射一次后继续向上。恰在中央时固定向右。靠左/靠右/靠中会改变反射点和扫过位置；最多命中两名目标，同一个目标跨过折点也只结算一次。到上方战斗边界或另一侧墙就停止，不能无限反射。

箱子、数字门、闭盾、投送保护会按真实首次碰撞截停，不能穿过奖励或封闭盾体；打碎箱子只生成拾取物，门只在穿过结算。同排奖励依旧互斥。伤害跟随激光常态永久强化和超载，但不递归触发光链、离子等组合；沿用正常击杀/中继规则。伤害计入激光家族的实际扣血，参数页另列折返命中计数。

与灼烧的持续单体、分光的邻敌补射相比，折返需要借站位覆盖主束以外的敌人。没有撤掉已经取得的旧能力；这是首次选择分支，不是运行中将已选灼烧替换成别的能力。

## 技巧奖励

新增第21项成就“借壁破阵”：选择折返镜组，让同一束光反射后实际扣除两名敌人的生命。不是累计打中两次，墙前一敌＋墙后一敌也不满足。旧成就/存档保留，本局计数重开清零，已获成就保存在原本机记录中。沿用现有战术成就组、追踪、金属奖章和保存提示，无新货币系统。

## 画面与说明

实际解析的两段光路使用淡紫亮芯和收敛光晕，反射点出现小型钢质反射片/短火花；原机械光学炮架增双镜面支架，主镜/充能/开火动作保留。弱档减少线层与火花，保留光路和硬件。持续0.28秒；支援光束仍为16条记录上限，必要时替换最旧视觉记录，物理伤害不受视觉配额影响。

三张改造卡片完整显示作用、65%/2敌及截停规则；暂停参数在原折射、棱镜/光链和其他配件信息之外增加折返行。只绘制玩家已发射的真实光束，不新增敌人预测轨迹。光路保持在y≥240的战斗区，不进入上方HUD，避免穿进HUD；仍需实际画面检查数字与危险辨识。

全部数值为候选。目标是更有辨识度的构筑与技巧奖励，不是宣称一条分支解决完整长期耐玩性。平台/上架继续后置。
