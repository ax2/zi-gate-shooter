# Stage-235 中段战术轮换

用户问题：难度低、敌量稀疏、章节相似。本轮补21秒中段的战术变化；前轮已经增加开场与三段增援，这次不再单纯加人数。后续章节沿已有战况轮换，首章和战况0完整保留。

|章节|战况0原组合|战况1|战况2|
|---|---|---|---|
|走廊|轻机夹双扇炮|双锁位哨穿插轻机|双横移炮错时准备|
|侧翼|两固定哨接冲锋|一机动哨＋一固定哨接短折返|双机动哨接短折返|
|重装|中继＋破阵双炮＋后继锚炮|保留中继双炮，后继折返炮|保留中继双炮，后继横移炮|

各章节中段分别仍为12/9/9个排程目标。所有入场时点/位置/护盖、其他敌阵与奖励定义保持。走廊双横移炮准备1/1.4秒，侧翼机动哨准备1秒且从同侧部署140范围；后继炮沿原预备/蓄能。枪口蓄能与真实实弹可见，不展示未来射击轨迹。原机体、钢环折返弹和移动喷流复用，无新增商业素材。

锁位哨可抢拆或诱射换翼；横移炮需要跟枪或先清轻机；折返弹需在真实回切时改线；重装仍可先拆中继或抓开甲。原伤害/成长/武器叠加保持，不锁血强制演招，不依据玩家DPS追涨HP。更换为既有折返炮会沿用其固定4倍普通装甲耐久；因此不能称所有单敌HP不变。

初稿侧翼机动哨跨中路与原横跨冲锋封退路：90条中2失败。收为同侧部署仍2失败，进一步把该战况后继冲锋收成280/440短折返后90条全过。保留人数与持续哨压，外侧留路；不是放弃该组合或用杀敌/无敌作弊通过。

取舍：人数守恒，目标存留与实际攻击形态变化；强构筑仍可抢拆。三个自动安全构筑20分钟拾取相同，但穿门少1/2/3次、后两条mastery各少1，最长成长空档未延长；不把排程相同当实际收益相同。九种中段组合不能代表长期重复已解决，真人难度、瞄准取舍与成长收益继续验证。
