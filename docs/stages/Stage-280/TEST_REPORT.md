## 实现与取舍

三类首领各有两件真实可击破的火炮/激光/布雷副舱。舱跟随主舰，机械支臂和实际炮口，拆掉即停止后续攻击；已发子弹照常存在。主舰保留基础弹幕，生命沿用空域公式，不读玩家DPS。两舱原子准入，不足两个敌人空位时主舰先入场使用旧攻击，不能阻塞首领循环。

先拆舱锁定拆解优先，每舱3同系零件和80分；未先拆的基础回收每舱2零件。实物金框30秒，飞近拾取才入仓；满池合并同种，否则保留最多两个待投送。副舱不算普通飞机击杀，不刷累计成就或航线。主舰先死清活舱和所属实雷，不虚构拆舱奖励。本轮只为新舱奖励保留待投送；没有声称修好所有旧普通奖励在满错种池时的丢弃行为。

两种开局取舍，每艘首领互斥：先拆舱、主舰半血前拆完双舱，再取胜认证拆舱先锋；拆舱前先压掉主舰25%耐久，再取胜认证直取中枢。锁定后不限制已有火力，不同首领可分别获得两类认证。成就沿用badges字段，不重置旧档或暗加DPS。13项大图分航迹7/战术6两页，战斗回执直达条件；同帧多个成就优先显示新战术。

最初要求核心击破时双舱仍存活且都开过火，正常流程暴露出它惩罚已叠加的范围火力。保留初稿与失败数据后改为开局优先级，不要求放弃已有武器。带舱旗舰横摆140，旧裸舰190，整组404宽在720空域保留边距，不是按玩家火力调难度。候选数值仍需试玩。
