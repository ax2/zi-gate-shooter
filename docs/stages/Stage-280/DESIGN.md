# Stage280 首领双舱与选择型认证（候选）

基线Stage279/423dfe8。继续雷电式自由空战、叠加配件与长期内容目标。

三类首领各有两件实际可击破的附属舱：火炮舱三发扇射，激光舱锁位后发短时实束，布雷舱投可拆实雷。本体仍可直接击破，活舱攻击由部件产生，拆舱会减少对应攻击；主体保留基础弹幕。主舰HP仍按原公式，附属舱HP只读空域，不追随玩家DPS。

部件占现有敌人预算，主舰只需原有一个空位先准入；双舱等两个空位一起展开，未展开时用原攻击兜底，不能拖住首领或产生幽灵炮口。副舱跟随本体，用实际位置碰撞/受击/开火，击破后不重生。本体先死时剩余舱与所属实雷清理，无凭空拆舱奖励。

实际拆掉一舱基础投2同系零件；先拆舱锁定拆解优先后，每舱多1零件（共3），拾取才入仓，独立金框30秒；满掉落池可合并同种，否则保留有界待投送。没有新货币。副舱不算普通敌机击杀，避免刷累计成就；有伤害贡献和80分回报。两种选择型成就：先拆一舱锁定拆解优先，主舰半血前拆双舱并取胜；拆舱前先打掉主舰25%耐久锁定核心优先，随后取胜。每艘旗舰互斥，只看实际伤害/破舱，核心优先后允许全部组件继续破舱，不因范围武器被取消。只根据真实战斗认证，单纯安装或预览无效。

成就沿用本地badges字段，不重置旧档案，不暗加战斗力。档案分航迹/战术两页，保留大图尺寸；达成回执可直达对应图片和条件。

渲染复用既有原创精细机械炮组图集，敌舱反向安装、机械支臂、局部炮口闪焰/锁位蓄能、真实破舱爆裂及物理战利品。没有提前绘制射击轨迹。危险与文字在友方效果上层，弱档/暂停不改物理。

本阶段需验证：预算/部署/父子生命周期、三攻击、命中与同帧结算、实体奖励/合并/过期、两类认证和旧存档、分页/回执、正常收益与首领循环、真实三类舱体交战与破舱拾取、标准/弱档/桌面/暂停。数值候选，未执行不记通过；稳定5178在验收前保持Stage279。

## 设计修订与取舍

最初“核心击破时保留双舱且都开过火”的候选在正常成长中与用户持续叠加范围火力冲突；自动路线会因自然溅射破舱失去认证。保留最初设计与失败样本，改为开局优先级锁定，而非要求放弃已有能力。两路线用同一光学购件策略、同一种子，只改变输入偏好；先拆多2零件，压核心更快结束战斗，认证在获胜后才入账。普通最优策略仍可能偏向拆舱，尚须真人平衡反馈。

带双舱的旗舰横摆幅度140（旧裸舰190），舱体半宽52，加双侧150偏移后404总宽，整组在720空域保持18像素余量；不读取玩家火力调整HP。拆舱不计普通飞机击杀，不刷悬赏累计。实际发弹数仍记录作证据，不再作为认证条件。
