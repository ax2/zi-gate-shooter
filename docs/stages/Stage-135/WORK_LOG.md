# Stage-135 危险猎手契约（进行中，2026-10-15）
目标：让首分钟自选挑战具有不同目标/打法和即时奖励，不再只是30秒15击毁的条件变种。
候选：任一配件T2后可接危险猎手，每轮仍一次、前40秒接取。追加两名带标记精英，首次立即尝试、第二名在接取6秒后；安全路线/容量满足才入场，失败0.5秒重试，不强塞。30秒内实际击破两名，第二名死亡立即兑现契约选择；允许受伤/升级/换装。额外奖励为充能150或已有配件升阶/精校，原精英击破充能照常。所有数值待试玩调整。
计数按本次契约标记单位真实死亡、去重；普通精英/其他击毁不顶替，目标逃脱/撞机或玩家死亡失败。失败不删掉已出现威胁、不追回旧收益、不自动接取。目标HUD与本机体悬赏标识；三契约卡完整显示前置/风险/奖励；沿用现有奖励页/技能树。
验证：有效前置/真实双目标/去重/立即成功/死亡优先/逃脱/超时/安全与预算；正常首分钟能接取并领取强化、参数和能力保持；手机/桌面显示和原生操作。预置夹具标明，未把脚本当真人体验。
状态：未实现/未构建，长期体验与偶发长帧继续。

## 实施与验证结果
新增第三种自选契约：任一已持有配件达到T2、每轮前40秒且本轮未接约时，可接危险猎手。30秒内击破两名本约标记精英，允许受伤、拾取与升级；第二名实际死亡立即进入奖励选择，无需等倒计时结束。奖励为充能150或指定已有配件升阶，T3则精校+50个百分点，其他武器/等级/技能保留。普通精英击破充能照常。本轮未新增成就条目；这是对既有技能树、组合、成就和契约的内容补充，不是全部耐玩目标完成。

两名使用同轮真实精英耐久，第一名立即尝试，第二名在首次成功入场6秒后。每次需通过安全路线和容量检查，失败0.5秒再试，不每帧重算或强塞。抵达y500后驻留至自身年龄20秒，再撤离；保持精英原有机体蓄能与射击，不画未来敌弹轨迹。不根据玩家DPS抬血。目标去重且必须本约真实击破，其他击杀不能抵数；逃脱/撞机、玩家死亡、超时失败，同步死亡优先。失败保留已部署威胁，不追回旧收益，不再追加敌人。

## 过程与失败证据
初版普通下移精英在四组正常规则回放中均只击破1名、第二名撤离，记录hunter-before-hold.json。改成有界驻留，让主动转火有窗口，未降低耐久。拒绝入场候选原先可能被误认为已逃脱，改成admit成功后才标记；容量/安全失败重试有界。另补超过30秒的大步更新不能迟发成功。HUD置于正常顶部信息下，标记位于危险与数字层下，进度回执期间隐藏旧底部提示。
