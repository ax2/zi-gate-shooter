# Stage300 设计：先看懂射法，再选组件

材料装配页、分支页、进化页与路线详情中的十二种副件射法共用纯展示模型。以实际组件的端口/改装数量、攻击间隔和既有实体/弹体/爆炸图集表达差别；卡片短距离飞行是压缩示意，不是战斗伤害预测或实战命中证明，图内标记“演示”。

蜂巢六/八/十发扇射；磁钉三/五/七条贯穿弹；巡航雷球二/三/五枚弯曲弹体与末段跳电；电极二/三/四个环绕实体短时放电；追光一/二/三道转向索敌光束；光刃三/四/五把绕船旋转。进化件展示双爆弹、重追踪球、三敌雷链、双极索敌、三束索敌和三枚出返飞刃。真实材质和机械结构与战斗画面同源，不新加商业资产或粗糙色块。

进入选择/科技模态从开火阶段起播，不会一打开就等在循环末尾。弹体前进、接触示意爆炸/电链、装填空档有明确时间段。激光/电链短亮，弱档减少外层光晕。原图裁剪限制在既有210×104区域；靶机完整放在裁剪边界内，选项、材料、前驱与未来进化图不被覆盖。

模型只接收科技ID、展示时间和改装阶级；输出有限姿态，不导入或创建World，不计算命中/奖励，不读写库存、科技、目标、RNG、实体序号或世界时钟。预览不能免费解锁、扣料或把敌弹的未来射线画到战斗里。旧攻击、掉落、首领、奖励、主炮累计成长保持原规则。

本轮改善识别与选前预期，不能据此宣布组件强度、真人理解、长期趣味或整体目标完成。基础科技中原有示意、长局内容及实际听感仍可继续打磨。平台工作保持后置。
