# Stage-149 扩展火力或定向改装

固定入口：http://127.0.0.1:5178/ ，刷新后加载本候选。服务停止后双击项目“启动游戏.cmd”或运行npm run play。冻结版本保留build/playable/Stage-149；需要单独启动时运行其中node serve.mjs（5229，默认不另外常驻启动）。

后续章节且已有至少两种武器时，补给一侧提供未持有的新武器，另一侧提供已有配件的定向改装；全部收齐时提供两个不同配件的改装。首章和仅持初始武器的教学补给保持原样。

两边都仍需射碎箱子、再走位拾取，同排只领一件。定向改装给指定武器升1阶；T3后给1次专属精校，伤害系数增加50个百分点（100%→150%→200%），不替换其他武器，也不额外给充能。普通重复装备仍按旧规则充能+30。

T3箱提示单轮直伤前后变化，包含常驻加成、原有精校及路线精调，不计超载和派生伤害；大值k为显示约数。专精试炼期间改装本身不会新增武器种类，但仍需满足击杀数和时限；技能选择安装新武器也仍会违反契约。光学激光沿用研发路线，箱内改装针对实体武器。

规则与正常成长对照已验证，新文字/箱子/掉落物的实机画面仍待复查。数值和长期耐玩性未获真人验收。
