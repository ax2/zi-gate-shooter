# Stage-149 定向改装候选（2026-10-16）

## 问题与选择

旧armoryOffers始终优先两种未持有武器。玩家难以在箱子处选择“扩大能力覆盖”或“强化既有核心”，也难在专精试炼期间继续获得有效装备收益。T3普通重复物品按原规则只给30充能，不能把它描述为直接精校。

本轮保留原箱子/拾取物、两排补给时刻、坐标、互斥行与首章安排。第二轮起且已有至少两种武器时，一侧给一种未持有武器，另一侧给一个已持有配件的定向改装；全部五武器齐全时给两个不同配件。仅一把枪的教学仍沿用原两种新枪。没有加货币、稀有度、槽位或新菜单。

改装配件优先匹配已投入较多的弹道/雷电路线；同点时匹配当前主显武器优先，否则固定顺序；没有对应路线则用当前持有主显武器。光学激光不是箱内实体枪，仍走原研发升级。该默认选择不声称是最优构筑，首领原菜单仍可指定其他已持有配件。

改装箱沿用对应阶箱体与耐久，不改敌人、时间线、基础战斗公式或碰撞。破碎仅生成带refit标记的掉落物，真正拾取时复用既有upgradeOwnedWeapon：低阶升1阶，T3精校+1（专属伤害系数+50个百分点），按拾取时的真实状态计算。其他武器/总阶/充能/技能不丢失；普通重复装备仍给30充能。互斥清理在结算时执行，首次装备/补给研发规则沿用，组合可因改装达到条件而真实触发。refitsClaimed只统计这些箱内改装，不把首领或契约奖励算成同一种次数。

## 提示与反馈

箱子分别标“叠加/强化”与“改装/精校”，T1/T2显示真实阶数前后；T3用共用战斗profile显示单轮直伤前后，包含常驻火力、精校和精调，不计超载、命中率或派生。大于千的显示用k约数，不改战斗值。提示随等待期间其他升级实时更新，避免旧箱子仍写过时收益。掉落物明确“拾取改装”，结算追加真实改装次数；沿用原升级回执/声音与光效。

## 两条正常300秒路线

normal.json来自从新World开始的真实射击/拾取/路线/首领奖励/契约领取，无装备、血量、敌人或免疫注入。共同选择光学/灼热路线，第二章同样接专精试炼；奖励菜单在合法时刻领取，契约成功后真实领75充能，不跳过待领奖状态。控制器知道危险和物品状态，不能代替真人。

|策略|结果|实际取舍|
|---|---|---|
|优先扩展|300秒/R4/HP3，5种武器，195击破，3次改装|补齐爆裂/电弧；新增种类使自选专精契约失败；全部收齐后仍可改装|
|优先改装|300秒/R4/HP3，保留速射/霰射/穿甲3种，185击破，5次穿甲精校|保留集中火力并完成专精契约，实际领奖1次；穿甲精校5，其他枪保留|

这是可达策略差异，不是“专精更强”的总战力结论：路线选择、覆盖与契约奖励不同，击破数也不能独立衡量乐趣。数值仍需试玩；高效策略均HP3，不宣称难度问题已解决。
