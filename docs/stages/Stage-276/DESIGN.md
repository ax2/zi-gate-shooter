# Stage276 火力装配与试装对比

用户最新玩法仍为雷电式二维自由空战。本阶段解决当前参数不可见、升级收益不清楚和图片科技难理解的问题；玩法基线见Stage274，悬赏/成就见Stage275。关卡差异、更多有意义的组合和长期体验仍属于持续目标。

## 参数与真实攻击共用

`src/flight/profile.ts`从实际Assembly生成弹道、电磁、光学参数，World直接读取这些数值发射、命中与结算。界面展示单次伤害、每轮弹数、间隔、索敌/连锁、贯穿、灼烧、溅射和终极攻击；实际伤害贡献独立显示，不把理论弹数相加写成实测DPS。

精校为同系伤害系数增加20个百分点。界面显示100%→120%、120%→140%等真实系数，不把第二次精校误称为相对再增长20%。原配件和旧攻击保留。

## 图片入口与只读试装

- 战斗左上火力按钮、暂停和结算页均可查看当前装配。三系图片标签切换参数，退出回到原页面；结算页只能复盘。
- 科技树下方的实际效果图片是试装入口。当前/试装后两列高亮变化，配件图片指向现有飞船，成功确认才调用原World.install并真实扣料。
- 未完成前驱时显示完整路径预览和缺少的前驱数，返回路径逐节点组装。展示的材料栏明确为库存/本节点所需，前驱费用另计。投影只复制Assembly，不能花费、解锁、改变随机数或推进战斗。
- 互斥终极科技只显示当前火力和专精已选状态，不提供可绕过的确认操作。材料不足也不提供确认。

## 强化与开火动作

复用现有原创飞船、机械外挂、科技和零件图片。真实组装成功后0.8模拟秒在对应炮位出现收束夹具和短火花，战斗通知给出该组件的实际变化。翼炮/轨道炮的短焰与后坐读取真实新发弹丸年龄，线圈与光学炮口读取真实电弧/光束；不添加全屏泛光或未来敌弹轨迹。弱档减少局部火花与亮度，危险判定核心最后绘制。

动作按模拟时间冻结，树、参数页和暂停不会让强化提示耗尽。重开清除旧升级回执，起始组件记录新局实际变化。当前数值未调整，六组正常流程完整World对照用于验证参数共用没有改变战斗。

## 约束与后续

AGENTS已更新为自由空战授权，历史数字门/底部固定规则仅适用于旧模式。无新增依赖、货币、后台、广告、支付或平台接入。数值、真人理解度、长期构筑差异和关卡内容仍需继续试玩打磨，本阶段不能证明整体吸引力达标。
