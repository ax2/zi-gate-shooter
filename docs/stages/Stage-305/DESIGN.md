# Stage305 设计：挂载图与实际武器战果

升级回执可点图打开“武器战果”，暂停和结束页同入口；原攻击参数页可切换，仍保留当前/预览对照。战果页绘制当前飞船的真实副组件与进化挂载，使用既有物理位置、原创素材和世界快照。死亡后只读展示静态挂载，不重启攻击、不复活、不修改世界。

每页六张武器图，点图查看射法演示、累计命中伤害和占比，按伤害排序、分页。护航电极另列已有componentInterceptions。主炮与翼炮原本共享guns来源，保持合计；双翼炮/蜂群弹幕/武库在该项下显示共同强化图标。连锁/索敌归电弧，分光/深穿归激光，不虚造独立伤害。护盾吸收原本不入contribution，明确注明不含护盾，累计值不是DPS也不是构筑强弱排名。墙反弹仍保留原弹来源；bounce项记录现有跳击，场景连爆单列。

新装武器暂无命中时仍显示为已装；正贡献低于1%显示<1%，避免四舍五入成0%。累计占比受出场时间影响。只展示已有数据，不增加战果奖励、经济、武器数值、击杀归属或敌人机制。菜单冻结/返回仍由原模式机制负责；预览攻击明确标“演示”，不预测敌人射击。

完整挂载图也修复原参数页裸机缺口。预览页面的大飞机显示“当前已装”，右侧目标图/参数列才是试装内容，不暗示未付款组件已经装上。浏览器/真人理解与设备性能仍待实际验证。
