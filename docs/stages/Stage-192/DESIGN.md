# Stage-192 武器撞击材质反馈

目标：五种叠加武器的实际接触有独立形状与材质，而不是只改发光颜色。不改World、伤害、敌人、奖励和成长。

霰射抛出3/5片有暗面和钢亮切面的金属扇屑；穿甲留下纵向切痕、侧切和标准档两片碎屑；电弧为2/3条局部叉电，不连接未实际命中的敌人；爆裂为3/6段椭圆压力冠和标准档三片金属；速射为白热针及蓝暖短火星。数量依次为弱/标准。标准普通命中0.18秒，弱档0.14秒，保留光学命中的原0.22秒。

录入只对28范围内同武器普通命中去重；不同枪可以共存。标准最多12、弱档4，满池优先更新同枪旧项，否则替换最老普通项；光学项优先保留，不能被普通项挤掉。同枪去重不重置存活时间。弱档切换立即裁预算。

效果裁在玩家射击区，普通局部几何不超过64单位；钢片为source-over实体，电光为lighter。敌弹仍后绘，原生数字与HUD在效果之后。无新贴图、库、全屏闪光、阴影模糊、未来弹道提示。弱档保留几何差异并减少元素。

取舍：有界池能避免五枪叠加无界增加绘制，但密集光学/击杀火光仍可能遮住细节。实景确认了此限制，后续应围绕光核与实体层级继续调整，不能把本轮几何独立判作最终爽感验收。
