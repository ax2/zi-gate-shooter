# Stage-205 雷暴精研检验与成就

将已有的流派选择接到主动挑战、实战认证和跨局目标，不另加货币或局外伤害。串联电桥擅长穿过桥接目标连到后排，聚雷破核通过集中霰射打出破核。选择精研后，挑战契约默认指向该路线，但仍需玩家主动接取。

候选检验均30秒，必须命中至少两批本轮标记敌阵。串联需要6次实际第二跳，聚雷需要4次实际破核；历史累计、普通敌人、首跳、无效伤害、旧轮次或尚未投送批次不计。每5秒尝试投送，沿用既有准入和对象预算，最多6批。串联三体桥接阵，固定耐久倍率2；聚雷双重装精英，固定倍率4、y380，保留真实扇射窗口。不会按玩家DPS即时加血。

成功沿用原契约的充能或一件已有配件强化，不能重复领取，所有旧武器保留。死亡与超时沿用旧失败顺序。认证保存具体路线：首次任一路线通过达成“雷暴专研”；分别通过两路线达成“雷暴双修”，允许跨局，旧基本雷暴认证不冒充精研认证。成就仅提供记录、追踪与身份反馈。

取舍：两条互斥精研鼓励下一局尝试另一种打法；本轮没有增加随机词条、装备库存和第二套技能货币。固定耐久、目标数和时限均为候选，R7以后超长局可完成性、真实玩家选择价值仍待验证。
