# Stage-221 超载增压

2026-10-17。改善充能奖励的可感知爆发，承接Stage-219章节增援与Stage-220首领协同。用户要求整体更刺激、难度更高、章节更不重复；本轮只完成奖励反馈的一部分，不等同于这些目标已完成。

满100充能仍提供永久火力+10%，仍触发6秒超载，仍为1.35倍伤害；新增五种武器和激光的真实发射速率1.25倍。重复满充刷新持续时间，不叠乘速率。进入/离开超载按原冷却剩余比例调整，不白送齐射或积存射击。常态武器profile不受临时倍率污染。面板逐枪注明常态，并在全局显示临时伤害/射速倍率；HUD显示剩余秒数与储能。

视觉采用原精细机体后的机械排热箱、散热格栅、短喷流和碎光，最后0.6秒退场；弱档减少喷流/刻线，保留机械结构。边缘收缩由绘制逻辑处理，未单独强制边界截图。效果位于机体后方，手机/桌面实景检查数字、门回执与危险可读，无新增敌人预告射线。

充能门与其他奖励的取舍更有意义：正常能量优先控制在63.63秒穿过第四扇门，获得永久+70%状态及超载；默认控制首次94.27秒触发，永久+110%。这是路线选择造成的时差，旧新版相同输入的触发时刻一致，奖励与结算没有改动。不能将多枪混合齐射计数当作整局DPS；单支主武器理论伤害与频率乘积1.6875仅描述同时生效倍率，实际受命中、护甲、独立触发冷却影响。

保留固定敌人耐久、敌阵和奖励规则，固定80玩家/48敌方弹体预算。加速是有意的成长增强，也可能让强构筑更轻松；整体难度后续仍应通过不同战术和章节设计调整，不能宣称本轮整体加难。全部数值为待试玩候选。
