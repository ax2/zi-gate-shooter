# Stage263 普通敌弹材质

本轮只改普通敌弹绘制，不添加弹种或改变攻击规则。火箭、折返弹、磁雷原有分支保持。普通弹从单红三角细化为暗边金属弹壳、明暗切面、红色热芯、米白尖端和两道横向散热切口，避免所有弹药都只靠发光辨识。

实体顶点位于局部x±7、y±11，仍沿当前速度旋转。原物理命中是轴对齐半幅7×11叠加玩家半径，与可旋转视觉不是同一几何；本轮没有扩大或改成旋转命中框，不宣称逐像素吻合。尾迹只从后盖y=-11往负向延伸，标准长度14至26，弱档8；最大局部范围x±7、y=-37至11，没有任何尖端前方预告线。热迹是局部材质示意，不是保存的历史运动路径。

实体以source-over、不透明暗边和金属面绘制，保留敌弹在爆炸、友方火力与奖励标签之上的既有顺序。weak与标准实体完全相同，弱档只减短热迹与省去两条余热丝；不让性能选项损失核心危险轮廓。尾部暗色隔离线有界，不使用阴影滤镜、全屏罩层、新纹理或随机粒子实例。

渲染只读取x/y/vx/vy/age，不改动World、子弹速度、伤害、命中、准入预算、首领发射或奖励。优先验证同一真实六弹场景的旧新完整World与贡献相同、实际弱档与暂停冻结，再检查手机与桌面可读性。未执行的低端性能、动态真人辨识和最终美术签收必须保留，不把材质细化宣称为玩法丰富度完成。
