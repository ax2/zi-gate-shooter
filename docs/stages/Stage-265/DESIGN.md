# Stage265 升级装配动作

精校持续外观沿用1/3/6分档、最多三档的预算，不为精校1→2等同档升级无限堆叠光层。每次真实新增、升阶或精校，在对应炮组播放0.85秒的自装配夹具：侧轨收拢、金属咬合、短接触火花，再收起。既有原创机甲和武器纹理不替换，不把机械装配当新武器或新伤害。

触发沿用recordEquipment的真实前后状态比较。普通充能、未拾取/未穿过、只有公共火力变化不触发。侧挂炮使用原mountedPose的位置、折臂和后坐；主炮位于当前机体的炮组基座。夹具限制在现有屏幕边界内，不能以角色中心的统一光环冒充所有配件升级。

弱档与标准保留同实体、同运动，只减少接触火花。动作采用World时间，因此暂停和参数查看冻结，不加速战斗或影响命中。每种武器最多一个开始时间，最多5项；连续升级刷新对应项，过期退场，重开/回主页清空。无新纹理、阴影滤镜、独立粒子池、货币或局外成长。

本轮不改伤害、成长、敌阵、首领奖励或输入；动作时长、美术和真人动态辨识仍是待试玩的候选。需要真实正常成长和升级后的实景，而不是只凭绘制调用通过验收。

技能树直接安装不经过普通拾取回执，因此在选择成功后以真实前后所有权差异登记装配；不追加或改写原技能回执。
