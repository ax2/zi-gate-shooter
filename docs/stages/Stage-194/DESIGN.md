# Stage-194 主动改装目标

问题：后续改装箱的配件由refitFocus按路线/主武器推测，玩家只能等自动供给，很难主动补组合所缺的装备级别或长期精校偏好的武器。

新增本局的改装目标：暂停→当前火力与参数→选择改装目标，卡片只显示已拥有配件。沿用原创机甲资产、equipmentPreview真实T级/精校前后常态全弹直伤、机制变化与可完成组合，不另做数值副本。已指定卡突出显示，随时恢复自动。选择页与当前火力页都处于暂停，返回不会直接开战；原生返回先回当前火力。新局/回主界面清空，不保存局外订单。

只在次轮起、原军械二选一生成时覆盖已有的改装焦点；不足两件配件仍优先发现新能力，未集齐时另一个选项仍提供缺失武器，集齐后仍两种不同改装。首章与已投送箱子保持原样。选择不发装备、不扣/送资源、不修改已拥有参数；必须射击破箱→移到掉落物拾取才升阶或精校，另一同排奖励取消。旧枪/技能/组合保留。

World.setRefitTarget拒绝未拥有配件，undefined恢复原自动；定向来源标记仅写入实际按指定生成的改装箱，并传递给其掉落物。改目标后已在路上的订单仍原样，箱牌以“定向改装/精校”清楚标识。原拾取函数、研究点、专精契约、同排互斥与预算沿用。默认自动时完整World物理与上一版一致。

非紧急改装箱引导提示暂停入口，敌人迫近/蓄能告警仍优先。新增菜单最高五卡，每卡124高/134间距，末卡到952；说明1004、自动1030、返回1130，保留24/21字号与精细机械图。当前火力顶部替换重复的主枪T级概览为显式目标按钮，T级仍在各武器行。

取舍：不是无成本即时换奖励，指定目标会延后新武器的收集机会，玩家仍在同排决定扩展或深挖；后续可改目标但不能重洗眼前箱子。无新货币/局外经营/登录/服务端。目标控制是否长期有趣仍需真人多局反馈，自动300秒差异只能证明机制生效。
