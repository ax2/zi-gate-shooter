# Stage-194 试玩

固定入口：http://127.0.0.1:5178/ 。刷新后开局。

1. 获取一件以上配件后，点暂停→当前火力与参数→选择改装目标。
2. 选择想升阶/精校的已拥有配件。卡片显示实际下一次升级参数及可完成的组合；选完返回当前火力→返回暂停菜单→继续战斗。
3. 次轮起，尚未投送的军械补给中，原改装选项会指向它；另一箱仍可提供新武器。同排选一种，打碎后仍需拾取，原能力保留。
4. 不想定向时点恢复自动；新局恢复自动。已经在路上的箱子不会因重新选择而变化。

例如偏好速射可从T1逐步养到T3精校；也可以继续养霰射，或改选穿甲补裂甲组合。选目标本身不发武器，卡片不是承诺一定拾取，更不是实战命中DPS。数值沿用当前候选，真人长期趣味仍待验证。

开发观测页tools/visual-fixtures/refit-plan.html为隔离存档/虚拟时钟/正常输入与实际奖励，无World注入；focus指定待观测目标，arsenal=5仅等正常收集五件后开观察菜单。正式包不含测试页。
