# Stage271 图示科技体系

用户要求升级以图片选择，能认出拾取物、当前强化和未来能力；前驱明确，阶段性获得强科技。既有基本三路线、九个基础节点、九个分支、六组合及后期精研实际存在，但文字与入口分散。本轮将这些真实能力统一成可查看、可操作的图示体系，不伪造新能力数量，不更换或重置已有火力。

- 首次真实装备拾取后的三路线选择用大幅机械插画，顶部同一套图片显示本次装备和阶数变化，右侧三张小图展示起点、改造、强科技方向。点图先看路径和实际升级增量，再明确研究，避免误花技能点。
- 科技树分基础、组合、进阶三页，适应竖屏。基础三阶直连，分支节点展示三张能力小图；雷暴霰射另连导电线圈，实际双前驱必须同时满足。
- 节点区分已学、可研究与未来。所有未来节点可点，详情仅展开短能力说明、图片前驱和当前缺项。前驱图片可直接跳转来源；预览不推进世界或消费点数。
- 六组合页面读取实际recipeStatus：全部实际前驱满足才自动生效，未完成可设为原有构筑目标。箱子在场不算已拾取，装备实际阶数与技能等级共同决定。
- 七类进阶科技展示精调计数、T3装备或组合条件。旧规则中裂甲/磁暴/光链/雷暴精研的条件性先后顺序也显示为可点击前驱，不在所有图标打勾后突然拒绝。第三节点和进阶科技使用更大的强力插画，后期不止剩一个没有未来的百分比按钮。
- 普通精调的下一节点仍可从选择界面进入，不将预览误写为免费解锁。真实分支由World原判断选择，消耗和锁定保持。超载协议仍在技能选择与科技树可达，免费条件不变。
- 战斗中的装备HUD使用相同身份图片；既有拾取回执、组装动作、数值和五武器叠加继续保留。

美术为本轮内置imagegen原创16格机械科技插画；文本、边框、状态、连线与按钮为Canvas原生，不把整张概念截图当界面。概念与最终实现的有意差异：为实际九分支/六组合/七精研加入第三页；概念装饰性厚机框简化为现有游戏框体以保持实际竖屏可读；未学节点仅降低亮度、不隐藏未来图片；分支用组图展开以保证触控目标；全部内容按真实规则替代概念示意。详见ART_PROVENANCE。
