# Stage-196 成长节奏与入场安全余量

先补正统计：Stage-195审计只数部分reward/upgrade等事件，漏计gate-taken，25秒不是全成长间隔。新审计同时记录完整领取事件与实际参数增量（武器/T级/精校/技能点花费/研发/永久火力/充能），保留旧日志与JSON，并给旧报告加补正。旧事件子集工具改名maxSelectedEventGap且明确omittedEvents，不再输出伪全局奖励结论。

基线完整复核：种子1337瞄准/全知避险策略最大实际成长间隔20.68/19.98秒；另一个种子避险20.30秒。49.2秒单门紧跟48秒箱，而27秒双门之后的中段战斗缺少领取机会。

把原49.2秒的单门移动到39秒，保留同一个门的方位、种类、奖励数值/封顶、20/27/58门与16/48装备箱。不是增加奖励次数或另加货币/掉落系统；仍射击提高数值、穿过才结算。中段先取门、晚段再破箱/拾取并作同排装备选择。门更早挡住友弹，使后方射手有机会出招；保守避让仍需可达，不把更多子弹或按DPS抬HP当难度。

检查中发现旧版也有R6/P2/x68/t40.0167在0.45反应下无预测路线，0.4有路线。入场判定在机体推进前进行，之后的帧推进与0.1秒离散预测格可能消耗边界余量（这是基于代码顺序与诊断的解释，不是完整连续几何证明）。只对未显示的新实体入场使用0.55秒预测反应，即原0.45反应外加一格0.1的保守余量；拒绝时按原队列0.5秒稍后重试，已显示机体/攻势不改。集中参数C.spawnSafetyReaction；实际测试仍要求0.45反应，无减测试门槛。54路径重验通过。

候选效果：四组300秒完整成长间隔降到14.75/14.75/16.92/17.75秒，突破次数每组新旧均9次。简单逐目标瞄准策略HP3→1，避险保持HP3；自动结果不能判定真人难度，后续试玩仍需调整。首领攻坚和跨轮开局仍有14–18秒间隔，不要求每秒发奖励。保持精细机械门与数字/危险层级，无新素材/系统。
