# Stage284：材料身份一致与点图装配实景

先补Stage283因浏览器连接缺失的主流程证据：真实三弹芯→自动三选图→原生一次点图付费→新增蜂巢与旧双翼共存。确认未注入世界状态，随后继续检查三起手、暂停、弱档和宽屏。

实景发现材料仍用武器图：弹芯显示轨道炮、线圈显示电弧武器、透镜显示激光器。它们实际是未安装原料，却与已装武器视觉身份混用，容易延续“收集一堆但无用”的误解。新增一张精细机械实物atlas，弹芯匣/铜线圈/玻璃透镜剪影各不相同，用在掉落、拾取浮字、顶部回执、库存、各科技费用和追踪；武器选择仍保留真实射法图。光甲盾形、维修加号和已承诺奖励继续原样。

此轮只改材料呈现，不改物理、掉落数量/频率/奖励、敌人、武器时序和前驱/费用，不通过加量掩盖认识问题。生成原图/提示/导出/透明安全边和差异按实际记录。必要时按真实390px游戏画布检查可辨轮廓与数量，不以源图精细替代小尺寸效果。未进行人类理解度验收，不承诺本轮已解决全部体验。

验证页增加只观察“真实追加组件子弹刚开火”的停止条件，公开最近组件子弹来源/年龄/运动值，便于对应实际截图，不造弹、不补材料、不改变物理时钟。测试流程/截图仍标全知指针与虚拟60Hz。

绘制参数在每次draw读取当前Assembly一次，供船体挂件共用；未跨帧缓存，也不缓存试装后参数，避免装配后显示陈旧状态。测试Canvas共享稳定方法并保存已赋值属性，仍完整60Hz/正常付费/同断言，避免临时函数分配污染耗时。默认5秒的长模拟用例在本机仍波动，额外15秒只用于区分断言与墙钟，默认配置不改、不能充作性能门槛通过。
