# Stage-222 试玩

固定入口：http://127.0.0.1:5178/ 。在主菜单刷新后开始。原用户页面不会被自动刷新。服务停止可运行项目“启动游戏.cmd”或npm run play。

沿用正常射击、选门、拾取和叠加武器。后续每三章轮换追击打法：走廊可遇炮机混编/锁位猎袭，侧翼可遇锁位轮袭/游猎双哨，重装可遇折返盾炮/游弋盾炮。已有跨出击三种计划会改变先遇到的组合，不需要解锁新菜单。

优先试两种操作：抢在蓄能结束前拆炮；或者先清另一翼，再根据已出现的实弹换位。游弋炮会离开前盾，折返弹碰墙一次后回切；没有未来轨迹线。成型武器能抢拆，新增武器仍保留旧火力。

本轮人数总额保持，重点是战术差异。重点反馈：能否辨认应优先打谁、强构筑是否仍太轻松、哪章空场/重复明显。所有候选数值需要后续真人试玩调整。
