# Stage-222 轮换追击战

2026-10-17，承接Stage221。目的：让原追击增援在长局与跨局三种战斗计划中有不同战术，减少只是换左右位置的重复。不引入新货币、成长菜单或敌人素材类别。

## 固定轮换

沿用battleIndex和镜像规则。默认出击第一轮保持，第二/三轮为原侧翼/盾炮；第四至六轮进入第二组，七至九轮第三组，随后循环。已有跨局战斗计划轮换会改变先遇到哪一组。

|章节|变体0|变体1|变体2|
|---|---|---|---|
|走廊|原两批轻机|炮机混编：每批中心炮甲＋两轻机|锁位猎袭：前批锁位哨机、后批内切冲锋＋掩护轻机|
|侧翼|原双哨追击|锁位轮袭：三段双哨均锁定入场位置|游猎双哨：换位哨机＋三角哨机，直线掩护轻机|
|重装|原前盾后扇炮|折返盾炮：前盾护住一次反弹炮|游弋盾炮：后炮离开盾后横移扇射|

每章仍三段追击。走廊/侧翼18人、重装12人；走廊变体1将6轻机换成6炮甲（击杀基础分相对+240），变体2换成3哨机＋3冲锋（相对+105）。其他两章种类数量保持。所有主波次、首章、门箱与成长结算保持。旧武器不移除，敌人耐久独立于玩家火力。折返炮沿用现有固定4倍耐久和单次反弹规格；未按玩家伤害缩放。

炮机混编的炮甲和游猎的机动哨机固定初始待机0.1秒，完整蓄能仍分别0.6/1.2秒，之后恢复间隔保持。原候选使用普通2.4秒待机，在三种正常成型构筑下炮机常全部来不及发射；缩短待机是为让战术真正出现。可在蓄能期间抢拆或移动避让，不增加预测敌弹轨迹。

## 可读性与取舍

复用精细炮甲、盾卫、机动侧移结构、三角瞄准机械和折返炮金属环弹。每波使用具体战术标题/一句应对提示，描绘已发生的机体与实弹，不画未来轨迹。战斗计划、原特殊编队和首领仍保留；同一章并非仅靠变色更换敌阵。

游猎候选的摆动掩护在补给区过挤，改该变体的追击轻机为固定直线，保留机动/三角射手、人数和子弹。这是使压力可读可避，不以封死全宽作为刺激。重装另一处粗网格误判通过49点实际重放复核；生产安全规划默认25点不变，额外采样只供测试操作者使用。

本轮增加九种追击战术组合中的六种实质变体，未新增九个独立关卡。敌总数不再堆高，重点是同样规模的不同应对。整体难度、强构筑长局压力、随机/选择丰富程度和真人耐玩性依然需继续验收，全部数值是候选。
