# Stage294：能辨认武器来源的飞行弹体

短光条无法承载玩家对已装配机械武器的期待。本轮给实际弹体增加硬表面结构，保留射法本身的差异，而不再用更多泛光冒充高质量。

六种图像：铜金机炮弹芯、蜂巢三瓣微弹、细长青色磁针、紫色电容雷球、闭合琥珀爆星弹、钛环电浆核。普通翼炮沿用微弹；轨道炮/磁钉共用磁针；返航光刃保留原刀体。

读真实Bullet的source、style、guidance与速度；每个活弹只绘一个对应实体。真实反射、追踪与返航由原模拟决定，渲染不会虚构命中、增加弹数、改伤害或改变敌人生命。尾迹在弹后且长度有界，不预画敌方轨迹。能量弹两条短侧屑只为表现，弱档省略；同一个实体和中心定位保持。

源图精细金属与小核心结合；两次生成的整体透明图保留。图集按整格导出，不擦除alpha或手绘。生成图居中有偏差，使用测量枢轴将真实弹体中心置于Bullet位置，再按实际方向旋转。具体像素与许可来源见art/FLIGHT_PROJECTILES_V1.md。

顺序保持：友方弹体→敌机/友方特效→飞船及判定点→敌方危险。不会扩大碰撞，也不能让装饰挡住红弹和HUD。手机原尺寸和宽屏弱档按实际渲染复核；测试和静态图不代表人类趣味或设备FPS。
