# Stage-157 挑战履历与下局目标

刷新 http://127.0.0.1:5178/ 。服务停止时双击“启动游戏.cmd”，保持窗口运行。

主界面打开“成就”，在成长/构筑/战术三组中选择未达成目标。追踪不花点、不改变伤害，可随时取消；主菜单与本局战绩会提示所选目标，完成后保留已达成状态，等你选择下一项。

新增三项：
- 王牌猎手：主动接取双线王牌，击破两名目标。
- 交火零伤：接取之后不受伤，完成双线王牌；接取前的受伤不影响这项挑战。
- 构筑全才：完成三种不同的构筑检验，可以分多局；重复同一种只算一次。构筑组会显示已认证类型和进度。

每轮前40秒可接取挑战契约；王牌建议准备T3或多种火力。认证按真实检验完成记录，单纯解锁组合、接取或领取奖励不会制造认证。无需登录，不增加局外攻击力。

旧分数、设置和既有成就保留。旧版只有通用检验勋章、没有记录具体类型的，不猜测补算；页面会说明需重新认证类型。所有记录仍在本机。
