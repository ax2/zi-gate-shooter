# Stage-232 领取信号与战术提示避让

承接Stage231新增敌量，改善密集战斗中的奖励理解和危险可读性。本轮是表现层修订，不增加系统、货币、自动拾取或未来敌弹轨迹。

1. 装备仍为原始机械模块素材；在实际掉落物周围画局部黄铜角框和短弧，不用大光柱覆盖敌人。距离玩家纵向180px内，标签改为快拾取并增强角框。弱档保留识别框和文字，减弱亮度变化。
2. 领取窗口严格到playerY+pickupRadius=1076，和当前52px扫掠圆碰撞的下边界对应。它只说明尚未滑过，不能保证横向一定赶得及。超过下界撤下拾取/组合指令、取消角框，模块以30%透明度退场；不补发、不延长领取范围、不改同排互斥。
3. 普通战术notice沿原2.2秒有效期，优先原上下位置，只有保守包络未占据时才显示。实际敌机/装备标签/已发敌弹占据两区则暂略；首领或悬赏只用底区，避免盖血条与核心。过期战术信息不排队重放。既有装备回执/组合反馈仍走自己的续读队列。
4. 掉落物包络区分实体和标签：尚可领取时保留完整标签范围，已经滑过后只考虑淡模块；模块出屏后不为不存在的标签继续占位置。其他机体继续使用原保守美术包络。
5. 已赚到的成就奖章也让实际实体和敌弹，阻塞时保留至少3秒余下读时。授予/保存/目标追踪和计数不变。这种永久奖励可等待；短战术信息不延迟，是两者的关键取舍。

本轮不降低上一轮敌量，不调整武器或奖励值。保守包络仍可能短暂省略一条提示，优先可操作目标与危险；不能以这些修订认定内容或真人刺激感达标。
