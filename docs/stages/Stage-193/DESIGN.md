# Stage-193 爆炸层级与余烬

目的：真实击破既有冲击感，又给多枪材质和危险信息留出对比。沿用原创9格explosion-v1火焰贴图、原机械残骸与火星，不增加商业素材/依赖/系统；World、伤害、成长和所有原事件不改。

贴图透明包络改为短热芯+低覆盖余焰，开端标准约0.84，标准爆炸0.45秒的前0.22寿命后只剩余焰包络；原贴图帧序列保持。取消普通爆炸中心的填充白盘/泛光层，前0.12寿命用小热环和短热划。以4/7段向外展开的断裂边缘承接爆炸轮廓，标准档带短边细线；2/5片有暗钢面的冷却余烬外抛，尺寸封顶3/5。弱/标准的差异用于控绘制量，不增加粒子池。

顺序改为爆炸→火星→EMP/真实连锁→实际命中材质，后续敌弹与HUD继续末层；钢片不再被随后绘制的加色火星漂白。局部爆炸线限制在战场区，不画未来轨迹、不增加范围伤害暗示。真实离子/电容组合保持各自专用爆发，裂甲保留原叠层；首领专用解体保持。

取舍：强光持续时间缩短，靠外缘、纹理和实体切面承担余波，避免用更大光块充当酷炫。此改动不等同整体音画达标，也不增加长期玩法内容；持续目标仍包括战术、奖励与多局体验。
