# Stage-229 试玩

固定入口 http://127.0.0.1:5178/ 。服务停止后用“启动游戏.cmd”或npm run play，保持窗口运行。

光学路线选好初始灼热/分光/折返，升到3阶并累计6次光学精调后，下一个光学点可“双镜复合”。若光链精研已满足而未选择，会先处理原光链精研。两张卡只提供未装的两种镜组；选择保留原镜组并追加一种，同时包含本次普通精调。返回不扣点，选择“仅做常规精调，稍后复合”会消耗一点精调，但保留未来复合机会。

灼热＋分光兼顾主束重敌和侧翼，灼热＋折返可利用走位拓展斜光覆盖，分光＋折返同时拥有两种侧向光路。没有更换原武器，原间隔和贯穿保持；也不重复缩短一次冷却。暂停→当前火力与参数查看双镜名称及两种参数，技能树查看已装镜组；继续打箱、穿门与充能成长。

数值仍需真人试玩，不保证所有镜组对每种敌阵同样有利。完整冻结目录build/playable/Stage-229，启动该目录serve.mjs可使用备用5312；本轮实际冻结与服务核对见TEST_REPORT，不生成ZIP。
