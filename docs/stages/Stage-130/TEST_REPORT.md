# Stage-130 中断归因验证

## 实际证据
独立静态探针5206不加载游戏/素材/音频，每次12秒。frame-clock.js记录rAF间隔、当前回调执行、100ms定时器与页面生命周期；完成状态保存到sessionStorage。

|范围|rAF样本|间隔P95|最大间隔|最大探针回调耗时|
|---|---:|---:|---:|---:|
|初版DOM更新（尺寸未写入原记录）|2855|4.5ms|21.1ms|0.2ms|
|Canvas，810×1084/DPR1.25|2857|4.5ms|24.2ms|0.3ms|
|Canvas，390×844/DPR约1|2849|5ms|24.4ms|0.3ms|

三次均hiddenfalse、focustrue、无记录到的生命周期切换。仅是短时控制测试，未包含游戏资源/音频/复杂绘制。
真实游戏默认视口记录game-desktop.json：playing29.8667秒，间隔P95约4.4ms，回调工作P95约0.6ms、最大15ms，无中断。随后game-after-input.json记录paused57.5333秒，802.3ms间隔、前次工作0ms、已测最大仍15ms。观测位于输入/视口切换附近，但未记录到足够精确事件关联以证明因果。

结论：已有数据反驳“游戏回调本身执行了约1秒”这一简单解释；不能证明全部浏览器/GPU/系统工作都很轻，也不能证明输入或视口必然是原因。根因和连续交互仍待定位。
