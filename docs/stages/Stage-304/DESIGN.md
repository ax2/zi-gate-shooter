# Stage304 设计：材料成为完整武器配方

## 核心交互

先通过图片选择基础组件，后续真实收集的材料足够完整目标时，强化页优先显示这套配方的大图、攻击示意、直接前驱图和累计费用。确认“装好这套”会一次装齐缺少前驱与目标，立即启用它们的真实攻击；玩家也可以选择其他小件、暂存材料或查看完整路线。

强化页“查看完整路线”直接进入当前追踪目标的图示路线；返回选择不付款、不丢弃原选项。确认装配按一次正常强化计量，关闭路线回到原战斗或暂停。已有直接前驱显示✓。图示路线页保留每个节点/多个前驱与未来科技。选中目标后，总材料够时可“连装N件”；不够时仍能逐件购买可装节点。未来终极/突破通过现有科技树明确选图追踪，再用同一配方机制，不自动选择或付费。战斗暂停期间预览与确认均不推进世界时间。

已有双翼炮和蜂巢副炮时，蜂巢爆星的四个缺件为反弹弹芯、轨道炮、爆裂弹仓、蜂巢爆星，合计16弹芯/5线圈/1透镜；已有的组件不再收费。磁钉阵列通向磁钉雷网的三缺件是电弧发生器、连锁电桥和雷网，合计6弹芯/8线圈。由当前库存和当前已装节点实时计算，不使用固定演示价格。

## 真实事务

assemblyRecipe按依赖拓扑去重，累计每个缺少节点的原价；已装目标仍只作为一次原价精校，不重新收前驱钱。applyAssemblyRecipe先在私有Assembly副本用既有install依次验证所有前驱、分支锁和费用，通过后才提交钱包/已装/精校字段。任一失败不动真实状态；World层仍拒绝死亡时付款，普通单件API保持原语义。

整条互斥路线连共享前驱也不应误导付款，因此路线总锁同时约束图片按钮和动作入口；玩家若想独立研究该共享科技，应从对应的可行科技界面明确选择。重复连装按钮和离开后的旧动作拒绝再次扣款。预览返回的数据不能修改下一笔真实事务。

旧组件/原有攻击/已有精校全部保留；花掉的是库存，实际累计拾取、主炮成长和已经发射的弹不撤回。没有新材料种类、额外免费科技、装备替换或随机重置，敌人HP/奖励/攻击规则不改。更强效果来自玩家付清已有路径而非新增伤害倍率。

## 图像和反馈

卡片画大目标、可动射法示意、两个直接前驱和“连装N件”；最多三类材料用真实总价和压缩格表示。三费用行上移到880/905/930，留出949按钮间距，避免第三类材料被遮挡。路线面板则显示所选节点整套费用，装配后图上所有新节点变为已装。

顶部真实回执显示目标、一次新增的件数与目标攻击参数；没有把多前驱当作多次免费抽奖。终极示意按现有参数展示六翼、双源电弧和八束日冕，给出“演示”标识，采用紧凑距离；它不是伤害模拟或敌人预测线。六翼子弹分开展示并标发数，避免起手重叠看成两发。复用既有原创机体、弹体与科技图，不新增分发素材/字体/依赖。

## 取舍和未证实部分

没有增加武器种类或新经济系统，本阶段让既有进化/终极/突破更容易成为实选内容。前驱依然真实存在、可查看、逐件买也可行；整体费用和理论可达火力没有打折。自动流程只是可达和计量证据，不证明真人已经理解、觉得爽或长期有趣。素材拥挤、手机文字辨识和整体长局平衡仍需真人反馈。

所有既有数值仍候选；平台、上架和真机继续后置。验证包括原子边界/费用/互斥、真实六套正常实收与新增攻击、单件旧规则完整对照、手机/桌面弱档实际Runtime离屏。浏览器连接仍缺失，不能冒充原生点击、听感或FPS通过。
