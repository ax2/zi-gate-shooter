# Stage315 机械安装体设计

轻炮：金属圆转台/外露支撑/三管头；重工事：低矮厚装甲/散热器和护盾电容/扇射头。各有底座与可旋转头，4格一套原创透明kit。银灰/深蓝钢与铜管，微磨损高对比边缘、内敛青色电容，不烘焙大光雾/字幕/地板。物体轮廓与地面接触明确，弱档保留金属实体和弹芯，降低粒子。

渲染锚点/炮口依生成源实测，不盲设中心；同一纯几何模块供模拟发射与画面使用。轻炮保留瞄准3发，重工事保留固定向下7发慢扇；头部朝向对应真实发射规则。后坐依据实际最近发射时钟，满池零发没有后坐/枪声，计数只计实际弹。原弧盾/损伤条适度保留，不用矩形卡片包裹整个机体、不逐个常驻名称；不画未来射击轨迹。

候选尺寸须经原生截图与命中核心可见性检查，不宣称真人签收或设备性能。若工具失败，不切换API/CLI，依skill记录限制并继续可独立工作。
