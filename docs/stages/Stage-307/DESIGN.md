# Stage307 设计：不同空域的真实飞行远景

舰队海域以深色海面为中央战场，侧边为大型舰体；磁暴云海用蓝紫厚云和远处感应塔；轨道巨构用轨道环、星空和低处行星。三图不是碰撞地形，不增加隐藏危险或可穿越墙。飞船、敌人、掉落、数字、弹芯继续前景绘制，不借背景提高敌人难度。

每张原创源图1024×1536。内置imagegen逐图生成，完整提示、原图路径、原始SHA和运行图SHA见art/flight-environments-v1.json。保留原PNG，sharp整图等比缩至720×1080、JPEG84；不裁切、重绘或覆盖旧美术，三图合计378882字节。制作候选不等于用户签收。

运行宽744，相对720世界留12像素边缘，玩家横向视差最多8像素；速度100/74/60世界像素每模拟秒，1280高战场裁切保护长屏黑边。144像素重叠段分32条（弱档16条）渐变；循环周期使用图高减重叠。仅背景在真实选区后0.9秒先淡暗再淡亮（前半旧图、后半新图，所有循环块先完整合成，防止接缝区重复透明度），待选时保留上一区，暂停不流逝，重开从0开始。中间与边缘透明暗幕保留主弹和危险对比。选区预览用相同图片并按真实比例取景。

发现原渲染中同位置分裂弹外壳遮住先画亮芯，新增所有敌弹最后统一绘制碰撞中心亮点，半径2至3世界像素，既保留原弹壳材质也使重叠核心可见。不是射击预告线，不改变碰撞半径、生命、轨迹、出弹预算或经济。统一亮点只改善已存在弹体的渲染。

验收边界：按实际Runtime离屏图判断构图/遮挡，以独立背景合成图判断接缝像素连续性；两者分目录。完整状态对照包含原Bullet/Effect/RNG/序号，不用删字段方式消除差异。浏览器原生交互、设备帧率、真人画面/趣味及长时间辨识仍待实测。
