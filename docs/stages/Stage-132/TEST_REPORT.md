## 实现

闭合盾卫不积裂口，邻近盾卫仍依正常规则减伤；奖励物不积裂口/不受派生爆破；HUD外目标、首领入场不受派生爆破。派生攻击直接结算，不再触发折射、跳电或裂甲。裂口在敌人对象上，重开不残留；不新增弹丸实体。
局部裂纹和三格刻度提示积累；引爆使用已有原创爆炸图，另加分段冲击环与程序绘制金属碎片。四爆炸上限保持，组合爆破可替换普通爆炸，避免在满预算时丢失关键反馈。弱档减弱光照/碎片，敌弹和数字仍在上层。新增断裂冲击合成音（150ms播报限频，沿用12声部上限）；未做主观听感验收。
配方页由暂停→当前火力→组合配方进入，显示雷暴霰射、棱镜激光、裂甲爆破的真实条件/状态/效果。满足条件提示组合完成，旧火力保留。成就“裂甲工程师”需单局实际触发10次，写入已有本地成就存档，不增加局外攻击力。
