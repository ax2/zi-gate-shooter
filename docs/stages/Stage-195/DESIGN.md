# Stage-195 奖励审计与三角哨机

基线发现：普通敌击破主要得分，其他成长奖励最长间隔约25秒；但给“正在蓄能普通射手击破”加8充能的候选在两条300秒策略中都只会触发3次，因此本轮取消该奖励候选，不增加另一个难以感受的微小计数。奖励空窗和真人难度仍是后续问题，不能把本轮攻势变体宣称已解决它们。

选择深化能实际开火的斜射哨机。仍占用原侧翼章23秒的一名狙击位，不加数量/生命/速度/掉落或额外子弹。在battleIndex>0的侧翼战况换为“三角哨机”；默认出击的第一侧翼仍保留原同点三连，后续轮次/跨局战况轮换时可遇到变体。

首弹对准不可变入场锁定点；第二、三弹分别瞄向固定叉开的两个道路点。间距候选160，边界向内调整，三个点都在合法道路且两两间隔至少80。不是动态追踪。后两发各经过0.1秒间隔与0.55秒真实蓄能；三发后或10秒截止撤离。原三枚、620基础弹速（沿用轮次倍率）、已发弹保留，击破可停剩余射击。EMP只暂停并重新蓄能，不改锁位/发射次数/旧弹，不重置成额外三连。

同一lockshotProfile与advanceBody同时用于实战和保守路线预测；不另外画预测轨迹。外观在原精细机械哨机上增加三腔钢质供弹架与实际已发弹指示。炮管充能时转向当前目标；发射闪光/回弹依照已接受子弹的真实方向，不能画到下一发方向。拒绝发射时无伪回弹。原名牌变“三角·蓄能/撤离”，战场引导介绍先制拆炮或待实弹通过后回中路；优先规则保持。

已有先制拆炮/诱射反击技巧成就沿用真实同源弹通过与伤害计数，不新加成就数量，不凭生成波次授予。多武器/组合/主动改装/箱门结算均保留。

取舍：增加一类可读的瞄准难题，避免仅堆敌人或按玩家DPS抬HP；让熟悉原同点连射的玩家重新选择移动节奏。自动路径证明可反制和正常可遇见，无法代替人类难度、趣味、节奏与动态音画验收。
