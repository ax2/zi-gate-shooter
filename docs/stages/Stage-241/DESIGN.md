# Stage-241 门后反压

补重装章有证据的27–33秒节奏空段。与已有“前盾后炮”重复叠盾不同，本段围绕原27秒双数字门：先清近屏，再在充门时处理门后错时实弹，穿过才结算，之后追清炮列。只追加重装章6人，其他章节和所有原排程/奖励定义逐对象保留，不改变武器或敌方按轮次固定HP曲线。

28.8秒首炮Y300，29.05/29.17秒近屏2轻机Y680；30.1秒后炮Y350，30.35/30.47秒后屏2轻机Y500。第一炮opening0.1＋完整0.6蓄能，第二炮0.35＋0.6，实际首发间隔1.55秒。普通炮163.2HP（第三章固定曲线），可被正常强火力或派生能力抢拆，不锁血演招。三战况为锚炮→横移、横移→锚炮、双横移，镜像连同目标一起变化。自然越过Y600停火，每炮实际最多1轮3发，不另写无限驻守。

门仍会吸收正面弹丸，不能当作已经拿到升级或免费穿透后排；近屏在玩家与门之间可先清，后排需要充门、避弹和转火取舍。已有跳电/派生能力若抢拆成功允许减少压力。原27秒双门同排只领一份，门消失和能量变化以World实际事件为准。没有新货币、经营、武器树或预画未来轨迹，使用现有精细机体/真实发射/实弹与命中表现。

所有时点/位置为候选。近屏的投送屏障0.45秒保留，完整450ms逐敌观察无射击路径验证；生产admit/预测算法不改。中门固定站桩可额外挨弹，但实际脚本换位仍能领门，不能把增加命中当强制掉血。当前测试边移时间是脚本预知，不等同真人反应验收；旧有碰撞/炮弹伤害与新增反压命中分开。

固定普通耐久与原奖励定义让强火力仍有价值，同时利用门遮挡形成章特征。正常长期实得保持不代表所有具体门都必领：实景默认领+60，而双横移保守AI本次错过原门，必须保留失败并检验旧版和主动路线。不为了“全绿”删除炮列/扩大拾取/自动领奖。数字、机体、实弹的清晰度按实际手机/桌面/弱档截图检查，不能只看排程表。
