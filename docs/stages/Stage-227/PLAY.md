# Stage-227 试玩

固定入口 http://127.0.0.1:5178/ 。服务停止后用项目“启动游戏.cmd”或npm run play，保持窗口运行。

投入雷电路线，在第二节点选择电容蓄爆。电弧直击积电，任何武器击破带电敌人都能把已有余能接给220内近敌；电弧主弹直击击破额外产生1格。最多接到2格，接力不造成伤害。继承1格还需两次直击，继承2格还需一次，满3格追加原200%蓄爆。无合适目标则耗散。

目标三颗电极显示实际电格。暂停→当前火力与参数，电弧行右侧看接力/蓄爆次数；总蓄爆含未继承目标，不把两种次数当作同一收益。保留原武器、组合、打箱与穿门结算。现有开场敌阵、追击变体和重装旋扫炮继续生效；本轮电容协同不代表敌方难度已完成调整。

冻结build/playable/Stage-227，node build/playable/Stage-227/serve.mjs可启动备用5310；46资源SHA256一致，备用服务本轮未启动，无ZIP。数值仍需真人试玩。
