# Stage-227 电容余能接力

2026-10-17。沿用电容分支与原三格追加200%直击伤害，完善累积武器的协同，不新增货币或系统。

任何友方伤害击破已有电格的敌人，都可把已有余能交给220内最近、可受击且未满2格的敌人，等距按id。只有电弧主弹直击击破额外产生本次1格；跳电、其他武器和派生攻击只保留旧格，不产生新格。转出、接收均最多2格，没有立即伤害或免费爆炸；仍需后续真实电弧直击把接收者推到3格。蓄爆先清空自身格数，避免重复转出。

链式击破可以继续转移同一份余能，但接力自身不攻击、不造格。参数中的回收格数是累计送达量，可能重复搬运同一格，并非新产生能量。无目标则耗散，不存到玩家。箱门、拾取、闭盾、投送保护、y240–1024以外和非战斗首领不可接收，满2格跳过；首领胜利后停止。已带电目标后来闭盾，被击破时可保留旧格，但闭盾直击不增加一格。其他武器和奖励结算保持。

沿用三颗实际电极；接力增加0.24秒碎线与正常3颗/弱档2颗移动光粒，复用12条电弧视觉预算。视觉被预算省略不影响物理。不增加敌人未来轨迹或全屏遮挡。电弧参数行显示接力与总蓄爆次数，分支卡/选择后的强化提示明确满3格、200%、范围与最多留2格。

否决最初“仅电弧直击击破才继承”候选：叠加武器常抢先清掉带电敌人，两个600秒样本继承后仅2/0次蓄爆。最终任意击破保留已有格，首章即可发生可观察收益，仍不等于无限自动清屏。多数接力未形成后续蓄爆，长期收益需真人试玩。所有数值为候选，本轮不修改敌方难度，整体难度/重复问题继续。
