# Stage-137 弹道分支与装甲队形验证（2026-10-15）

## 内容与规则
弹道第二点提供贯穿弹芯/爆破弹芯二选一，两者保留原霰射总伤害+30%、所有已有武器、弹数/扇角/射速、第三点雷电前置与雷暴组合和后续精调。
- 贯穿：每颗霰弹最多真实命中2敌，连续轨迹和每敌去重保持；箱子、门、闭盾仍吸收弹丸。第二敌实际接触有短促穿出亮痕，不用闪电表示不存在的电能力。
- 爆破：真实命中敌人后，在140范围对邻敌追加50%该发直伤，不对主目标重复加伤，不递归、不充箱门、不打场外/入场首领；闭盾不向邻敌传播。旁边闭盾仍按自身减伤受波及。复用原创爆炸图集与金属冲击环，使用更轻、150ms限频的独立声音，不增派生子弹。
第二节点生产明确选择，浏览/返回不花点、模拟冻结，跨路线分支无效，本局不可改选。树回显已选分支，参数页显示贯穿数或范围/比例。原无UI选择默认贯穿，兼容旧规则策略，不提供生产赠点接口。
第二章起35秒追加两名普通同轮装甲：侧翼章/后续走廊为x300/420紧群，重装章为同路x220、35/36.5秒错峰纵列；位置随原章节镜像。每个仍逐个通过现有安全入场、实体预算和重试，不加动态耐久，不宣称成对原子同时出现。它们为弹道几何提供目标，也增加优先清除的威胁；第一章不变。

## 修复派生伤害阶段保护
检查发现旧跳电、速射折射和爆炸邻敌分支没有统一排除入场首领。本轮三处均补phase检查，实战首领照常受击；新霰弹爆破同样遵守。规则测试用真实敌人邻近入场首领、不同武器真实碰撞验证，不靠UI描述。
