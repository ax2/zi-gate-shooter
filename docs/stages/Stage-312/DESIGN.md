# Stage312 磁轨成长设计

新机库独立主武器磁轨Lv1–5：1/2/2/3/3轨，间隔0.85/0.80/0.75/0.70/0.65秒；Lv3起最多贯穿8敌，之前5敌。单轨伤害基于76×原弹道强度，双轨各0.65、三轨各0.55，Lv3起乘1.35，避免只靠弹数导致跃升过大；实际总伤/秒逐级上升。价格、槽和存档格式不改。历史非机库轨道炮仍1.1秒/单轨/5敌，不获得新反馈或升级。

Lv5只有标记的磁轨主炮实际接触敌人会累计12次；命中盾也属于接触。同一弹敌对通过hits集合只计一次，空气/副炮/旧普通弹/反射/突破子弹不计。12次后发三轨扩散突破，单弹为当前普通磁轨弹2.5倍、0.8秒触发冷却；子弹预算不足保持就绪但不部分发射或假播枪声。普通齐射也整组准入。弹道从当前主槽实际炮口发出，左右2主槽不再误对中心。

最后0.23秒蓄能两侧线圈亮起；实际发射后短炮口离子碎屑、原机械弹头与最多80逻辑像素的后向电离尾迹，弱档保留弹头与细芯、减少碎屑。效果寿命0.18/突破0.36秒，hostile核心仍最后绘制；不预画敌方弹道。小HUD显示轨数、Lv5命中/12或短突破字样，会避让当前敌弹/机体/敌人，首领条优先。

保留已装备磁轨的冷却与蓄能提示标记，买外观/护甲不能重置更快开火；卸下清掉命中进度，买回/换回保留资产等级，但本次计量从0开始。暂停/帮助/机库/失焦完全冻结模拟和炮口状态；重新出击恢复资产、清本局计量，死亡不再发射。

新增原程序音效charge/fire/burst三组独立包络与限频，保留总12声音节点预算；是代码/事件与故障测试，不等于实际设备听感验收。未生成/修改素材，复用原创projectile/impact/mechanical图。数值仍为候选。
