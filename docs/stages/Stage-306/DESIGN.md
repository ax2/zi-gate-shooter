# Stage306：磁雷后续轮换的折返截击

后两种磁雷cross（pattern4/7）在完成原440横穿后，再用3.2秒返回一次，分别下降110/180，再向下退出。左右进入/最初cross不变。通过全场移动，玩家可以侧绕、上移或尽快击破发射者，不能只按一次固定横移理解整场。

每次双枚追弹替换原双枚直弹；实体绿色外框表示可射落，发射自两侧机械吊舱。1.05秒有限角速率制导后保留当时速度直行，3.8秒寿命并保留出界清理；发射间隔2.2秒。原HP/击杀与拾取奖励/波次排程/容量不变；停留延长可能改变同时在场数量和整场发射机会，不宣称总难度不变。

追弹沿用orb真实扫掠接触，普通友弹可击落，光甲可挡、护场可反射。击落不刷分/掉料、不触发攻击科技；反射清除追踪/敌方标记。已发射的弹不会随发射者死亡直接消失，仍按自己的短时追踪/直行/有限寿命处理。

截击机使用既有原创机体，加金属吊舱和折返状态标识；弹体用原机械细长弹壳和真实中心pivot，尾焰只向后，制导结束变短/暗。危险最后绘制，弱档保留实体/可击落外框/白色碰撞核心。没有预测弹道或大范围发光遮罩。选区图片卡和无障碍文字直接说明折返/可击落。

独立记录实际发射和实体友弹击落数，不把电极拦截/光甲/到期冒充这些计数。两条QA刻意只装基础副组件与改装，用于观察完整动作；一条正常组装猎镜/日冕/焚星，确认成长和旧火力共存。素材/依赖/经济系统不新增；数值候选，真人趣味和设备性能未证实。
