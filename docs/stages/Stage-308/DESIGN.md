# Stage308 设计：三拍折光扫射

只修改棱光精英后续variant1/2，首轮variant0保留固定斜束，另外两类精英保持。每轮首发锁定玩家当时方向，夹角限制朝下方；三束围绕锁向依次-0.34/0/+0.34弧度，顺逆取决于轮换及入场侧。每拍0.22秒、间隔候选0.34秒，整轮约4.2秒。炮机移动只改变实际炮口，不重新锁定后两发方向。击破/离场/死亡阻止未发后续；已发光束是独立有限危险，仍自然消失。原HP、人数、分数、2份实物配件、累计主炮成长与已有武器均保持。

炮口由prismMuzzle共享，机械转台复用原创mounted-modules图，附三枚钢质棱片和余量灯；灯是本机拍数，不是未来射线。新光束暗色外描边/橙色实宽/亮色中芯，正常/弱档都保持实际有效期对比，不随年龄提前淡成不可见；弱档去外光。选区预告移位或抢拆，精英入场提示三拍锁向，不加弹路预告。

攻击记录包含真实施放数、脉冲数、拍序、方向、时间和发射者；诊断拷贝独立，不允许外部观察修改待发状态。只复用已有Effect预算，最多一个本机短束同时存在，不加后台、资源或额外经济。参数待真人试玩，不把全信息自动驾驶生存当难度签收。
