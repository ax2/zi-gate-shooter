# Stage-86 盾卫（进行中）

制作第6类普通/精英敌人：闭合减伤、展开预警后扇射，暴露窗口仍受全额伤害。原有子弹最近命中规则保持，闭合装甲能挡住穿透弹；不是无敌单位，持续射击仍可击杀。第二/三章替换一部分重甲，避免单纯增加密度。候选数值与美术未最终签收。

## 实现
- guard候选64HP/60分、100×108碰撞、100/秒推进。闭合时50%减伤并消耗穿透弹；展开0.8秒预警、三路扇射、0.8秒暴露后摇，再闭合2.4秒。y650后不再射击，仍可被击杀或离场。
- 减伤与穿透阻断都读取同一guardClosed规则；所有子弹保持最近命中排序。弱点暴露并非额外倍率，只恢复全额伤害，不将盾卫设为无敌。
- 第二章38秒重甲、第三章35秒重甲和第二套中央纵队前排替换成盾卫；保留奖励窗口和总密度。
- 原创三态图（闭合/展开/破损）由内置imagegen生成，2172×724透明源图和完整提示词已保留；导出768×256/327836字节，第三帧独立残骸图。三格均通过3px透明边界检查。专属图和装甲/弱点文字接入正式Canvas。

## 验证与修订
- 网页构建及类型检查通过（189ms）。初轮26项中24项通过、2项死亡夹具失败：旧夹具用4伤害击杀4HP盾卫，正确减伤后剩2HP。修订为2HP真实致命命中，未修改减伤规则来迎合测试。
- 修订后guard/enemy-wreck/encounters共23项通过（658ms）；包括穿透弹是否打到后方、0.8秒预警/后摇、组合可达路线、近身取消射击、残骸与奖励危险层级。
- 初轮的三种子各20分钟正常成长规则模拟均通过（同组总耗时7.95秒），死亡夹具修订不改变生产规则。
- 实际390×844标准档展开图、1280×720弱档闭合图：盾片/橙色核心区分明显，弱点暴露和装甲减伤文字可读，扇射预警与在途子弹清晰。使用预置T1盾卫夹具，非自然章节真人试玩或设备验收。
