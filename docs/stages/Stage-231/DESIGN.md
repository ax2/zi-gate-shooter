# Stage-231 连续增援与轮换攻势

用户反馈：敌少、难度低、章节重复。本轮直接调整普通敌阵，不增加货币、模式或成长系统。

- 首章10秒、21秒两段由各6人增至9人；该三段增援合计24→30。仍有清晰两外侧道路，不提高敌人HP，不按玩家伤害追涨。
- 后续走廊第一段12→16人，三段合计36→40。三战况分别为纯机群、轻机夹两装甲、轻机夹锁位哨机与冲锋。玩家要清翼、穿列或抢拆后哨。
- 侧翼第一段9→12人，三段合计27→30。四批交替内切；后续战况第一批改锁位哨机或机动哨机，后接冲锋，目标优先级与转火不同。
- 重装第一段9→12人，三段合计27→30。锚炮＋横移、折返＋横移、双横移三种组合。折返炮放在13.6秒第三梯队，不能与第10秒旧炮一起封退路；初稿两条无解观察路线因此被修订。
- 战况沿已有跨局次序与每三章轮换，无随机拼凑和未来敌弹轨迹。原箱碎后拾取、门穿过结算、同排互斥、叠加武器、首领和其他波次完全保留。

美术沿用原有精细机械资产：炮机与轻机能靠机体/蓄能/实弹分辨；不加遮盖数字与危险的大面积光效。入场使用既有护盖与提示。各参数仍候选，九种组合并不等于长期重复已解决。

取舍：固定增援能让火力兑现，同时也让不走位的操作更容易失败。额外压力可能挤压拾取和成长空档；已保留新旧实得数据，继续真人检验。不实施额外技巧充能奖励，避免这一轮同时增压、补偿而无法判断原因。
