# Stage-153 首领半血双炮反击（2026-10-16）

## 设计取舍
正常600秒三种成长策略的基线21场首领，大多只完成一次招牌攻击，部分后续弹道场仅2秒多。新增固定半血过热阶段，保持首领HP/伤害/奖励和玩家能力，不按DPS抬血、不加无敌门槛拖播放；高火力仍可快速击破，不能保证每次都见到全部新招。

HP首次≤50%进入过热。已经开始的旧蓄能/第二拍继续，已经发出的弹丸不改速度/位置、不删除。空闲时或旧招结束后准备0.15秒，下一招双炮蓄能1.1秒，从原画真实双炮位置各射三发斜向扇弹（最终vx -180/0/180，vy480，再按已有轮次弹速换算）。后续固定章节过热短语保留原招并夹入新招，休整1.8秒。不通过尚未显示的安全准入时保留第一次反击排队，0.3秒后重试，不能吞掉该新招，也不改已经显示的攻击。

三机体用各自炮口偏移（±96/+110、±120/+90、±76/+76）。渲染在原精细机体上增加狭窄热鳍、核心环、炮口蓄能增长与真实发射短闪；弱档保留核心和炮口，去掉细碎热流。不画未来轨迹、无全屏闪白、无新增纹理/粒子实例预算。HUD标“过热”，阶段回执在底部，危险弹在光效/奖励板之后绘制。

## 安全与边界
18项受控观察：第1–6轮、左中右起点，半血开始、20秒、移除本方弹丸、无杀敌/免疫，初始与护卫新入场450ms反应。均HP3、0击杀，实际多次反击，最终峰值总弹30（慢速候选曾31）。另6项在第4–6轮2秒/4秒已有敌弹时穿过半血，保留原弹后仍实际HP3；transitions记录原弹数。不能把受控HP设置称正常成长，也没有重跑400种子全场景。

第一次新招准入拒绝的受控单元用mock强制一次false，确认排队仍在；该mock不作为安全证明，自然路线由上述24个真实模拟场景验证。入场不进入过热，预测不改原实体，旧招第二拍的实际时刻与形状不被半血截断，阶段持续性/暂停/重开与敌弹叠层另有规则/渲染检查。
