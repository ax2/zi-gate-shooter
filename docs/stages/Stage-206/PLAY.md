# Stage-206 试玩

固定入口http://127.0.0.1:5178/，请回菜单后自行刷新；用户当前对局不会被自动刷新。

暂停→当前火力与参数→实战贡献，可以看本局武器与组合实际打掉的敌方血量。若出现“下一页”，第二页能查看其它已经生效的组合；返回当前火力再返回暂停菜单即可继续原对局。战败后的本局战绩右上也有实战贡献，返回后仍可再开一局，重开清零。

数字是累计实际伤害，不是理论DPS或命中率；组合派生与原武器分列，不重复相加。比较不同路线时要留意取得装备的时间与遇到的敌阵。所有候选强度仍需试玩调整。

隔离工具页tools/visual-fixtures/combat-contribution.html使用虚拟时钟和内存存档，正常爆裂开局/触摸操作者/赚点/选技能，600秒停点；继续至战败只改操作者为固定瞄准中央，不修改World或直接设置死亡。工具页不含在正式构建。
