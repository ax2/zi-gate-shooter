# Stage-206 本局实战贡献

玩家需要知道叠加的武器和组合是否实际发挥作用。现有参数页是理论直伤，不能回答雷暴、裂甲、磁暴、光链等效果真正贡献多少。本轮增加暂停→当前火力→实战贡献，以及战败战绩→实战贡献，两种入口共用本局数据。

统计只累计敌人减伤后真正减少的HP，过杀只取剩余HP；不计箱门、投送保护拦截、已死目标或减伤挡下部分。每个实际扣血事件只归一个来源，最后一击单独计数。5种武器、激光、雷暴、离子、裂甲、磁暴、光链共11类上限；没有逐弹日志或额外持久存储，重开新World清零。

原始武器直击与其普通分支仍归原武器，例如跳弹霰射归霰射、电容蓄爆归电弧；额外组合伤害单列。原有weaponKind承担撞击材质等作用，不改它来统计激光/组合，而是传入独立只用于计数的来源。ECMAScript私有计数器不进入World的公开序列化，不参与随机数、寻敌、伤害、奖励、成就或存档决策。快照返回副本。

页面按实际伤害排序，每页6类，显示累计伤害、占比条、有效作用次数、最后一击次数和一句打法说明。只显示已有武器、已解锁激光或实际生效的组合。没有有效伤害时明确提示。看报告时战斗冻结；返回保持原暂停/结果上下文。累计装备时间和敌阵不同，不能将占比当作DPS或平衡排名；页面直接说明这一限制。

本轮是反馈与可理解性改善，不宣称增加了敌人种类或解决无尽后期重复。后续用玩家实际构筑和战斗取舍继续调节，避免把重复记录和大数字当作耐玩性完成。
