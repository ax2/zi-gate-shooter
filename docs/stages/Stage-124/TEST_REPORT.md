# Stage-124 棱镜激光组合
光学三节点与弹道首节点联合解锁两束侧向激光，各45%主束伤害；中央主束和既有武器保留。三束各自按从近到远命中，箱门/闭合盾卫吸收，沿用贯穿数量上限；侧束从机体两侧42px向上展开至180px，显示紫色细芯、流动光点与发射棱镜，主束青色。参数页显示组合伤害，技能树末节点写明条件。未添加额外武器实体或独立升级货币。
验证：75项支持武器/技能树/渲染测试通过，新增真实三条线路伤害对照；最终类型检查/Vite构建通过。390×844、1280×720渲染夹具原帧截图保存，紫色侧束与青色主束可区分，敌人轮廓和血条可辨。夹具预设4突破、三只高血量静止敌人，首帧后冻结，不是自然解锁或长局演出验收。首次侧束与主束均偏蓝，调整侧束光晕/粒子为紫色后复查。
限制：尚未覆盖所有横向位置的侧束遮挡/多目标组合长局，也未测低端设备；每束45%为候选值。独立配件机体、组合解锁仪式、成就联动、更多组合及长期难度仍待推进。开发入口5178更新，5202仍Stage119历史版本。
