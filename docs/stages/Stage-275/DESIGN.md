# Stage275 航线悬赏与实战成就

2026-10-22，源码基线bc853b5；本轮承接自由空战，回应用户“需要成就，包含选择性质”“升级和奖励需要有真实意义”的既有要求。整体游戏目标仍active。

## 玩法选择与回报

三张起始组件图片各带一条本局悬赏：双翼炮对应反弹击破3敌；电弧对应3次单次实际命中至少3敌；激光对应3次同一主束实际命中至少2敌。不是选了图片就给成就，需要装配并使用相关能力。HUD显示真实进度，点击可直达需要的反弹弹芯/连锁电桥/激光节点；读树时暂停，返回不改变飞机位置或火力。达成后提示可查看对应成就。

每局悬赏只兑现一次，实体奖励为4个同系组件，出生于实际触发位置。需要真实飞近拾取；达成、已投送、已回收、已离场分开记录，不因为勋章已保存就自动加料。奖励受32掉落上限约束；满额且无同类可合并时保留待投送，出现空位再投，不能丢奖励或重复投。初测六组有两组在首领战错过18秒普通窗口，因此一次性悬赏改为最长30秒、金色外框与悬赏标签，并在首领HUD保留奖励提示；出画面仍会离场。普通零件保持18秒。没有额外货币或永久DPS加成。

## 航行档案

11项图片成就包括累计100/1000击破、5旗舰、单局万分、三条打法悬赏、三种终极认证，以及跨不同出击获得全部终极认证的三相工程师。终极认证需要该专精真实伤到旗舰且最终击破；安装图片、一般伤害、其他武器的单独击破不能冒领。终极本局互斥维持，因此三相必须跨出击选择不同路线。

档案从主页、暂停、战绩页进入，战斗冻结。每个图标有当前/目标、已达成标志和短规则，可查看后续追求。数据仅为新模式本地数值和已知成就ID，独立键firebreak-flight-career-v1，不读取/修改旧数字门存档。累计按每局新增差值记账；反复进出菜单、帧轮询和重读不会重复加分。首获成就立即保存，平时约5秒合并，暂停/离开/重开时强制刷存；存储不可用时保持内存进度并重试，不使游戏崩溃。不是战斗续关或云同步，清除浏览器数据可能丢本地档案。

## 实现与取舍

records.ts集中定义悬赏、成就、安全解析和增量台账。World仅在真实命中、最后一击、投送/拾取及旗舰击破处产出事实；Renderer负责档案、HUD和正常操作。公开只读诊断，不提供成就发放按钮。测试控制器和Session隔离验证页不进入生产入口。复用已有原创科技图片，不新增商业素材、依赖、登录、后台或经营系统。

原武器伤害/射速/敌阵保持，悬赏奖励会改变后续组装与随机序列，不能承诺每局得分都高于旧版。成就和累计不送隐藏初始组件或DPS；相关正常开局物理已做对照。数值仍是候选，真人耐玩性、长期关卡变化与火力参数可读性继续推进。
