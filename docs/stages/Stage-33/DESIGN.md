# Stage-33 光电与粒子表现候选

目标：让主要射击元素承担画面表现，保持简洁玩法。三武器采用不同长度/粗细的白热弹芯、彩色尾焰和卫星火星；穿甲附带电弧。枪口短促喷发，局部照亮；原始九帧爆炸保留火焰纹理，叠加闪燃核心、扩散冲击环、断续电弧与冷暖火星，机械残骸继续保留。

绘制只读取弹丸轨迹、模拟时间与真实事件，不扩展伤害范围。粒子标准160/弱50、爆炸4的硬上限保持，弱档省略弹道辉光、卫星火星和爆炸电弧，减少爆炸粒子。避免全屏闪白、屏幕后处理和高成本模糊。敌弹、危险预警、门数字与HUD保持上层。

验收：真实击杀触发爆炸，手机尺寸能区别尾焰/弹芯/火星，枪口不合并成遮挡机体的纯白块；弱档保留必要反馈；暂停冻结粒子、重开清空，绘制不改变World。需要实际画面审查，不以构建成功代替视觉结论。原生设备与真人观感仍待验。
