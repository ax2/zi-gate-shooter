# Stage-116 构筑、挑战成就与难度重设计

状态：策划建议，未实现、未试玩。来源为用户最新直接反馈：取消提前敌弹轨迹、难度偏低、增加积累和选择成就、升级路线/技能树/配件升级与组合、提高代入和长期动机。优先于此前五武器全部叠加即充分内容的候选目标。保留能力不因换武器被移除；不增加账号、支付、广告、后台或经营。当前停下零散光效微调，先实现可验证的构筑闭环。

## 当前事实与问题
代码world目前武器全收集共同开火，grantEquipment全局stage升级，突破永久+10%；三章九组重复。存档仅最高分和设置，没有成就、配件树或构筑存档。五种子脚本20分钟通过不能证明真人有挑战。自动满配与全武器同步升阶压低选择价值；未来弹道线提前泄露解法；充能解锁虽有反馈，但大多固定顺序，局与局差别小。

## 核心提案：战地机甲构筑
角色是一名在推进战线上临时组装机甲的驾驶员。仍左右移动、自动开火。射击箱门是获取构筑资源的手段，目标从捡齐所有枪转为完成一套战术。主炮和获得的模块均保留，不设会强制吞掉旧武器的装备上限。机会成本来自升级次数与分支选择，而非拾取后降级。暂停式技能选择只出现在突破或首领安全结算点，战斗中仍靠走位选择箱门，不叠加密集菜单。

一次标准体验以8至12分钟形成完整构筑为候选，打完仍可进入更高威胁无尽；这不是硬时间上限。后续无限成长保持有限实体数，不能无限增殖子弹/连锁。

## 单局节奏（候选）
- 0至30秒：主炮开战，第一个箱子必定给两个不同方向的配件选项；击碎后拾取，只领一个，第一分钟就有打法差异。
- 30至90秒：补基础配件与第一次突破。普通奖励直接领取，突破提供暂停三选一，旁边能查看整棵本局技能树和当前收益。
- 90至150秒：首领检验构筑，并给确定性升级；奖励选择完成后再开始下一章。时间随战斗表现变化，不能无限等敌人清空却没有首领入口。
- 每章安排快速清杂、针对性威胁、释放奖励、首领四段。每两章至少一个改变打法的进化节点，避免只有百分比变化。
- 首领后可选择一个战地挑战：提高风险换额外一次构筑奖励，或不接受。失败不会让整局立刻结束。

## 装备与技能树
装备由独立的武器模块等级、局内分支、组合节点构成。取消所有武器同时T3：拿到新模块是该模块L1；重复配件可升级对应模块，已满级转研发点。显示每件模块自己的等级和实际参数。已获得的威力不因这次结构迁移在旧进行中对局突然变化：新规则只对新局，旧记录保留且标记规则版本。

第一版三条主路线，每条3个节点：
1. 雷电：导电标记 → 分支选连锁扩散或单体蓄爆 → 离子风暴组合。
2. 激光：贯穿光束 → 分支选持续切割或周期扫射 → 棱镜光阵组合。
3. 弹道：近距聚弹 → 分支选破甲穿透或爆破弹芯 → 雷暴霰射/裂甲爆破组合。
每次只从已解锁前置中选择，至少一个选项适配已有装备；无效项不占奖励。允许跨路线，但有限奖励意味着专精和混合有差别。分支互斥只限制未来节点，不删除原有能力、不降低既有数值。初版不做几十个微小百分比节点。

重复装备明确三种结果：首次解锁模块；对应模块升级；满级转固定研发点。研发点在首领结算用于一次定向升级或补缺失基础模块，不做商店经营和货币堆叠。角色不因为捡到无关模块损失当前装备。

## 三套首批组合
| 构筑 | 条件 | 新机制 | 应对弱项 |
| 雷暴霰射 | 霰射升级+导电模块 | 一轮命中同敌达到阈值，产生一次向邻敌的闪电 | 需要聚弹；远处收益小 |
| 棱镜激光 | 激光升级+折射模块 | 光束首次命中分出两条侧束，不递归；每目标每次发射只受一次分束伤害 | 单体主束不减伤；分支收益依赖站位 |
| 裂甲爆破 | 穿甲升级+爆破弹芯 | 穿透对装甲积累裂口，达到阈值触发局部爆破 | 需要持续命中，分散扫射触发较慢 |
组合是加法进化，不消耗基础配件。达到条件后在下一次突破/首领奖励中保证出现激活选项，不靠极低概率。图鉴提前显示两项配方及效果预览，拒绝后仍可再获得。额外命中不对箱门重复刷能量；派生攻击不能无限触发派生攻击；给出每次发射/每目标去重与触发冷却。

## 成就：记录、技巧、选择三层
- 记录型：击破数、首领次数、发现全部模块；奖励图鉴/徽章/外观，不作为主要耐玩手段。
- 技巧型：无伤过首领、连续三个精英不受伤、用组合一次清除一群敌人。按真实事件判定，禁止依赖按钮点击或只看最终分数。
- 选择型战地契约：每局或首领后选一个，主动改变下一段目标。
  - 孤注一掷：下一首领前不领取修复奖励并存活获胜，得到额外模块升级。
  - 定向研究：下一章完成所选组合，奖励一次对应分支进化。
  - 危险猎手：选择额外精英波并击破，奖励定向配件；不接受则走常规波。
  - 专精试炼：已持有模块照常保留，下一章不拾取新类型武器并击败首领，奖励已有模块升级。
所有可选契约先显示条件、期限、奖励、当前进度和失败条件；按装备状态过滤不可完成任务。无维修资源出现时，相关契约不作为有效挑战奖励刷取；额外精英可达性先检查。每次最多一个契约，避免任务墙。失败只失去额外奖励，原装备/主线保留；不设每日签到、限时过期、重肝永久伤害。
长期成就解锁新的同强度起始模块、挑战变体、机体涂装/挂件与档案记录；不靠永久攻击力让旧关卡越来越无聊。所有进度先本地保存，版本迁移保留最高分/设置，写入失败显示未保存；不需要账号。

## 难度与可读性
明确移除：未来弹道线、扇形轨迹、提前标记全部安全路径。保留敌机自身抬枪、炮口蓄能、短促音效和已发射子弹；这些是行为信息，不显示未来轨迹。高速直击若依赖旧轨迹才能躲，需要同时调弹速、蓄能和发射距离，不能只删图制造必吃伤害。
从首章后半就让精英迫使玩家移动。难度来自侧翼突进+正面盾卫、近距群敌+远程压制、首领转阶段与站位要求。降低无脑站桩收益，不能用全屏随机弹海和纯血量墙。给予全套构筑的玩家清杂优势，但留下优先击杀目标。
使用预定威胁等级/章节曲线增长，不按玩家DPS实时等比例抬血。限制同时攻击槽，避免不同敌人随机同时封死横向走廊。可达性验证以移除轨迹后的可观察行为和反应窗口为基准，而不是脚本预知所有弹道。候选反应窗口普通威胁0.45至0.7秒，高危0.7至1秒，必须试玩修正。
无尽每两章增加一种有限规则变体，例如精英护卫、移动掩体、首领双阶段；先做少数互相可组合的变体，不能宣称有限变体带来无限新内容。更长局目标为挑战层数/构筑极限，允许首领后主动结束并记录成绩。

## 反馈与代入
新配件实际装到机体并显示独立发射动作，不能只切换整个人物贴图。升级某配件只让该组件结构/声效变化；组合激活增加专属发射演出。战斗画面数字少，奖励/结算清楚显示本局构筑、关键组合触发、达成契约与解锁。角色移动避让、武器后坐与爆炸受击共同支撑代入，背景剧情仅简短任务语音/文字，不加大量对话。
