# Stage-203 雷暴霰射精研

增加雷暴霰射精研二选一：串联电桥保留原跳电并追加340范围第二跳；聚雷破核对同敌累计6次霰弹有效直击，追加150%单体放电。T3霰射/弹道3/精调5后花1点，原武器、分支、跳电与常规增伤保留。52相关检查/构建、两条正常600秒及手机/桌面实际选择与触发留证；后期重复度、两项强度和长期真人体验仍待收敛。

本轮先以59cb367基线三条正常600秒策略审计：均R8/HP3、31次升级，最后一次机制分支约162秒；弹道优先后续22次精调。操作者策略有限，不能外推所有流派无选择。源码确认雷暴只有基础跳电，后续弹道机制取舍主要依赖另两件配件的裂甲。

新分支要求弹道3、雷电≥1、弹道精调≥5、已拥有T3霰射；若已有可选裂甲精研，先处理裂甲，随后再开放雷暴。所有前置均以真实状态核对，花1已赚技能点；本次仍增加原弹道10个百分点。选择本局不可改选，未选其它武器也不会被移除。T3与精调5为候选，不是用户确认值。初版精调2在161秒过早，调至5，正常约209.53秒出现。

串联原首跳保留，追加一跳340范围，沿用65%或80%逐跳衰减/最近目标/ID稳定顺序、访问集合、不回跳、不递归。箱门不作为跳电目标；原护盾/保护阻断保持。初版追加跳距沿用原值，正常额外5次；扩距后7次，仍需更多场景和真人平衡观察。单独首领没有新增目标是明确取舍。

聚雷每台存活敌机单独累计6次霰弹实际直击；脉冲/跳电/溅射/激光等派生不计，箱门、闭盾、保护入场不计，直接击破不留下可转移收益。每满6次额外造成触发弹丸伤害150%的单体放电，沿用hit的真实减伤/死亡/得分，不递归其它组合。前一次原跳电和派生结算完成后才蓄雷。首领入场不可命中，击破只结算一次。
