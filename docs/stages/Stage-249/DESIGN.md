# Stage-249 重装护炮组

2026-10-18，候选数值，后续需真人试玩。针对重装章后半段轻机重复、长局空场的问题，增加需要分配火力与走位的组合，而非只加一排血条。

第3章起，每个重装章在14.7、37.7秒各增加6名敌人：前盾卫、后炮、侧翼两轻机、延后1.05秒的冲锋机和一名跟进轻机。盾炮在同一纵列，初始纵向间隔200px；另一翼可独立清理。两组交换左右，且随已有镜像排程翻转。新增共12敌，原敌阵、装备、门和首领排程逐项保留。

沿用战况轮换：扇射护炮、沿边折返护炮、横移护炮。后炮使用已有行为与耐久规则；折返炮沿用BANKSHOT的4倍基础耐久，扇炮和横移炮不额外加血。不是按玩家伤害或武器实时抬血。原敌人预算26、弹预算、投送保护0.45秒、开火蓄能与安全准入仍生效，新增炮与盾的首次计时0.5秒，不突然在玩家身上生成弹幕。

取舍：可以正面拆盾、压后炮；也可以先清另一翼冲锋，再移动到后炮可命中的方向。前盾按真实接触吸收玩家弹丸，后炮没有额外无敌。横移炮离开前盾纵列后，按实际位置提示“后炮离盾”，不制造预告射击轨迹。闭盾/开盾/离盾三种帮助复用原下方说明区并服从危险避让。
