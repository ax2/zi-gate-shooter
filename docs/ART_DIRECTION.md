2026-10-11 / Stage-00。方向为候选，当前无概念图、无批准稿、无正式素材、无运行截图。此规格定义未来制作与验收，不代表视觉已经实现。

## 1. 视觉目标

建议使用斜俯视的工业试验跑道：石墨灰金属地面、冷白机体、青蓝我方弹道、琥珀橙爆炸；敌方危险使用珊瑚红与白色实心箭头/菱形。门是有实体边框与机械底座的装置，箱子是有锁扣、甲板接缝和分层破损的机械箱。形状与动势承担识别，不能只靠红绿区分。

精细来自统一透视、材质、阴影、关节、反冲和受损状态；爆裂来自短促的打击、碎裂、烟火层次与节奏。辉光仅辅助，不接受“几个几何图形加泛光”作为正式成果。

先建立三个可审阅状态：普通 T1 战斗；箱子破碎后装备露出、旁边门正在升档；T3 密集清场与危险共存。需先确认完整画面方向，再拆出透明背景的独立资源；概念图里的数字不是最终 UI。角色、敌人、地表、门框必须使用同一视角与左上主光方向。

## 3. 层级与清晰度

绘制顺序：地表→阴影→实体→我方弹道→局部爆炸/烟尘→敌弹与危险预警→奖励数字/耐久/角色识别轮廓→HUD。给主要对象加少量接触阴影，减少贴纸感。敌弹始终有稳定实心核心与暗描边，不被烟覆盖。

关键区域包括每扇门数字面板、箱子耐久、玩家核心和敌方弹丸。爆炸进入这些区域时降低装饰烟透明度，数字面板保持不透明深底。屏幕震动只影响画面呈现，不移动判定或HUD，不改变输入坐标换算。

门主数字目标≥24 CSS px、标签≥14 CSS px，按实际缩放计算而非固定逻辑字号。在360×800中，720宽画布缩放约0.5，因此主数字至少48逻辑px、标签28逻辑px。长文案如“火力+5%/超载+25”拆为两行，不缩到无法辨认；金额上限状态使用“储能已满”。更小视口使用短标签并保证最低字号，必要时声明最小支持宽度待确认。

装甲、门、箱子不能都使用同一个发光圆。敌弹为菱形/箭头与清晰长程动势，我方弹为细长短拖尾；奖励为稳态机械轮廓、低频呼吸；危险为有时间方向的填充预警。关闭色彩区分后仍能识别主要类型。

## 4. 反馈强度预算（候选，未实测）

| 事件 | 画面/声音 | 时间与上限 |
|---|---|---|
| 开枪 | 短枪口、炮管后坐、弹芯与短尾 | 枪口30–50ms；同组声音合并，不按每弹播放完整枪声 |
| 普通命中 | 接触点火花、局部受击亮边 | 50–90ms；同目标每80ms最多一次视觉闪光 |
| 箱破碎 | 甲板先裂开、4–8块碎片、装备露出 | 0.25–0.4s；最多6块装饰碎片常驻/箱，掉落标签立即清楚 |
| 门升档 | 数字短促放大、机械边框充能 | 0.12s；一次多档只播一次，以最终数值为准 |
| 拾取升阶 | 炮组展开、能量汇入、射击音层变厚 | 0.35–0.5s；下一模拟步战力生效，不等动画结束 |
| 普通击杀 | 核心火球、小烟团、短碎片 | 0.18–0.3s；不摇屏；同区80ms内爆炸可合并 |
| 精英击杀 | 两层冲击波、残骸与低频短音 | 0.4–0.6s；震动≤3逻辑px/90ms |
| 首领击杀 | 顺序局部爆炸、断裂、机芯熄灭 | 0.8–1.2s；震动≤5逻辑px/160ms；不做全屏白闪 |

第一版去掉击中停顿和首领慢动作，避免改变射击、超载和奖励可达性；可以用声音瞬态和分层爆炸实现重量。正式试玩后如要增加慢动作，需统一模拟时钟再评估。

候选硬上限：装饰粒子标准160/弱档50；同时大爆炸≤4；残骸≤12、寿命≤2秒；浮字≤8，得分按短时间窗聚合；效果声音并发≤12。超过预算优先合并/省略烟、碎屑、浮字，不能删掉敌弹、预警、门数字或箱子耐久。预算不等于引擎能稳定运行的结论。

设置简化为特效标准/弱、震动开/关、音乐开/关、音效开/关；弱档取消强光脉冲并降低烟密度。逻辑对象数量、敌方危险和奖励规则在两档完全一致。音频在首次“开始”操作初始化，初始化失败仍能无声游玩并显示设置状态。

## 5. 视觉验收门槛

在360×800、390×844、430×932和桌面1440×900实际运行，分别保存常态、箱碎、门升档、T3群怪、首领爆炸截图；同一状态记录标准/弱档。动态表现另留短录屏，静态图无法证明拖尾、摇屏或警告时机。

检查：正常比例下2秒内能读出奖励和生命；T3不看HUD也能由炮管、弹道和声音辨识；高密度截图里可指明危险来源与安全通道；地面接缝不可见、素材透视一致、放大无明显脏边；弱档不隐藏危险。至少3名未参与设计的试玩者中，至少2人能在首局后解释“箱子打碎还要捡”和“门穿过才加”。这是待执行验收目标，不是已有人参与测试。

正式可视版本必须有配套实体美术。构建成功、程序截图、概念图以及AI自评都不能替代实际画面检查和玩家体验。
