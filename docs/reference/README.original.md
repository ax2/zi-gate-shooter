# 游戏规划与 Codex 交接包

本包用于把“竖屏无尽数字门射击游戏”的讨论交给新的 Codex 会话。它是策划资料，不是已完成的游戏工程，也不会自动创建或迁移会话。

## 文件

| 文件 | 用途 |
|---|---|
| `docs/GAME_DESIGN_HANDOFF.md` | 完整上下文、确认需求、设计方案、候选数值、开发范围、里程碑与验收规则 |
| `CODEX_START_PROMPT.md` | 新会话第一条消息，复制其中分隔线后的内容即可 |
| `AGENTS.md` | 精简的项目协作约束，指向完整策划 |

## 使用

新会话需要实际能读取这些内容，不要仅告诉它旧聊天标题。

在支持附件的会话里，提供完整策划文件并粘贴启动指令；使用项目工作区时，把相关文档放入 Codex 可读的目录，再要求它先读文件。已有仓库中的 `AGENTS.md` 应先检查并合并，不能直接覆盖。`README.md` 也不需要覆盖现有工程的说明。

本包的启动指令默认先完善规划，不会授权自动开始开发、部署或购买任何服务。准备进入实现时，再在新会话明确提出“开始开发”。

最小移交只需完整策划与启动指令；`AGENTS.md` 用于在有项目目录时保留简短工作约束。

Codex 官方关于项目指令文件的说明：`https://developers.openai.com/codex/guides/agents-md/`。

## 已完成与未完成

已完成：需求总结、v0.1 游戏规划、候选规则与数值、初版范围、开发顺序、测试清单和启动指令。

未完成：代码、正式美术与音效、试玩、性能实测、发布、新会话创建或迁移。文档内的技术和美术方向均标明建议状态。
